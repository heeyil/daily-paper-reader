## 摘要
当智能体自身的状态和自我报告恰恰是你无法信任的东西时，你如何验证一个长期智能体？我们提出一种智能体工具，其构建使得验证是结构性的而非事后性的。一个确定性的执行器拥有所有信念；语言模型只能提交类型化的提案，并且只有当行动前预先登记的预测被代码与观察结果匹配时，声明才被接受。该工具使其成为自身科学的验证者，而不仅仅是智能体的验证者，这体现在两个性质上：每当每个组织的写入错误、渲染大小或加盐金丝雀回显下限被突破时，每次运行都会使自身失效（前八次架构运行中有四次被判定无效，每次均定位到一个真实缺陷）；以及一个渲染不可见的影子参考，编译了完整系统在每个消融单元中本会承诺的计划，因此即使在所测试机制已被移除的情况下，漂移指标也是可定义的。利用该工具，我们报告了一个关于每个长期智能体都会遭遇的失败的干净的单变量结果：消融承诺机制将目标放弃率从0.00翻转为1.00，而绑定误差保持平稳在0.00（每个单元三个种子，每次运行最多394个参考节拍，每次运行均通过有效性门控）。相比之下，绑定通道在其修复被消融时并未重新表现为每节拍漂移——因为绑定归代码所有，该失败类别被结构性吸收，其唯一残留出现在上一层，表现为假设形成的崩溃。我们在完全披露的情况下报告这些结果：任务效能为零（在ARC-AGI-3上52次门控运行中零级完成任务），并预先登记为结构性挫败。贡献在于一种用于智能体开发的验证方法及其使漂移分解变得可测的特性。

## Abstract
How do you verify a long-horizon agent when its own state and self-reports are exactly what you cannot trust? We present an agent instrument built so that verification is structural rather than post-hoc. A deterministic Executive owns all belief; a language model may only file typed proposals, and a claim is admitted only when a prediction pre-registered before acting is matched against observation by code. Two properties make the instrument a verifier of its own science, not just of the agent: every run invalidates itself when per-organ write-error, render-size, or salted-canary-echo floors are breached (four of the first eight architecture runs were invalidated, each localizing a real defect); and a render-invisible shadow reference compiles the plan the full system would have committed in every ablation cell, so drift metrics are defined even where the mechanism under test has been removed. Using this instrument we report a clean, single-variable result on a failure every long-horizon agent suffers: ablating the commitment mechanism flips goal-abandonment from 0.00 to 1.00 while binding error stays flat at 0.00 (three seeds per cell, up to 394 reference beats per run, every run gated valid). The binding channel, by contrast, does not reappear as per-beat drift when its repair is ablated -- because binding is code-owned, the failure class is structurally absorbed, its only residue appearing one layer upstream as a collapse in hypothesis formation. We report these under full disclosure that task efficacy is null (zero level completions across 52 gated runs on ARC-AGI-3), pre-registered as a structural defeater. The contribution is a verification methodology for agent development and the drift decomposition it makes measurable.

### 1. 核心问题与整体含义（研究动机与背景）

- **核心问题**：长期（long-horizon）语言模型智能体在执行数百至数千步任务时，会偏离自身目标——即“目标漂移”（goal drift）。然而，现有验证方式存在两个根本性弱点：
  - **信任危机**：大多数评估依赖智能体自身的状态和自我报告，智能体说“完成了”就被计为完成，但智能体的状态恰恰是不可信的。
  - **指标模糊**：漂移以聚合分数报告，无法判断具体是哪一种失败，也无法判断某次运行本身是否有效、是否应被归因。
- **整体含义**：论文主张验证应当是**结构性的**（built into the agent），而非事后性的（post-hoc）。其核心立场是：**“谁验证智能体？”** 的答案不是另一个智能体或下游检查器，而是通过架构设计让验证成为运行的基石。
- **关键概念分解**：论文提出“漂移”并非单一失败，而是至少两种机制上不同的失败：
  - **绑定漂移（binding drift）**：意图及其指称对象都在，但“目标”与“目标所指向的对象”之间的连接仅存在于 Transformer 注意力中，在长距离、低显著性情境下会丢失。修复手段是**位置性/结构化绑定**。
  - **承诺漂移（commitment drift）**：意图本身从后续上下文中消失，即使每个上下文都很短、目标高度显著，错误仍会累积。修复手段是**外部承诺存储（由代码执行）**。

### 2. 方法论：核心思想、关键技术细节、算法流程

**核心架构——LLM 提议，执行器（Executive）处置：**

- **确定性执行器（deterministic Executive）** 拥有全部信念（belief）状态；语言模型不能直接修改任何状态，也不能读取原始数据转储。
- 三个模型“器官”只能通过**类型化提案（typed proposals）**在封闭词汇表中提交请求：
  - **Observer（观察器）**：解释机器计算的变化集（change-sets）；
  - **Surveyor（测绘器）**：提出目标/假设/实验；
  - **Actuator（执行器）**：发出动作。
- 所有提案须通过**准入门（admission gates）**，由执行器（差分器、匹配器、验证器、编译器、渲染器、测试评估器）处理。
- 所有存储为**追加式（append-only）**，状态通过计算得出而非覆盖，每个结果回执（receipt）键控至精确的逐帧锚点，保证身份是可重放的数据。

**信念分级验证：**
- 一个指称对象（referent）需逐级攀升，每级转换均由机器检查：
  1. 仅命名文本（尚未成为指称对象）；
  2. 从原始观察中经显著性无关抽取锚定；
  3. 被已记录的动作回执参与（engaged）；
  4. **被特征化（characterized）**：仅当被一条经过测试的规则引用时成立——即该规则的预测在行动前被预注册到日志中，并由执行器与确定性观察差分匹配。
- 模型无法伪造未经预注册的匹配；“完成”永远不是一个事件，而是触发对已记录事件的谓词。

**两个独立开关（消融机制）：**
- **绑定修复 J（ARG_JOIN=0/1）**：目标↔指称对象的持久连接结构，每轮在固定提示位置重新以预连接的形态呈现所有活跃目标，避免模型跨距离提示区域自行连接事实。
- **承诺修复 A（ARG_AGENDA=0/1）**：由代码执行的外部承诺存储，即编译后的计划，Actuator 独立于模型注意力进行查阅。
- 两者均为单一环境标志，其他脚手架完全一致——保证单元间差异可归因于单一变量。

**运行自验证机制：**
- **运行有效性门（run-validity gate）**：满足以下任一条件则本次运行标记为 INVALID（不可用于归因）：
  - 任一器官的每操作写入错误率 > 0.25；
  - 任一渲染视图超过硬性 token 上限；
  - 加盐金丝雀（salted canary）回显率低于下限。
- **金丝雀（canaries）**：注入各提示区的隔离合成行；分区回显可区分传输缺陷与消费腐败。
- **影子参考（shadow reference）**：在每个消融单元中，以纯读取方式编译完整系统本会承诺的计划（不渲染、不执行）。字节一致性测试证明影子路径不会泄漏到行为中，从而在有/无消融的单元格中都能定义漂移指标。

**漂移分类（逐拍打分）：**
- 每个参考节拍（reference beat）若有计划步骤（target, action）：
  - **bind**：执行了计划的动作且带有意图，但落在 ≠ 计划目标的指称对象上；
  - **aligned**：忠实执行了活跃步骤；
  - **abandon**：既未按计划的动作执行，也未命中计划的刻意目标。
- 无目标动作不带意图参数，无绑定接缝——可以放弃但不会绑定失误。

### 6. 主要结论与发现

1. **承诺漂移的因果分离**：仅消融承诺机制（A0），目标放弃率从 0.00 翻转为 1.00，绑定误差保持 0.00——效果是单变量的、极端显著的（在最多 394 个参考节拍中几乎每拍都放弃）。
2. **绑定漂移被结构性吸收**：消融绑定修复（J0）不改变任何逐拍指标（bind=0.00, abandon=0.00, grounding rate=1.00, goal adherence=0.964），因为瞄准（aiming）、包容性检查（containment checking）和回执归因（receipt attribution）均由执行器代码拥有，绑定失败类别在构造上不可能发生。
3. **绑定修复的残留在上游**：双消融（J0A0）导致效应关联的假设形成率从 3/3 降至 0/4——系统在产生计划之前就已崩溃。绑定修复的可测影响在“假设原料”层，而非逐拍漂移层。
4. **任务效能为零**：52 次运行中零关卡完成，预注册为结构性挫败（defeater）；但机制结论独立于效能成立——系统是“纪律严明的实验者”，而非“会得分的玩家”。
5. **小型模型可行**：Haiku 级模型在工程改进（逐操作示例）后实现写入错误率 0.0，证明该架构将模型任务降为封闭语法中的槽填充，降低了对模型能力的依赖。
6. **机制通用性**：引擎在 3/3 个未见过游戏上生成课程、假设和里程碑（2/3 通过有效性门），零游戏特定代码。

### 7. 优点

- **验证的结构性设计**：信念必须通过“预注册预测 + 确定性匹配”获得，模型无法伪造匹配。“完成”不是事件——从架构上杜绝了自我报告的不可信问题。
- **运行自动失效机制**：金丝雀回显、写入错误率、渲染 token 上限三重门控使运行可自我宣布无效；前 8 次运行中 4 次被判定无效且每次定位到真实缺陷，证明门控不是装饰品。
- **影子参考解决“消融中指标未定义”的困境**：即使在承诺机制被删除的单元格中，也能定义漂移指标（通过编译“完整系统本会承诺的计划”），这解决了消融实验中的测量缺失问题。
- **漂移的分解**：将目标漂移分解为承诺漂移和绑定漂移两个可独立开关的通道，给出干净的因果分离结果——这是此前文献未做到的。
- **坦诚的 null 报告**：先报告效能为零，预注册为结构性挫败，而非事后掩饰；同时证明机制结论独立于效能。
- **可靠的工程保障**：字节一致性测试确保影子路径不泄漏；早期引用虫（按 id 而非最具体包含者归因点击）被工具自身的分解暴露并当日修复——工具能自查缺陷。
- **计算对等性**：完整系统推理消耗低于裸骨干，排除了额外推理开销的影响。

- **任务效能为零**：在 ARC-AGI-3 上零关卡完成，系统距离实际任务能力有根本差距。
