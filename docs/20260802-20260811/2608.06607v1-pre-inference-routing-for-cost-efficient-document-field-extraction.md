## 摘要
大多数文档提取系统对所有文档使用单一模型。这虽然简单，但对简单案例可能成本高昂，对困难案例则效果不佳。我们研究是否可以在提取前使用廉价的、基于文档的信号预测文档难度，并据此在较便宜与较强的提取器之间进行选择。我们发现，只有满足两个条件时，路由才有帮助：较便宜模型失败得足够频繁，使得路由有价值；并且这些失败可以从可见特征（如图像质量和布局）中预测出来。我们将这些转化为一个实用测试，并将其应用于五种文档类型。当两个条件都满足时，校准后的路由器在收据上降低了31-33%的成本，在退化的广告投放表单上降低了77%的成本，同时质量保持在始终选择大型模型的F1值0.02以内。如果任一条件缺失，路由则无帮助，例如已易于读取的清洁数字发票或营养标签。一个小规模标注试点可以预测路由是否有效，在我们首先运行的两个案例中，预测是正确的。一个简单的词袋路由器与工程特征的效果相当，表明主要限制在于文档类型而非路由器设计；我们使用可解释特征来帮助解释哪些文档类型可以被路由。路由器必须针对每个数据集重新训练，并且不能跨数据集迁移，即使在同一文档类型内也是如此。这些结果适用于成本差异为5倍和3倍的两组模型对。

## Abstract
Most document-extraction systems use a single model for all documents. This is simple but can be costly for easy cases and less effective for difficult ones. We examine whether we can predict a document's difficulty before extraction using inexpensive, document-based signals, and use this to choose between a cheaper and a stronger extractor. We find that routing only helps if two conditions hold: the cheaper model fails often enough to make routing worthwhile, and those failures can be predicted from visible features such as image quality and layout. We turn these into a practical test and apply it to five genres. When both conditions are met, the calibrated router reduces cost by 31-33% on receipts and 77% on degraded ad-buy forms while keeping quality within 0.02 F1 of always choosing the large model. Routing does not help if either condition is missing, as with clean digital invoices or nutrition labels that are already easy to read. A small labeled pilot can predict whether routing will work, and in the two cases where we ran it first, the prediction was correct. A simple bag-of-words router works about as well as engineered features, showing that the main limit is the genre, not the router design; we use interpretable features to help explain which genres can be routed. The router must be retrained for each dataset and does not transfer across datasets, even within the same genre. These results hold for two model pairs with cost differences of 5x and 3x.

## 2. 论文提出的方法论

**核心思想：**
- 对每个文档 $d$，计算 13 个预推理特征向量 $x(d)$；
- 定义难度缺口 $g(d) = q_\ell(d) - q_s(d)$，其中 $q_\ell$ 和 $q_s$ 分别为大/小模型的字段级 F1；
- 根据 $g(d) > \tau$（$\tau=0.02$）生成二值标签 $y(d)$（是否“需要大模型”）；
- 训练一个校准随机森林（配 isotonic 校准）估计 $p(d) = \Pr[y(d)=1 | x(d)]$，当 $p(d) \ge t$ 时路由到大模型；
- 扫描阈值 $t$ 绘制成本–质量 Pareto 前沿，选取满足 $Q(t) \ge Q_\ell - \delta$（$\delta=0.02$）的最小成本点 $t^*$。

**关键技术细节：**
- **13 个预推理特征**，分为 4 个家族：
  - OCR 质量（均值/标准差置信度、预处理 stage、短 token 比例、字符碎片化）；
  - 图像质量（拉普拉斯模糊分数、对比度、词框高度变异系数）；
  - 布局（拥挤行比例、行密度、宽高比）；
  - 内容/结构（条目密度、总 token 数）。
- 特征仅来自页面图像、OCR 文本和 OCR 框几何信息，**完全不使用 ground-truth 标注**，避免标签泄漏。
- 成本模型：按 token 计费，$c_m(d) = \pi^{in}_m n_{in}(d) + \pi^{out}_m n_{out}^m(d)$，主模型对成本比为 5×（Haiku/Opus），另一个模型对为 3×（Haiku/Sonnet）。
- 管线：离线阶段（OCR → 特征 → 运行两个模型 → 计算 gap → 训练路由器），推理阶段（OCR → 特征 → 概率 → 阈值决策）。

## 6. 论文的主要结论与发现

1. **路由只有在两个条件同时成立时才有价值**：存在足够的困难文档（headroom），且这些困难可从预推理特征中预测（AUC 显著高于随机）。
2. **可路由的正面证据**：
   - 收据（CORD+SROIE）：held-out AUC 0.707，成本节约 31–33%，质量损失 ≤ 0.02 F1；
   - 退化广告投放表单（DeepForm，非收据）：held-out AUC 0.916，成本节约 77%，质量损失 ≤ 0.02 F1；
3. **不可路由的负面案例**：
   - 数字发票（DocILE）：虽有 67% headroom，但 AUC 仅 0.52——语义难度无法从视觉/布局特征中预测；
   - 营养标签（POIE）：AUC 0.63 可预测，但 headroom 仅 16%——小模型已接近上限；
   - VRDU：headroom 与 AUC 都弱，属于边缘情况。
4. **路由器设计并不是瓶颈**：一个简单的词袋（TF-IDF/LSA）文本路由器在大部分类型上与 13 维工程特征效果相当；真正的决定因素是文档类型本身是否满足两个条件。
5. **路由器不跨数据集/跨类型迁移**：即使 CORD→SROIE 也是随机水平（≈0.55），因此必须对每个部署语料重新训练。
6. **预推理路由严格优于置信级联**：在完整文档重新提取并采用相同升级决策时，预推理路由因避免了在升级文档上多余的廉价调用而更便宜；在升级频繁时，甚至优于具有完美触发条件的级联。
7. **跨模型对鲁棒**：在 3× 成本比的模型对上也成立（DeepForm 节约 65%，收据 22–51%）。
8. **可解释性**：重要性最高的特征是 token 碎片化比率（inv_chars_per_word）、条目密度（item_density）和 OCR 置信度标准差；图像质量特征贡献较小。

## 7. 优点

- **清晰的两条件诊断框架**：将“能否路由”拆解为可量化的 headroom 与可预测性两个条件，给出可直接在小样本上操作的检验步骤。
- **严格防止标签泄漏**：特征仅用图像/OCR/布局，不用任何 ground-truth 信息；并主动报告了移除潜在泄漏特征前后的 AUC 几乎不变。
- **评估客观**：以阈值无关的 AUC 作为主要判别指标，同时提供无窥探（no-peek）阈值转移实验和 bootstrap 置信区间，减少选择性报告风险。
- **成本与质量双目标明确**：定义了在质量损失容差 δ 下最小化成本的优化问题，并绘制 Pareto 前沿，便于实际部署决策。
- **多角度消融**：特征家族消融、评分协议对比、阈值敏感性、跨模型对、跨类型迁移等，分析全面。
- **诚实结论**：承认工程特征并不优于简单词袋，强调路由价值由数据固有属性而非路由器设计决定；明确报告不适用场景。
- **实际可操作**：发布代码与特征提取器，使用固定模型快照，结果可复现；小试点成本低廉（数美元）。

## 8. 不足与局限

- **正面场景覆盖有限**：只有收据和 DeepForm 两类显示明确收益，更广泛的正面案例（如合同、学术文档等）尚未验证。
- **跨域不可迁移**：路由器必须按数据集重训，无法直接复用，这限制了其在快速更换语料场景下的便利性。
- **仅单页处理**：DeepForm 多页表单仅处理第一页，导致绝对 F1 偏低（部分字段在后续页），虽不影响 gap 但限制绝对性能评估。
- **单次采样与解码噪声**：每个文档仅采样一次，F1 标准差约 0.02，与 τ 同量级，可能使靠近边界的标签不稳定；作者通过 AUC 稳定性和重提取试点部分缓解，但未完全消除。
- **依赖特定供应商与 OCR**：模型版本与价格均来自 Anthropic 固定快照；Tesseract 的 OCR 置信度未跨引擎校准，跨引擎可能不稳定。
- **未覆盖 FUNSD**：由于注解类型（实体链接标签而非键值字段）与本文的提取 F1 协议不兼容，无法评估该基准。
- **未测试跨提供商**：未验证其他提供商（如 OpenAI、Google）或开源模型对路由结果的影响。
- **概念边界**：路由目标只在“文档页面”上，不涉及文本查询级别路由，因此不适用于纯自然语言问答场景。
