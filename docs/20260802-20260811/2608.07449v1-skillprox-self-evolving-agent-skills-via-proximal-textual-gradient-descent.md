## 摘要
LLM智能体通过将程序性知识积累到技能中，日益适应重复性任务。这些技能是轻量级、可复用的文本工件，在无需权重更新的情况下加载到智能体的上下文中。近期方法通过迭代任务执行、失败诊断和轨迹引导的文本空间更新来细化技能。然而，现有框架缺乏明确的诊断结果反馈，并将删除视为一种通用编辑操作，而非用于整合累积知识的专门机制。我们提出SkillProx，一种受近端梯度启发的正向-反向框架，将闭环诊断进化与效用感知的近端细化相结合。受到平衡任务损失和技能复杂性的复合目标的驱动，正向阶段在同一任务批次上重新执行诊断驱动的编辑，回滚回退，并将测量结果反馈到后续诊断中。反向阶段将生成的技能分解为可审计的知识单元，使用冻结的留一效用审计估计其贡献，并应用验证门控的整合、降级或移除。在多个骨干LLM上的分布内和分布外基准实验中，SkillProx相比最强的基于梯度的基线平均准确率提升了3.0个百分点。组件消融实验证明了闭环诊断和近端细化的互补效应。

## Abstract
LLM agents increasingly adapt to recurring tasks by accumulating procedural knowledge in skills. These skills are lightweight, reusable textual artifacts that are loaded into the agent's context without weight updates. Recent methods refine skills through iterative task execution, failure diagnosis, and trajectory-guided text-space updates. However, existing frameworks lack explicit diagnosis--outcome feedback and treat deletion as a generic edit operation rather than a dedicated mechanism for consolidating accumulated knowledge. We introduce SkillProx, a proximal-gradient-inspired forward--backward framework that couples closed-loop diagnostic evolution with utility-aware proximal refinement. Motivated by a composite objective balancing task loss and skill complexity, the forward stage re-executes diagnosis-driven edits on the same task batch, rolls back regressions, and feeds measured outcomes into subsequent diagnoses. The backward stage decomposes the resulting skill into auditable knowledge units, estimates their contributions using a frozen leave-one-out utility audit, and applies validation-gated consolidation, demotion, or removal. Experiments on in-distribution and out-of-distribution benchmarks across multiple backbone LLMs show that SkillProx improves average accuracy by 3.0 percentage points over the strongest gradient-based baseline. Component ablations demonstrate the complementary effects of closed-loop diagnosis and proximal refinement.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **背景**：大语言模型（LLM）智能体通过将程序性知识外部化为“技能”（skill）来适应重复性任务。技能是轻量级、可复用的文本工件（如 `SKILL.md` 和引用文件），在推理时加载进上下文，无需更新模型权重。
- **现有方法的不足**：
  - **前向更新缺乏验证**：已有技能进化方法（如 SkillGrad）将 LLM 生成的诊断视为有效更新方向，直接提交补丁，不重新执行验证效果，也不把结果反馈给后续诊断。这种“开环、增长导向”的方式可能采纳看似合理但实际有害的编辑。
  - **技能增长无约束**：迭代打补丁会不断累积重复指令、冲突启发式或过度任务特定的规则，删除只是被当作一种通用编辑操作，缺乏专门的“知识整合/收缩”机制，导致冗余内容干扰有效知识。
- **核心问题**：如何将“结果验证的前向诊断”与“结构感知的后向细化”耦合，使技能的任务能力与其累积结构共同进化？
- **整体意义**：作者提出 SkillProx，一个受近端梯度（proximal gradient descent）启发的正向-反向框架，旨在实现更可靠、更可维护的技能自我进化，使技能不仅“更长”，而且“更优”。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

### 2.1 核心思想

- 将技能进化形式化为一个复合优化问题：
  \[
  \min_{X\in\mathcal{X}} J_\lambda(X) := L_T(X) + \lambda G(X)
  \]
  其中 \(L_T\) 是任务损失，\(G(X)\) 是技能文本复杂度（字符数），\(\lambda\) 平衡两者。论文指出这是概念目标，而非直接优化的损失。
- 借鉴近端梯度下降的“前向梯度步 + 后向近端步”分工：前向阶段负责改进任务性能（诊断进化），后向阶段负责控制技能结构与复杂度（近端收缩）。
- 两个关键设计原则：
  1. **前向**：更新不能仅凭诊断文本判断，必须通过在同一任务批次上重新执行来验证实际效果。
  2. **后向**：累积知识可按单元审计，移除负效用内容可以提升准确率（如案例中 46%→54%）。

### 2.2 关键技术细节

- **前向闭环更新（Closed-Loop Forward Update）**：
  - 在每轮迭代 \(k\)，用当前技能 \(X_k\) 在训练批次 \(B_k\) 上执行，诊断器根据失败轨迹、对比成功轨迹、历史记录和上次拒绝原因提出编辑方向。
  - 补丁器生成候选技能 \(\tilde{X}^{(j)}_k\)，并在**同一批次**上重新执行，用门控函数决定是否接受：
    \[
    \text{Gate}_{\text{fwd}}(\tilde{X}^{(j)}_k) = \mathbf{1}[H_{B_k}(\tilde{X}^{(j)}_k) \ge H_{B_k}(X_k)] \cdot \mathbf{1}[C_{B_k}(\tilde{X}^{(j)}_k) \ge C_{B_k}(X_k)]
    \]
    其中 \(H\) 为硬准确率，\(C\) 为平均单元格准确率。
  - 若候选有严格硬准确率提升则提前终止；否则最多尝试 3 次，选择按硬/单元格准确率字典序最优的候选，但必须满足门控条件，否则保持原技能。
  - 拒绝的尝试会将观察到的准确率变化和尝试方向反馈给下一次诊断，形成跨迭代的接受/拒绝语义历史。

- **后向近端细化（Prox）**：
  - 将前向得到的 \(X_f\) 解析为 \(n\) 个可审计知识单元（L2 章节和 L3 引用组）。
  - 用**冻结的留一法效用审计**计算每个单元 \(q_i\) 的边际效用：
    \[
    u_i^{\text{hard}} = H_V(X_f) - H_V(\text{Ablate}(X_f, q_i)),\quad
    u_i^{\text{cell}} = C_V(X_f) - C_V(\text{Ablate}(X_f, q_i))
    \]
  - 候选集按单元格效用升序排序：\(I_\tau = \{i : u_i^{\text{cell}} < \tau\}\)，默认 \(\tau = -0.001\)，按 \((u_i^{\text{cell}}, u_i^{\text{hard}})\) 字典序处理。
  - **验证门控的收缩**（Shrink）：
    - 对每个候选，在临时副本上执行整合（consolidate）、降级（demote）或移除（remove）操作。
    - 必须满足结构性有效和严格复杂度降低（式 9）。
    - 在固定验证集 \(V\) 上评估，要求硬准确率不降（\(\delta_h = 0\)），单元格准确率最多降 0.02（\(\delta_c = 0.02\)），且累计压缩率不超过软上限 \(\rho = 0.10\)（式 10）。
  - 只接受通过全部门控的编辑，否则丢弃；处理完所有候选后得到最终技能 \(X^\star\)。

- **实现层面**：
  - Prox 候选集有限，每个候选至多处理一次，因此有限终止。
  - 每次接受的编辑严格减少文本复杂度，验证门控保证记录在案的验证性能不降。
  - 论文强调 \(\tau\) 是效用阈值而非显式正则化权重 \(\lambda\)，\(\tau\) 扫描给出的是经验压缩-性能折中曲线。

## 6. 论文的主要结论与发现

- **SkillProx 一致改进基础技能**：在所有骨干上均将 Human Skill 基础技能转化为净正向信号；例如 Qwen3.5-27B 从 38.3 提升到 51.3，Qwen3.6-27B 从 36.7 提升到 54.5。
- **IID 最强**：在 SpreadsheetBench 上，SkillProx 在三个骨干上都取得最佳准确率，且方差低于多数自进化基线。
- **OOD 稳健**：在 WikiTQ 和 HiTab 上，SkillProx 大多为最佳或极具竞争力；相比之下 SkillOpt 在 OOD 上严重退化（如 4B 模型上 WikiTQ 26.0、HiTab 16.0）。
- **消融结论**：去掉闭环诊断降低 1.5 pp，去掉 Prox 降低 2.5 pp，说明前向闭环验证与后向近端收缩互补，且 Prox 对控制冗余和任务特定内容更为关键。
- **压缩-性能折中**：在 \(\tau=-0.001\) 附近，Prox 可在保持甚至提升准确率的同时压缩 25.7% 的技能文本；压缩超过约 80% 后性能开始下降。
- **模型规模影响**：小模型（4B）最终技能约比大模型（27B）长 45%，差异主要来自引用文件；更大模型本身更善于产生选择性、紧凑的技能，而闭环验证和 Prox 为小模型提供了外部更新筛选机制。
- **机制层面**：闭环门控会选择“可证伪”的编辑（其行为后果可立即观测），避免不可操作的元指令积累；Prox 能识别并整合负效用冗余单元，提升验证准确率与 OJ 硬准确率（案例中 46%→54%）。

## 7. 优点：方法或实验设计上的亮点

- **问题定义清晰**：将技能进化形式化为“任务性能 + 复杂度”的复合优化，并在近端梯度框架下给出前向/后向分工的概念基础。
- **闭环前向设计**：首次将“重新执行验证 + 回滚 + 拒绝反馈”纳入技能诊断循环，使诊断过程能根据实际结果自适应进化，而非仅依据语义合理性。
- **后向效用审计与验证门控**：将技能拆分为可审计单元，用留一法估计边际效用，并通过验证门控决定整合、降级或删除，实现了“知识整合”而非单纯增删。
- **实验充分且坦诚**：主实验、消融、阈值扫描、10 种子分析、案例研究互相支撑；论文明确区分了描述性关联与因果证据，给出了严谨的限定（如相关性受数学耦合影响、案例研究是观察性的）。

- **OOD 覆盖有限**：仅两个表格问答数据集，且都是类似表格领域；对更广泛的技能迁移场景（如代码、多跳推理、交互式环境）缺乏验证。

- **指标未完全对齐**：主实验的“accuracy”定义未在正文详述，部分关键指标（如 mean cell accuracy 的归一化、OJ 协议）散落在附录中，影响可读性。
- **τ 与 λ 的关系是近似的**：论文承认 \(\tau\) 只是正则化强度的单调代理，并非显式权重；\(\tau\) 扫描不能精确等价于正则化路径。
- **案例研究的推断力有限**：两组案例研究复用同一 seed，且 seed 8 同时是最弱 open-loop 运行和最大增益点，作者也指出不能外推为平均效应；OOD 上技能是独立生成，无法严格归因于某个编辑。
- **压缩软上限可能被突破**：\(\rho=0.10\) 是软停止条件而非硬约束，最终压缩率可能显著超过 10%（实验中达到 25.7% 甚至更高），实际行为可能与设计意图有偏差。
