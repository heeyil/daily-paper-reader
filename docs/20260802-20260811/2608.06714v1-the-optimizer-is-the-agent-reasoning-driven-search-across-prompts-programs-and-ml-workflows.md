## 摘要
近期用于优化提示、程序和机器学习工作流的系统通常依赖显式的外层循环控制器，如进化搜索、多臂老虎机或文本梯度方法。我们提出了一个根本不同的问题：这种搜索策略有多少可以被一个单一的工具使用智能体内化？我们提出了ReASearch，一个统一的推理驱动优化框架，其中智能体自主决定评估什么、如何诊断失败、进行哪些编辑以及何时验证或重启。该智能体不仅仅作为由手工设计启发式引导的提议生成器，而是主动分析结果、分配预算，并通过持久内存在长时间跨度内完善其策略。通过共享的智能体循环和领域特定工具，ReASearch用完全相同的脚手架来优化提示、程序和机器学习工作流。在14项多样化任务中，它与专用优化系统相比具有竞争力，并且大多优于它们，在强领域特定基线上获得了2%到40%的提升，在某些情况下还发现了改进先前人类最佳已知结果的解决方案。至关重要的是，我们观察到，通常由显式控制器实现的复杂搜索行为，会自然地从智能体的推理过程中涌现。

## Abstract
Recent systems for optimizing prompts, programs, and ML workflows typically rely on explicit outer-loop controllers such as evolutionary search, bandits, or textual-gradient methods. We ask a fundamentally different question: how much of this search policy can be internalized by a single tool-using agent? We present ReASearch, a unified framework for reasoning-driven optimization in which the agent autonomously decides what to evaluate, how to diagnose failures, which edits to make, and when to verify or restart. Rather than serving only as a proposal generator guided by hand-designed heuristics, the agent actively analyzes outcomes, allocates budget, and refines its strategy over long horizons through persistent memory. With a shared agent loop and domain-specific tools, ReASearch instantiates the exact same scaffold to optimize prompts, programs, and ML workflows. Across 14 diverse tasks, it is competitive with and mostly better than specialized optimization systems, achieving gains of 2% to 40% over strong domain-specific baselines, and in some cases discovering solutions that improve on prior human best-known results. Crucially, we observe that complex search behaviors, which are typically implemented by explicit controllers, emerge naturally from the agent's reasoning process.

- 提出 Reasoning-driven Agentic Search（ReASearch），一个"无控制器"（controller-light）的统一框架：核心优化操作全部打包为工具，由 LLM 智能体自主编排搜索过程。
- 与既有方法的本质区别：候选分支选择、评估预算分配、停滞恢复等策略不再由外部算法硬编码，而是从智能体的推理过程中涌现。

## 3. 实验设计

**三大领域、14 项任务**，统一智能体脚手架，仅更换领域工具与系统提示；每项设置做 3 次独立运行取平均。

**提示优化（4 项任务）**
- 数据集：AIME 2025、GSM8K、HotpotQA、Terminal-Bench 2.0。
- 学生模型：GPT-4.1 mini（AIME、HotpotQA）、Llama 3.1-8B（GSM8K）、GPT-5（Terminal-Bench 2.0）；优化器模型为 Claude Sonnet 4.6。
- 对比方法：GEPA（最新提示优化算法），控制学生模型调用次数一致。
- 结果：ReASearch 全面优于 GEPA——AIME 52.00 vs 50.67、GSM8K 83.40 vs 82.11、HotpotQA 67.60 vs 65.80、Terminal-Bench 53.33 vs 42.22（提升约 2%–26%）。

**程序进化（5 类任务）**
- 数据集/场景：圆填充（n=23–32）、Heilbronn 三角形（n=11–15）、事务调度 TXN、专家并行负载均衡 EPLB、ARC-AGI-2 视觉推理。
- 对比方法：AdaEvolve（另有 GEPA、Shinka 作为 TXN/EPLB 对比）；预算控制为相同的评估器调用次数（圆/Heilbronn 每 n 上限 500，ARC 每谜题 100，EPLB/TXN 500）。
- 结果：几乎所有任务最优；圆填充 n=32 达到 2.940，超越人类已知最优 2.939；Heilbronn n=12 达 0.03260 持平人类最优、n=14/15 接近人类最优；ARC-AGI-2 测试准确率 50.0% vs AdaEvolve 12.5%（4 倍差距）；EPLB 0.2305 vs AdaEvolve 0.1976。

**ML 工作流优化（5 项任务）**
- 场景：NanoGPT 语言建模（BPB）、IMG-100 图像分类、Atari Q*bert 与 MuJoCo 强化学习、DRW 加密市场预测 Kaggle 竞赛。
- 对比方法：Claude Code（AutoResearch 官方配置，指令内容匹配，仅对齐墙钟预算），训练脚本、数据管线、评估器、硬件、单次实验训练上限均相同。
- 结果：NanoGPT 持平（0.976 vs 0.974）；IMG-100 83.99 vs 78.59、Atari 4500 vs 1250、MuJoCo 5267 vs 3986、Crypto 相关 0.1110（排名从 36 升至第 6）vs 0.0999（第 29），且 token 消耗远低于 Claude Code。

**消融与扩展实验**
- 组件消融：去除记忆机制 / 去除 Python 执行工具（AIME、Terminal-Bench、ARC-AGI-2、Heilbronn）。
- 记忆设计：简单三段式 schema（what worked / what did not / what to try next）足够且可跨运行迁移（NanoGPT 经验迁移使新运行起点从 0.998 提升至 0.977）。
- 验证反馈粒度：仅暴露聚合指标优于逐样本轨迹（AIME 52% vs 约 50%）。
- 开源骨干：GLM-5、Kimi-2.5 在多数任务上接近 Claude Sonnet 4.6。

## 6. 主要结论与发现

- **统一框架有效性**：同一智能体脚手架在 14 项任务上与专用优化系统竞争力相当且多数更优，提升幅度 2%–40%，部分场景发现超越人类已知最优解（圆填充 n=32）。
- **搜索行为涌现**：复杂优化行为无需硬编码即可自然涌现——包括：对候选收益的双重验证、复用相似失败经验、在无效分支后刻意回退、方差感知与过拟合检测（"领域特定添加即使提升训练也损害验证泛化"）、在预算约束下自适应探索、基于完整历史而非最高分数选择最终提示。
- **关键能力来源**：持久记忆使智能体具备因果诊断（EPLB 定位捐赠约束瓶颈）、数学抽象（Heilbronn D4 对称性将 24 维降至 2 参数并 50 位精度求解）、复合算法迭代发现（圆填充将线性规划嵌入随机位置搜索）等能力。
- **工具调用的时间分配特征**：提示/程序优化中 70%+ 的工具调用用于 Python 推理而非执行；ML 工作流中 Python 占比相对低但仍关键。
- **普遍性**：性能随骨干模型能力扩展，开源模型亦能复现大部分收益。

- 扩展至更多优化领域（如超参数搜索、神经架构搜索、科学假设发现），检验“推理即优化”的普适性。
- 考虑混合架构：保留轻量级外部控制器作为安全兜底，同时允许智能体内化大部分搜索决策，平衡鲁棒性与灵活性。

## 10. 总结与个人评价

ReASearch 是一项具有范式启发意义的工作，成功展示了“搜索策略内化为智能体推理”的可行性，并以统一脚手架在提示优化、程序进化、ML 工作流三大领域取得了有竞争力的结果，部分场景甚至超越人类已知最优。其核心贡献在于概念简洁、通用性强、成本可控，开启了将 LLM 从“变异器”升级为“优化引擎”的新方向。然而，论文在统计严谨性、计算公平性披露和理论深度方面仍有明显提升空间，部分结论需要更多重复实验与消融支撑。整体上，这项工作为未来智能化优化系统提供了重要的研究与工程思路，值得关注其后续发展。
