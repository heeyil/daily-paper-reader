## 摘要
长时程LLM智能体需要记忆系统从大规模交互历史中恢复有用的证据，而不向下游模型传递过多上下文。现有的记忆流程通常依赖手工设计的启发式规则和重复的LLM调用，这可能会引入冗余上下文和高推理成本。我们提出MemoryCPT，一个端到端可训练的智能体记忆流程，涵盖离线记忆构建和在线查询条件下的上下文生成。MemoryCPT由两个阶段组成：查询无关蒸馏（QAD），利用显式推理轨迹将模块化记忆构建流程蒸馏为紧凑模型；以及查询感知检索与摘要（QAR），将倒数排名融合（RRF）与基于LoRA的摘要器相结合，该摘要器通过成本感知奖励下的组相对策略优化（GRPO）进行训练。我们进一步引入单位成本质量（QPC）以量化每单位推理成本下的答案质量。在LoCoMo和LongMemEval上的实验表明，相较于评估的基线方法，MemoryCPT改善了成本-性能权衡，同时消融和敏感性分析刻画了其组件的贡献和关键设计选择的影响。

## Abstract
Long-horizon LLM agents require memory systems that recover useful evidence from large interaction histories without passing excessive context to downstream models. Existing memory pipelines often rely on hand-crafted heuristics and repeated LLM calls, which can introduce redundant context and high inference cost. We propose MemoryCPT, an end-to-end trainable agent memory pipeline that spans offline memory construction and online query-conditioned context generation. MemoryCPT consists of two stages: Query-agnostic Distillation (QAD), which distills a modular memory-construction pipeline into a compact model using explicit reasoning traces; and Query-aware Retrieval and Summarization (QAR), which combines reciprocal rank fusion (RRF) with a LoRA-based summarizer trained via Group Relative Policy Optimization (GRPO) under a cost-aware reward. We further introduce Quality per Cost (QPC) to quantify answer quality per unit inference cost. Experiments on LoCoMo and LongMemEval show that MemoryCPT improves the cost-performance trade-off over the evaluated baselines, while ablation and sensitivity analyses characterize the contributions of its components and the effects of key design choices.

## 2. 方法论

### 2.1 总体框架

MemoryCPT将记忆系统 \( f_{mem} \) 实例化为两个可训练阶段：

\[
M = f_{QAD}(H), \quad m_q = f_{QAR}(q, M)
\]

- **离线阶段（QAD）**：将原始对话历史 \( H \) 蒸馏为可复用的情景记忆（episodic memory）和语义记忆（semantic memory）库 \( M = M_{ep} \cup M_{sem} \)。
- **在线阶段（QAR）**：对用户查询 \( q \)，先从记忆库中检索候选记忆，再压缩为紧凑的查询条件摘要 \( m_q \)，最终由冻结的QA模型 \( f_{ans} \) 生成答案。
- 下游QA模型（Qwen3-14B）在训练和推理中保持冻结。

### 2.2 查询无关蒸馏（Query-agnostic Distillation, QAD）

**核心思想：** 将教师的模块化记忆构建能力蒸馏进紧凑的学生模型，且学习对象是"推理轨迹+结构化输出"而非仅最终摘要。

**关键技术细节：**
- 教师管线包含四个角色：**BatchSegmenter**（对话分段）、**EpisodeGenerator**（情景记录生成）、**EpisodeMerger**（情景合并）、**SemanticExtractor**（语义知识提取）。
- 教师输出采用"推理过程（\<think\>标签内）+ 可执行JSON"格式，提供显式推理监督。
- 相邻教师调用被合并为单次学生预测以降低推理开销；目标序列 \( z = r \oplus y \)（推理+输出），采用标准因果语言建模损失：

\[
L_{QAD} = -\mathbb{E}_{(x,r,y) \sim D_{QAD}} \sum_{t=1}^{|z|} \log p_\theta(z_t \mid z_{<t}, x)
\]

- 学生模型为Qwen2.5-7B-Instruct或Llama-3.2-3B，附加LoRA适配器（LoRA-A），训练后合并为独立模型 base_A。

### 2.3 查询感知检索与摘要（Query-aware Retrieval and Summarization, QAR）

**核心思想：** 先用检索限定候选集，再用强化学习训练的摘要器生成查询条件的紧凑摘要，显式优化质量-成本权衡。

**关键技术细节：**
- **RRF检索融合**：稠密检索（Qwen3-Embedding）与稀疏检索（BM25）分数尺度不同，采用倒数排名融合（Reciprocal Rank Fusion）：

\[
s_{RRF}(m; q) = \sum_{r \in \{dense, sparse\}} \frac{1}{k_{rrf} + rank_r(m \mid q)}
\]

默认检索深度为top-20情景记忆 + top-50语义记忆， \( k_{rrf}=60 \)。

- **策略建模**：将QAR训练建模为上下文赌博机（contextual bandit）问题。状态 \( s_q = (q, M^{RRF}_q) \)，动作是摘要词元序列 \( m_q \sim \pi_\phi(\cdot \mid s_q) \)。LoRA-B在base_A之上训练。
- **GRPO优化**：使用组相对策略优化，最大化奖励并加入KL散度正则：

\[
\max_\phi \mathbb{E}_q \mathbb{E}_{m_q \sim \pi_\phi(\cdot \mid s_q)} [R(q, m_q)] - \beta D_{KL}(\pi_\phi \| \pi_{ref})
\]

- **成本建模**：训练期成本代理为：

\[
C(q, m_q) = |m_q|(p^{out}_{7B} + p^{in}_{14B}) + |\hat{y}| p^{out}_{14B}
\]

并以 \( C_{ref} \) 裁剪归一化至[0,1]。

- **奖励设计**：

\[
R(q, m_q) = \alpha \cdot F1(\hat{y}, y^*) + (1-\alpha) \cdot (1 - \tilde{C}(q, m_q))
\]

默认 \( \alpha = 0.8 \)。选择加权和而非直接优化比值 QPC=F1/Cost，以保证数值稳定。

### 2.4 端到端训练流程

1. 教师管线产生角色级推理轨迹和结构化JSON输出；
2. 构造单轮SFT数据训练LoRA-A（QAD阶段）；
3. 合并LoRA-A得到base_A，离线构建记忆库；
4. 对每个训练查询执行RRF检索，用GRPO训练LoRA-B（QAR阶段）。

推理阶段仅三步：RRF检索 → LoRA-B生成摘要 → 冻结QA模型生成答案。

## 5. 主要结论与发现

1. **MemoryCPT在成本-性能权衡上全面超越基线**：
   - 在LoCoMo+Qwen-2.5-7B配置下，F1达0.479（较BudgetMem提升约28%），Cost仅3.46（较BudgetMem下降约86%），QPC达0.138（约为BudgetMem的9倍）。
   - 在LongMemEval上同样取得最优QPC（0.085）。

2. **QAD是"质量放大器"**：引入少量离线成本，但大幅改善下游记忆质量（F1 +0.109，Judge +0.172）。

3. **QAR是"成本控制器"**：查询感知压缩使成本降低约69%，同时F1和Judge不降反升。

4. **Fine Summary（FS）在保留语义正确性的同时大幅提高成本效率**：去掉FS后Cost从3.46升至8.35，QPC从0.138降至0.053。

5. **α=0.8是最优权衡点**：过大的α导致冗余摘要（成本增加但F1提升有限），过小的α导致过度压缩（关键证据丢失）。

6. **检索深度20/50是最优**：8/20处已恢复约96%的峰值F1，20/50处达最优质量；增至32/80后噪声引入反而下降。

7. **成本摊销分析**：离线构建成本在50+查询后降至约$6×10⁻⁴/QA，接近在线下界，验证了离线/在线分离的设计合理性。

## 6. 优点

1. **端到端可训练的记忆管线**：不同于现有方法依赖手工提示词和启发式规则，MemoryCPT将记忆构建和摘要策略显式编码到模型参数中。
2. **两阶段分离设计巧妙**：离线构建（QAD）与在线提取（QAR）解耦，缩小RL动作空间，使RL训练切实可行；LoRA-A与LoRA-B各司其职，互不干扰。
3. **推理轨迹蒸馏**：通过"think+JSON"格式监督中间决策（何时分段、合并、抽象），而非仅监督最终摘要，学习目标更细腻。
4. **奖励设计务实**：使用F1而非LLM judge作为训练奖励（连续、可计算、密集反馈）；加权和代理（而非直接优化QPC比值）避免训练不稳定；成本归一化裁剪保证量纲一致。
5. **QPC指标的提出**：为记忆系统的成本-性能评估提供了统一、可复现的度量标准。
6. **统一的评估协议**：冻结QA模型、统一价格表、统一prompt，使不同记忆系统间的比较公平且可复现。
7. **实验覆盖面较全面**：主实验、消融、敏感性、分类别分析和成本摊销分析构成了多维度的验证体系。

## 7. 不足与局限

1. **基准覆盖有限**：仅涉及LoCoMo和LongMemEval两个多轮对话记忆基准，未涵盖其他重要场景，例如：工具调用型agents的长期记忆、多模态记忆、跨任务持续学习、真实生产环境日志。结论的泛化性有待验证。

2. **数据规模与统计可靠性**：
   - LongMemEval的测试集仅有105个问题，其中SS-Pref子类仅6个问题，在该子类上MemoryCPT与基线均表现极差（F1约6.1%），统计意义较弱。
   - 未报告多次独立运行的标准差或显著性检验，结论可能受单次运行随机性影响。

3. **成本模型的简化**：
   - 价格表基于特定API定价，不同提供商价格结构不同，绝对Cost数值可能不具普遍性。
   - 训练成本（GPU算力、SFT/GRPO训练电费）未被纳入成本计算，仅考虑了推理成本。
   - 变量成本代理排除了检索成本（认为在GRPO优势估计中抵消），但检索本身在真实系统中也可能成为显著开销。

4. **评估指标的限制**（续）：

5. **训练信号与推理部署的潜在不一致**：
   - QAD阶段将教师（DeepSeek-V3）的"think+JSON"推理轨迹蒸馏进7B/3B学生，但教师与学生能力差距显著，学生可能无法完整复现教师的决策逻辑；论文未报告蒸馏后学生输出与教师输出的结构/内容一致性指标（如JSON格式合规率、分段/合并决策匹配率）。
   - QAR阶段使用7B/3B模型生成摘要、14B QA模型消费摘要，二者未联合优化；学生摘要器规模的缩放规律（scaling law）未被探索。

6. **记忆类型的覆盖缺口**：
   - 仅涵盖情景记忆（episodic）和语义记忆（semantic），未涉及程序性记忆（procedural memory，即技能性/操作性知识），在工具调用、技能学习型智能体中该类型记忆至关重要。
   - 缺乏记忆时效性衰减与冲突消解机制：当用户偏好随时间改变或新旧记忆矛盾时，系统缺乏显式的遗忘/更新策略，相关场景（LongMemEval的Knowledge Update类）表现未单独分析。

7. **上下文规模的泛化存疑**：
   - 两个基准的平均上下文仅约8–9K tokens，远低于真实长时程智能体的典型规模（如数百K至百万tokens）。在极长历史下，离线构建的记忆库规模会急剧膨胀，检索延迟、离线构建成本、记忆冗余度等关键指标如何变化，论文未做压力测试。

8. **部署层面的未量化成本**：
   - 未报告在线阶段的端到端延迟（尤其RRF稠密+稀疏双路检索在大规模记忆库中的耗时）和峰值内存占用；
   - 训练成本仅以抽象形式提及（GPU数量、步数），未给出总GPU小时数、电费或云端费用估算，外部读者难以复现或横向比较训练开销。

## 8. 未来工作方向

基于论文的局限，可预见如下扩展方向：

1. **扩展到更长上下文与更多场景**：在百万token级记忆库、工具调用型agent、多模态对话历史等场景下验证MemoryCPT的泛化能力。
2. **联合优化QAD与QAR**：将离线构建与在线压缩纳入同一优化目标，探索真正端到端的记忆策略学习（如将构建策略也参数化并纳入RL动作空间）。
3. **自适应检索与压缩**：根据查询复杂度动态调整检索深度、摘要长度和是否需要多轮检索，进一步逼近成本-质量帕累托前沿。
4. **记忆冲突消解与遗忘机制**：引入时间衰减权重、版本化记忆或基于用户反馈的记忆修正机制，处理偏好漂移与知识过期问题。
5. **更强蒸馏与模型缩放分析**：尝试更大规模学生模型、更紧凑的推理轨迹表示（如结构化思维链），量化蒸馏损失与学生规模的关系。
6. **标准化评估套件**：在更多基准上统一报告QPC、延迟、训练成本和统计显著性，推动记忆系统评估的标准化。

## 9. 个人综合评价

这是一篇**工程完整度高、问题定义清晰、实验设计规范**的实证研究。其核心贡献不在于提出全新理论，而在于将"记忆构建 + 查询条件压缩"统一为端到端可训练管线，并首次将成本-质量权衡显式纳入目标函数与评估指标。QAD的推理轨迹蒸馏和QAR的GRPO优化形成互补——前者提升记忆质量，后者控制在线成本，两阶段分离亦规避了RL在高维动作空间中的训练困难。

**值得肯定之处**：QPC指标简洁有力，统一评估协议为后续研究树立了可复现的标杆；消融与敏感性分析扎实，结论可信度高；成本摊销分析展现了工程直觉。

**需要警惕之处**：基准规模偏小、成本模型简化、统计检验缺失，使结论的稳健性尚待更大范围验证；F1作为训练奖励的机械性可能限制了摘要的语义多样性。总体而言，该工作为长时程记忆系统的"效率-质量"权衡提供了有价值的参考框架，适合作为该方向的基线方法，但其工业部署价值仍需在真实长上下文中进一步检验。
