## 摘要
长程智能体依赖记忆来复用经验，然而现有的记忆系统通常假设证据可以通过固定表示直接消费。这导致了表示不匹配，即相关信息存在但未针对当前决策进行组织。为此，我们提出了MemPrism，一个任务条件关系记忆框架，将持久经验存储与决策时的工作记忆分离。MemPrism将交互记录为事件流，并根据当前任务上下文动态构建关系视图。一个轻量级视图策略选择关系结构、证据范围、结果条件和粒度，而一个确定性组合器和渲染器将历史事实转换为冻结任务策略的临时光学工作记忆视图。在长程具身和Web智能体基准上的实验表明，MemPrism持续提升了任务性能，尤其是在轨迹变长时，同时减少了记忆令牌消耗。此外，学习到的视图策略无需额外适应即可跨不同的VLM迁移，展示了任务条件关系视图作为通用智能体记忆接口的有效性。

## Abstract
Long-horizon agents rely on memory to reuse experiences, yet existing memory systems often assume that evidence can be directly consumed through a fixed representation. This leads to representation mismatch, where relevant information is available but not organized for the current decision. To this end, we propose MemPrism, a task-conditioned relational memory framework that separates persistent experience storage from decision-time working memory. MemPrism records interactions as the event stream and dynamically constructs relational views according to the current task context. A lightweight view policy selects the relation structure, evidence range, outcome condition, and granularity, while a deterministic composer and render transform historical facts into a temporary optical working-memory view for a frozen task policy. Experiments on long-horizon embodied and web-agent benchmarks show that MemPrism consistently improves the task performance, especially as trajectories become longer, while reducing memory token consumption. Furthermore, the learned view policy transfers across different VLMs without additional adaptation, demonstrating the effectiveness of task-conditioned relational views as a general memory interface for agents.

- **研究背景**：长程智能体（如基于 LLM/VLM 的 Web 导航、软件工程、具身交互等任务）依赖记忆系统来复用历史经验，其轨迹往往跨越数十甚至上百个决策步骤。
- **核心问题**：论文指出现有记忆系统普遍存在一个隐含假设——**证据一旦被存储和检索，就可以通过固定表示直接供策略消费**。然而，同一段历史事实对不同决策可能需要完全不同的组织方式（如时间线、状态表、动作-效果视图、依赖链），固定表示会导致 **表示不匹配（representation mismatch）**：相关信息已被检索，却未按当前决策所需的关系形式组织，最终导致决策失败。
- **关键观察**：成功的长程记忆不仅取决于“存什么、取什么”，还取决于“**如何呈现**”——持久记忆应保存稳定可复用的事实，而工作记忆须为当前决策动态构建。其核心研究问题为：*访问到正确的证据，是否就能保证它对当前决策有用？*
- **意义**：论文将“表示不匹配”从存储失败与检索失败中单独区分出来，将其定位为长程智能体决策的一类独立瓶颈，并据此提出相应的解决框架。

## 2. 论文提出的方法论

### 2.1 总体框架

MemPrism 将**持久经验存储**与**决策时的工作记忆**分离，包含五个模块：Recorder（记录器）、Router（路由器）、Composer（组合器）、Render（渲染器）和 Adapter（适配器，仅训练时使用）。

### 2.2 核心流程

1. **Recorder（持久事件流）**：将所有真实交互以统一事件流存入持久记忆。原始事件为 \( e_t = (o_t^-, u_t, y_t^+, r_t, m_t) \)，经事件提取器 Φ 和规则校验映射为结构化事件 \( \tilde{e}_t = (t, e_t^{ent}, e_t^{act}, e_t^{out}, \Delta s_t, \xi_t) \)，包含主实体、归一化动作类型、结果类型（异常/状态更新/无变化）、稀疏状态更新集和可选证据。
2. **Router（视图策略）**：根据当前观测、任务目标、近期事件特征与全局历史统计，从 144 个联合视图动作 \( (τ, w, c, γ) \) 中选择一个，其中：
   - 关系类型 τ ∈ {时间线、动作效果、实体状态、依赖链}
   - 时间范围 w ∈ {近期 6 步、近期 10 步、全部}
   - 结果过滤 c ∈ {全部、异常、状态更新、无变化}
   - 粒度 γ ∈ {粗、中、细}
   - 采用联合动作头以保持四个因子间的依赖关系，评估时用贪心 argmax 选择。
3. **Composer（关系构建）**：按所选动作，先以时间范围和结果过滤条件选择事件，再恢复任务相关事件（防止严格过滤丢失关键证据），最后构建关系特定结构：
   - **时间线**：按时间排序，展示动作顺序与任务进展
   - **动作效果**：按动作类型与实体分组，对齐重复动作与结果，便于检测失败循环
   - **实体状态**：按实体与状态键分组的时序状态链
   - **依赖链**：以最新事件为锚点，链接共享实体/状态键/邻近时间的相关事件（显式声明为启发式依赖痕迹，非因果图）
4. **Render（光学工作记忆）**：将关系结构用**确定性视觉语法**渲染为临时光学视图——空间邻近表示分组、行列对齐支持状态比较、箭头表示状态变化/依赖、高亮标记失败与任务相关证据。该视图仅供当前步骤使用，**绝不写回持久记忆**。
5. **冻结任务策略**（如 Qwen2.5-VL-7B-Instruct）读取当前环境输入与光学视图，产生环境动作。**只有执行的动作与环境反馈会追加到事件流**。

### 2.3 视图策略学习（Adapter）

- **阶段一：决策条件初始化（SFT）**。用视图教师基于当前观测、任务目标、事件历史与参考下一动作产生软标签分布，通过 KL 散度 + 结构成本正则项初始化 Router。
- **阶段二：结果引导优化（分组 GRPO）**。在同一任务的 G 条轨迹构成一个组，将组内归一化的轨迹优势赋予该轨迹内所有视图决策；仅更新 Router，任务策略、提取器、组合器、渲染器与参考视图策略全部冻结，从而**隔离视图选择本身的因果效应**。

### 3.2 对比方法

## 6. 论文的主要结论与发现

- **表示不匹配是真实瓶颈**：在证据完全相同时，不同关系视图导致成功率从 30.00% 到 35.71% 不等，动态选择进一步达到 40.71%，直接验证“右证据 + 错误组织 = 决策失败”。
- **动态组织与光学呈现互补**：光学呈现独立贡献 3.57 个点，动态组织贡献 5.00 个点，二者结合最佳。
- **自适应粒度最重要**：在四个视图因子中，固定细粒度导致最大性能下降（-7.84 点），固定视图类型次之（-4.99 点）。
- **长轨迹优势放大**：轨迹 ≤5/10 步时 MemPrism 略逊于 Full History，但在 ≥15 步后反超并持续扩大，≤50 步时领先 9.3 个点。
- **令牌效率显著**：随轨迹变长，Full History 提示词近线性增长（≤50 步 1,201 token），MemPrism 保持在 642–852 token 之间，50 步时减少 33.6% 令牌且 SR 更高。
- **视图策略可跨 VLM 迁移**：同一规划器零适配应用于 Qwen3-VL-4B、Qwen2.5-VL-3B、MiniCPM-V-2.6 均提升成功率，同时减少 30.6%–48.1% 提示 token。

## 7. 优点

- **问题定义清晰**：首次明确区分“表示不匹配”与存储/检索失败，将其形式化为工作记忆决策问题，概念贡献突出。
- **解耦设计**：持久事件流（真实、不可变）与临时工作视图（按需、可弃）分离，避免固定摘要与反复压缩造成的信息失真，架构思想简洁有力。
- **光学视图空间**：把二维布局作为语义编码手段（邻近=分组、箭头=依赖、高亮=异常），使光学记忆不仅是压缩媒介，更是关系表达接口。
- **训练目标隔离**：两阶段学习（SFT 教师初始化 + 在线 GRPO）只训练视图策略，冻结任务策略与其余模块，使性能提升能直接归因于记忆表示接口，实验逻辑严谨。
- **公平的基线处理**：使用官方实现、共享任务策略、明确排除需联合训练的 RL 光学系统，并公开复现性清单，整体实验规范度高。
- **实际收益明显**：在三个不同模态/难度的基准上一致提升，且长轨迹优势与跨模型迁移进一步验证了方法的通用性。

## 8. 不足与局限

- **绝对性能仍较低**：Mind2Web 总体动作准确率仅 12.87%，EB-ALFRED 平均 SR 17.7%，与实用部署仍有较大差距。
- **子集故障未解释**：EB-ALFRED 的 Visual 子集上所有方法（含 MemPrism）均为 0% SR，论文未深入分析原因（如视觉观测分辨率、任务难度或基准封装问题）。
- **模型规模覆盖有限**：跨模型迁移实验全部为 4B–7B 级 VLM，未在更大模型（如 72B+）或 GPT-4V 级别闭源模型上验证。
- **DependencyChain 的实际作用存疑**：ALFWorld 上该视图类型在最终贪心选择中出现频率为 0%，其是否真的有用、如何被有效利用，缺少专门消融或案例分析（EB-ALFRED 案例中亦未展示依赖链的使用）。
- **Router 输入表征受限**：Router 当前仅使用文本嵌入（未使用 CLIP 图像嵌入），在高视觉依赖任务上的视图选择可能无法充分利用环境图像信息。
- **短时上下文为潜在瓶颈**：Router 的窗口统计仅覆盖最近 8 个事件、全局统计 64 个事件，在更长轨迹（数百步）中可能丢失更早的结构信息。
- **计算开销说明不足**：尽管论文报告了 token 与像素效率，但 Phi 提取器每次调用的额外延迟/成本、渲染延迟、视图策略推理开销等未与原基线（Full History）做完整端到端成本对比。
- **Mind2Web 评估方式局限**：教师强制回放（下一个状态总沿人类轨迹前进）与实际开放环境存在分布差异，可能高估或低估真实在线性能。
