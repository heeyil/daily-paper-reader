## 摘要
长时程LLM智能体越来越依赖外部执行支持来维护状态、跟踪进度、调用工具、验证结果以及跨交互重用经验。然而，有效的执行框架使用带来了两个耦合的挑战：从噪声交互轨迹形成状态，以及对外部状态访问的运行时控制。现有智能体通常通过提示、启发式规则或领域特定约定来处理这两者，使得外部工作空间及其使用策略需要手动设计。为解决这一问题，我们研究了执行框架策略学习问题，即智能体离线学习执行框架策略，并在运行时任务执行过程中在线部署这些策略来构建和更新外部执行框架状态。我们引入了EvoHarness-RL，它将信念（Belief）、进度（Progress）和经验（Experience）作为面向策略的执行框架状态暴露出来。监督式执行框架微调教会基础智能体执行框架的动作空间以及如何构建有用的外部状态，而成本感知的GRPO则探索协调策略，以在长时程交互中选择性地读取、更新和整合该状态。在ALFWorld上以Qwen3-8B LLM实例化后，EvoHarness-RL达到了96.9%的成功率，并揭示了两个关键动态：执行框架退火（harness annealing），即训练将反复出现的执行框架使用模式内化到模型策略中，使智能体从频繁调用执行框架转向选择性外部状态访问；以及执行框架进化（harness evolution），即进度更新和经验整合将执行框架精炼为紧凑的、任务自适应的状态基底。这些结果表明，长时程智能体受益于可训练的、用于构建和协调外部执行框架工作空间的策略，而不仅仅是增加更强的工具或更大的记忆。

## Abstract
Long-horizon LLM agents increasingly rely on external execution support to maintain state, track progress, invoke tools, verify outcomes, and reuse experience across interactions. However, effective harness use raises two coupled challenges: state formation from noisy interaction traces and runtime control over external-state access. Existing agents usually handle both through prompts, heuristics, or domain-specific conventions, leaving the external workspace and its usage policy manually engineered. To address this, we study the problem of harness policy learning, where agents learn harness policies offline and deploy them to construct and update external harness state online during runtime task execution. We introduce EvoHarness-RL, which exposes Belief, Progress, and Experience (BPE) as policy-facing harness state. Supervised harness fine-tuning teaches the base agent the harness action space and how to construct useful external state, while cost-aware GRPO explores coordination policies to selectively read, update, and consolidate that state during long-horizon interaction. Instantiated on ALFWorld with a Qwen3-8B LLM, EvoHarness-RL reaches 96.9% success and reveals two key dynamics: harness annealing, where training internalizes recurring harness-use patterns into the model policy and shifts the agent from frequent harness calls toward selective external-state access, and harness evolution, where progress updates and experience consolidation refine the harness into a compact, task-adaptive state substrate. These results suggest that long-horizon agents benefit from trainable policies for constructing and coordinating with external harness workspaces, beyond simply adding stronger tools or larger memories.

## 1. 核心问题与整体含义

- **背景**：长时程 LLM 智能体在交互式任务（如具身交互、Web 导航、软件工程、工作流自动化）中，越来越依赖外部执行支持来维护状态、跟踪进度、调用工具、验证结果和跨交互复用经验。这些外部支持组件（记忆、工具、状态追踪器、验证器、执行日志等）统称为“外部执行框架”（external harness）。
- **核心问题**：如何让智能体学会**构建**有用的外部状态，并**高效地协调**对这些状态的访问，这一“harness 策略学习”问题尚待解决。现有方法通常通过提示（prompt）、启发式规则或领域特定约定来管理 harness，因而是人工设计的。
- **两个耦合挑战**：
  1. **状态形成**：从噪声交互轨迹中形成有用的外部状态。
  2. **运行时控制**：决定何时、以何种代价访问外部状态。
- **整体含义**：作者主张长时程智能体不应只依赖更强的工具或更大的记忆，而应**训练可学习的 harness 策略**，将外部工作空间的使用从提示工程转变为策略决策的一部分。

## 2. 方法论

### 2.1 核心思想：BPE 统一外部状态抽象

- 将异构的外部 harness 组件抽象为三个策略面向的（policy-facing）功能角色，记为 `Ht = (Bt, Pt, Et)`：
  - **Belief (B)**：环境状态的持久化估计，如物体状态、位置、空间关系；
  - **Progress (P)**：任务分解与执行状态，通过子目标状态记录 `(gi, σi)` 外化已尝试、待办、受阻的进度；
  - **Experience (E)**：跨回合可复用知识，如技能、失败模式、搜索先验、高层策略。
- 动机：对应长时程交互中三类反复出现的失败模式——丢失环境信念、遗忘进度、反复发现本可复用的经验。

### 2.2 Agent-Harness 动作协议

- 定义紧凑的 harness 元动作集合：`Abpe = {track, commit, recall, note}`：
  - `track [object/world]`：从 Belief 读取信息；
  - `commit [subgoal]`：向 Progress 写入子目标/执行更新；
  - `recall [query]`：从 Experience 检索可复用知识；
  - `note [insight]`：将新经验写入 Experience。
- 策略每步从 `A = Aenv ∪ Abpe` 中选择动作：`at ~ πθ(·|ot, Ht, ct)`。两类动作消耗相同的交互预算，因此需要学习“何时访问 harness 是值得的”。

### 2.3 环境适配器

- BPE 是功能接口而非固定 schema：内部实现可领域特定，但策略面对的统一界面共享。
- ALFWorld 实例化：
  - Belief 通过基于规则的解析器维护世界状态，`track` 提供选择性查询；
  - Progress 为有界子目标状态列表，`commit` 外化执行步骤；
  - Experience 为跨回合技能库（通用技能、任务特定技能、常见错误、搜索先验），支持 `recall`/`note`，并在回合批次边界由汇总模型进行增删改/合并。

### 2.4 两阶段训练流程

1. **监督式 harness 微调（SFT）**：在教师轨迹（Claude Opus 生成）上微调 Qwen3-8B，学习动作格式和 harness 动作语义；同时初始化技能库。
2. **成本感知 GRPO**：从 SFT 检查点出发，优化奖励：
   `R(τ) = R_succ(τ) + λ_eff·R_eff(τ) + λ_div(u)·R_div(τ) − λ_spam·R_spam(τ) − λ_inv·R_inv(τ)`
   - `R_succ`：成功奖励（10），作为严格门控；
   - `R_eff`：效率奖励（仅成功时给予，惩罚冗余 harness 查询）；
   - `R_div`：随时间退火的词汇多样性奖励（鼓励早期探索 harness 动作，后期收敛）；
   - `R_spam`/`R_inv`：重复循环和格式错误的固定惩罚。

## 6. 主要结论与发现

- **性能**：EvoHarness-RL 在 Qwen3-8B 上达到 **96.9%**（seen）和 **86.6%**（unseen）成功率，相对基础 ReAct（47.9%）提升 +49.0，超越 SkillOS（80.2%）和 SkillRL（89.9%），并接近 Claude Opus 4.5（96.4%）。
- **BPE 普适性**：prompt-time 的 BPE harness 对前沿模型也有显著帮助（GPT-4.1 +22.1，GPT-5 +25.7），表明外化信念、进度、经验是长时程任务的通用需求。
- **动态一：harness 退火（harness annealing）**：训练中 harness 调用从频繁的脚手架式使用收敛到约每回合一次的选择性访问，说明 GRPO 将常规化的 harness 使用模式内化到策略中；不同动作衰减速度不同（`recall` 最持久，`commit`/`note` 快速衰减，`track` 居中）。
- **动态二：harness 进化（harness evolution）**：经验库在训练早期快速扩张，随后通过合并、淘汰和保留进入紧凑而多样化的稳定状态，形成任务自适应的状态基底，而非只追加的被动记忆。
- **整体结论**：长时程智能体应当训练可学习的 harness 策略来构造和协调外部工作空间，而非仅仅依赖更强的工具或更大的记忆。

## 7. 优点

- **统一抽象简洁有力**：BPE 三个角色和四个元动作覆盖了长时程交互的核心信息流，接口紧凑、可跨任务迁移。
- **将 harness 使用纳入可学习策略**：从人工提示/启发式转向显式的策略决策，是研究视角上的重要推进。
- **两阶段训练设计合理**：SFT 先建立动作空间语义，GRPO 再优化成本感知的协调策略，逻辑清晰、互补明确。
- **奖励函数设计有层次**：成功作为硬门控，效率、多样性、格式等辅助项共同防止策略坍缩（忽略 harness 或死循环）；时间退火的多样性权重是一种巧妙的课程学习策略。
