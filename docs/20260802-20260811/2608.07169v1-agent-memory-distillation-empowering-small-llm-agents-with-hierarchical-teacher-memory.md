## 摘要
记忆系统在提升智能体性能方面展现出潜力，但其在小语言模型中的潜力在很大程度上仍未得到开发，因为小模型自身难以生成足够多的成功轨迹。我们提出了智能体记忆蒸馏（AMD），一种无需训练的训练框架，通过分层记忆将结构化知识从大型教师智能体传递给小型学生智能体。AMD从成功的教师轨迹中构建三种互补的记忆类型：工作流记忆编码任务级策略，子任务记忆以中间粒度提供具体的行为示例，函数记忆捕获逐函数的调用约定和常见陷阱。工作流记忆和子任务记忆在每个任务开始时主动注入，而函数记忆则在工具调用错误时被动检索。我们在三个工具使用基准上使用四种学生模型（4B-8B参数）并以GPT-5-mini作为教师评估了AMD，在AppWorld、BFCL V3和ToolSandbox上分别实现了27.2个百分点、11.2个百分点和3.4个百分点平均准确率提升，同时始终优于现有的基于记忆的基线。进一步分析表明，子任务记忆贡献了最大的提升，教师有效性取决于教师能力和学生兼容性，而4B规模的学生从AMD中获益最多。

## Abstract
Memory systems have shown promise for improving agent performance, but their potential remains largely unexplored for small language models, which struggle to generate sufficient successful trajectories on their own. We propose Agent Memory Distillation (AMD), a training-free framework that transfers structured knowledge from a large teacher agent to a small student agent through hierarchical memory. AMD constructs three complementary memory types from successful teacher trajectories: Workflow memory encodes task-level strategies, Subtask memory provides concrete behavioral examples at an intermediate granularity, and Function memory captures per-function calling conventions and common pitfalls. Workflow and Subtask memories are injected proactively at the start of each task, while Function memory is retrieved reactively upon tool-calling errors. We evaluate AMD on three tool-use benchmarks using four student models (4B-8B parameters) with GPT-5-mini as the teacher, achieving average accuracy gains of 27.2%p, 11.2%p, and 3.4%p on AppWorld, BFCL V3, and ToolSandbox, while consistently outperforming existing memory-based baselines. Further analysis shows that Subtask memory contributes the largest gains, teacher effectiveness depends on both teacher capability and student compatibility, and 4B-sized students benefit most from AMD.

## 1. 核心问题与研究动机

- **背景**：记忆系统已被证明能提升 LLM 智能体的性能，使其复用成功行为模式、避免重复失败。然而，现有记忆方法大多针对大型专有模型（如 GPT-4、Gemini 2.5）设计，对小型模型关注不足。
- **核心难题**：小型语言模型（4B–8B 参数）自身任务成功率低，难以生成足够的成功轨迹，导致自生成的记忆库中多为失败经验，记忆收益有限。
- **关键观察**：即便直接提供高质量教师记忆（naive memory transfer），由于教师与学生之间存在"能力鸿沟"（capability gap），学生模型往往难以理解或应用高层级教师策略，提升仅微乎其微。
- **研究目标**：探索一种无需训练（training-free）的知识转移框架，将大型教师智能体的经验以结构化、可理解的方式传递给小型学生智能体，从而显著提升其在工具使用任务上的表现。

## 2. 方法论：Agent Memory Distillation (AMD)

### 2.1 核心思想
- 将教师智能体在成功轨迹中积累的经验，蒸馏为**三种层级化记忆**，分别覆盖任务级、子任务级和函数级粒度，使小模型能够"看得懂、用得上"教师知识。
- 该框架**无需模型参数训练**，仅通过在推理时注入/检索记忆来增强学生智能体。

### 2.2 三种记忆类型

| 记忆类型 | 粒度 | 内容 | 注入方式 |
|---|---|---|---|
| Workflow Memory | 任务级 | 高层任务完成策略：涉及的应用/工具、关键前提、决策规则、验证提示、常见失败模式；具体值替换为类型占位符（如 `<ID>`） | 任务开始时主动注入系统提示 |
| Subtask Memory | 子任务级 | 将教师轨迹分割为语义连贯的段（如"登录 Venmo"、"分页获取请求"），每个段包含标签、描述和具体执行示例（代码/工具调用及观察） | 任务开始时主动注入系统提示 |
| Function Memory | 函数级 | 单个函数调用的使用约定：函数名、教师的具体调用示例、上下文、参数 schema 及返回结构（有文档时） | 工具调用出错时按函数名被动检索并注入错误提示 |

### 2.3 检索与注入流程
- **主动注入**：任务开始时，用任务指令检索 top-k Workflow 记忆；同时学生模型将任务分解为最多 6 个子任务标签，每个标签独立检索 top-1 Subtask 记忆（去重后注入）。
- **被动注入**：执行过程中检测到工具调用错误时，提取失败函数名，在 Function 记忆库中按函数名检索 top-1 记录，将提示块附加到错误信息上下文中。
- **具体算法**（Algorithm 1）：
  1. 初始化消息历史；
  2. 用任务指令检索 Workflow 记忆并注入；
  3. 学生分解任务得到子任务标签序列；
  4. 逐个子任务检索 Subtask 记忆，去重后注入；
  5. 进入执行循环：若上一步有错误，检索对应 Function 记忆并追加到上下文；生成工具调用、执行、记录，直到任务完成或达到最大步数。

## 3. 实验设计

### 3.1 数据集 / 基准
- **AppWorld**（168 个任务，test_normal 子集）：多应用智能体基准，通过 Python API 操作模拟真实应用（邮箱、消息、支付），以数据库状态单元测试判定成功。
- **BFCL V3**（200 个任务，multi-turn base 子集）：函数调用基准，要求结构化函数调用，每项必须完全匹配预期 API 状态和最小可行调用路径。
- **ToolSandbox**（129 个任务，base 子集）：有状态、对话式工具使用基准，LLM 模拟用户驱动对话，按人工里程碑和雷区评分。

### 3.2 模型
- **教师**：GPT-5-mini。
- **学生**：Qwen3-4B、Qwen3-8B、Gemma4-E4B、Llama3.1-8B（后两者为 8B 级/e4b 变体，共四种学生模型）。
- 嵌入模型：OpenAI text-embedding-3-small。

### 3.3 对比方法
- Zero-shot 学生基线。
- 三种现有记忆方法（改造为教师→学生迁移场景）：
  - **ReasoningBank**：扁平任务级推理记忆。
  - **MemP**：层级过程记忆（但为同模型自进化设计）。
  - **SASM**：子任务级检索（但仅用一种统一记忆类型）。

### 3.4 实验设置
- k=1（每种记忆检索 top-1）。
- 每个任务最大 40 步。
- 每实验重复两次取平均；鲁棒性分析中重复五次。

## 6. 主要结论与发现

- **总体效果**：AMD 在三基准及全部学生模型上始终优于零样本和所有记忆基线，平均提升 AppWorld +27.2%p、BFCL V3 +11.2%p、ToolSandbox +3.4%p。
- **超越教师**：多个学生模型达到甚至超过教师（AppWorld 上 Qwen3-8B/Gemma4-E4B 超过 GPT-5-mini；BFCL V3 上三个学生超过教师；平均性能 Gemma4-E4B 和 Qwen3-8B 超过教师）。
- **子任务记忆贡献最大**：在复杂长程任务中（AppWorld），ST 记忆带来的增量增益最大（例如 Qwen3-4B 上 WF+ST 比 WF 高 +25.0%p）。
- **教师质量与兼容性**：对较强学生（8B），教师准确率是可靠预测因素；对较弱学生（4B），教师能力未必单调对应学生收益（GPT-5-mini 比 DeepSeek V4 Pro 对 Qwen3-4B 更有效），即教师-学生兼容性比单纯教师能力更重要。
- **学生规模效应**：AMD 精度随规模提升，但增益峰值在 4B 规模；1.7B 容量不足，8B/14B 已接近教师水平，提升空间小。
- **检索数影响**：k=1 接近最优，增加 k 会引入噪声，伤害小模型性能。
- **表示形式**：高层规划知识宜用自然语言，低层执行知识宜用具体代码/示例。
- **效率**：AMD 显著减少学生交互步数，使其更接近教师效率。
- **鲁棒性**：在 disjoint evaluation（记忆与任务不重叠）下，增益依然保持，说明提升来自记忆的真实泛化而非任务记忆泄漏。

## 7. 主要优点

- **问题定位精准**：清晰识别"小模型自生成记忆不足"和"直接迁移教师记忆存在能力鸿沟"两个核心障碍。
- **方法新而简洁**：首次系统化研究教师→学生的记忆蒸馏，采用无需训练的层级记忆结构，思想清晰、工程实现可行。
- **记忆粒度分层合理**：任务-子任务-函数三级划分对应规划、执行、纠错三种能力层，相互补充，案例研究（图 6）展示了级联效应，验证了各层不可或缺。
- **注入策略智能**：主动注入（WF/ST）与被动注入（FN）结合，避免上下文膨胀，仅在错误时注入函数级提示。
- **实验全面**：覆盖多基准、多学生模型、多教师，包含消融、鲁棒性、泛化性（disjoint eval）和案例研究，证据充分。
- **分析深入**：揭示子任务记忆重要性、教师-学生兼容性效应、4B 规模最优增益等洞察，对后续研究有指导价值。

## 8. 不足与局限

- **基准覆盖有限**：仅评估文本工具使用场景（Python API/结构化函数调用），未涉及多模态环境、开放式代码生成、非结构化交互等更复杂的智能体任务。
- **记忆静态冻结**：记忆离线构建后不变，无法在测试时融合学生自己的成功/失败经验，也无法适应教师演示与学生实际任务之间的分布漂移。
- **依赖教师轨迹质量**：教师太强或太弱都可能不利，教师-学生兼容性的预测和自适应教师选择仍开放。
- **小模型上下文/指令遵循局限**：额外记忆可能干扰弱模型（如 LLaMA3.1-8B 上加入 FN 反而掉点），记忆注入的容量边界未深入建模。
- **公平性隐患**：现有记忆基线是"改编到跨模型迁移"的，非原设计场景，可能低估基线能力；比较主要按任务成功率，未全面对比成本（token 消耗、延迟）。
- **资源报告缺失**：未披露具体 GPU/算力，复现成本不透明。
