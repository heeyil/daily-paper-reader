## 摘要
技能进化通过随时间推移的反馈来提升智能体技能，其中失败的轨迹往往能通过揭示不完整或误导性的行为提供信息丰富的信号。然而，现有方法主要依赖单条轨迹，早期推理错误会传播到后续步骤，削弱可用于技能精炼的反馈。因此，改进技能需要反复进行展开、诊断和更新的循环，产生大量令牌成本。为应对这一挑战，我们提出Branch2Skill，一个将单一推理树转化为密集监督信号用于技能进化的高效框架。对于每个任务或问题，Branch2Skill在固定预算下执行蒙特卡洛树搜索以获得多样化的推理轨迹，然后将精英路径与共享相同前缀的兄弟替代路径进行比较，提取关于哪些推理模式应保留、修改或避免的分步证据。最后，Branch2Skill将多步证据提炼为可复用的更新，使单一推理树能够跨多个推理步骤提供监督，减少重复展开-更新循环的需求。在涵盖推理和智能体任务的六个基准测试中，Branch2Skill一致地提升了任务性能，同时提高了技能进化效率。例如，以GPT 5.5作为目标模型时，Branch2Skill比SkillOpt节省73.2%的令牌，同时实现更优性能。这些结果表明，推理树不仅能支持更有效的轨迹搜索，还能为更高效的技能改进提供更丰富的监督。代码将公开发布。

## Abstract
Skill evolution improves agent skills through feedback over time, with failed trajectories often providing informative signals by revealing incomplete or misleading behaviors. However, existing methods mainly rely on single trajectories, where early reasoning errors can propagate through subsequent steps and weaken the feedback available for skill refinement. Consequently, improving skills requires repeated cycles of rollout, diagnosis, and update, incurring substantial token costs. To address this challenge, we introduce Branch2Skill, an efficient framework that transforms a single reasoning tree into dense supervision for skill evolution. For each task or problem, Branch2Skill performs Monte Carlo tree search under a fixed budget to obtain diverse reasoning trajectories, then compares an elite path with sibling alternatives sharing the same prefixes to extract step-wise evidence about which reasoning patterns to retain, revise, or avoid. Finally, Branch2Skill distills multi-step evidence into reusable updates, allowing one reasoning tree to provide supervision across multiple reasoning steps and reducing the need for repeated rollout-update cycles. Across six benchmarks covering reasoning and agentic tasks, Branch2Skill consistently improves task performance while enhancing skill evolution efficiency. For example, with GPT 5.5 as the target model, Branch2Skill uses 73.2% fewer tokens than SkillOpt, while achieving superior performance. These results demonstrate that reasoning trees can support not only more effective trajectory search, but also richer supervision for more efficient skill improvement. Code will be published.

## 2. 方法论：核心思想、关键技术细节、公式与算法流程

### 2.1 总体框架

Branch2Skill 的每个更新步骤流程如下：

1. 给定当前技能 \( K_t \) 和 \( M \) 个训练问题，目标模型（target model）为每个问题构建一棵独立的推理树，技能保持不变。
2. 搜索结束后，从每棵树上提取一条“精英路径”及其对应深度的兄弟节点集合，构成紧凑的树片段证据。
3. 技能模型（optimizer）汇总所有证据，通过 **APPEND / REPLACE / DELETE** 三种操作生成候选技能 \( \hat{K}_{t+1} \)。
4. 在固定验证集 \( V \) 上进行门控判断：若候选技能在所有指定指标上不劣于当前技能，则接受，否则回滚保留原技能。

### 2.2 步进式推理树构建

- 根节点 \( S_0 \) 表示基于问题和当前技能的空推理路径；非根节点 \( S_d^i \) 表示第 \( d \) 层第 \( i \) 个候选推理步骤（或环境动作），节点内容仅为单个推理步骤而非完整答案。
- 扩展节点时，目标模型读取从根到该节点的完整前缀，生成 \( C \) 个候选子节点，并对每个子节点给出一个“进展分数”（progress score），反映该前缀支持正确完成的可能性。
- 节点选择采用 **PUCT**（一种策略引导的 UCT 变体），公式为：

\[
\text{PUCT}(u,v) = Q(v) + c_{\text{puct}} \, P(v|u) \frac{\sqrt{\max(1, N(u))}}{1 + N(v)}
\]

其中 \( Q(v) \) 是通过 \( v \) 回溯的平均分数，\( N(\cdot) \) 是访问次数，\( P(v|u) \) 是子节点创建时分配的先验概率（没有概率时均匀分配），\( c_{\text{puct}} \) 控制对未充分访问替代方案的探索。

- 搜索在以下任一条件满足时终止：迭代预算耗尽、无有效可扩展节点、达到最大深度 \( D_{\max} \)。
- 搜索结束后，有效的非终端前缀会被补全一次，以提供终端结果，使原本仅有部分证据的分支也能用于比较。

### 2.3 共享前缀证据提取

- 从树中保留一条代表性路径 \( \pi^\star = (S_{1}^{i^\star_1}, \ldots, S_{L}^{i^\star_L}) \)。优先选择成功终端路径；若无成功路径，则选择最强的失败路径以提供诊断价值。
- 对每个保留深度 \( d \)，构造兄弟集合：

\[
B_d = \{ S_d^j \mid \text{pa}(S_d^j) = \text{pa}(S_d^{i^\star_d}), j \neq i^\star_d \}
\]

即所有与选中节点共享同一父节点（同一前缀）的替代步骤。

- 由于选中节点与兄弟节点共享前缀、仅在当前决策处不同，其下游结果的差异可**归因于当前决策**，这种局部对比比独立采样轨迹的对比更精确。
- 每个证据条目包含：共享前缀、选中步骤、少量已评估的兄弟节点、下游结果和紧凑的搜索统计信息。**并不会将整棵树发送给技能模型**。

### 2.4 技能修订与验证

- 所有 \( M \) 棵树的证据合并后一次性交给技能模型，生成完整的候选技能；可用操作包括：
  - **APPEND**：添加缺失的规则、条件或前提。
  - **REPLACE**：修正与证据冲突的动作、对象、条件或范围。
  - **DELETE**：删除误导性、冗余或与失败分支反复关联的指导。
- 验证门控采用**分量级非回归规则**：

\[
K_{t+1} = \begin{cases}
\hat{K}_{t+1}, & g(\hat{K}_{t+1}; V) \succeq g(K_t; V) \\
K_t, & \text{otherwise}
\end{cases}
\]

其中 \( \succeq \) 要求所有指定验证指标都不下降。最终评估使用验证集上表现最佳的检查点。

## 6. 主要结论与发现

1. **推理树是有效的密集监督来源**：Branch2Skill 在 30 个设置中排名第一或并列第一的有 26 个，27 个设置优于 SkillOpt；平均分从无技能的 50.8 提升至 69.1（SkillOpt 为 66.0），平均增益 18.3 分 vs. SkillOpt 的 15.3 分。
2. **显著提升 token 效率**：以 GPT-5.5 为目标模型时，Branch2Skill 比 SkillOpt 减少 73.2% 的演化 token，同时总增益从 117.8 提到 128.7（+9.3%），每百万 token 增益从 0.224 提高到 0.911，效率提升 **4.07 倍**。
3. **更强的目标模型（GPT-5.5）作为技能模型表现最佳**：在 LiveMath 上平均 45.7 vs. 次优 41.7，且对每个目标模型都产生最好的 LiveMath 技能；SearchQA 对技能模型身份相对不敏感（最大差距较小）。
4. **结构化兄弟证据优于单路径和整棵树**：消融显示，相比仅用精英路径（无兄弟证据）和将整棵树发给优化器，本文方法在 LiveMath 上分别高出 13.7 和 15.3 分；在 SearchQA 上高出 2.9 和 5.6 分——支持“同父比较”优于“未过滤全树”的观点。
5. **技能可跨模型与跨数据集迁移**：从 GPT-5.4 演化的 LiveMath 技能可提升 GPT-5.5（+18.9）和 GPT-5.4-mini（+21.6）；从 OlympiadBench 演化的数学技能可提升 Omni-MATH 上 3 个目标模型（+2.8~+3.5）。
6. **验证门控保证非递减演化**：门控机制使保留的技能曲线单调不减，拒绝局部合理但损害整体效用的修订。

## 7. 优点

1. **方法论创新性**：首次系统性地将 MCTS 推理树中的“共享前缀兄弟节点”转化为持久化技能的密集监督信号，把搜索树从“求解工具”升级为“学习信号发生器”。
2. **归因更精确**：兄弟节点共享前缀的特性天然隔离了每一步决策的影响，无需依赖事后错误定位模型，避免了单轨迹中早期错误对后续节点归因的污染。
3. **极高的 token 效率**：单棵树即可提供多深度的反馈，大幅减少 rollout-update 循环次数，在实践中节省 73.2% 的成本。
4. **架构解耦与兼容性**：目标模型与技能模型可以不同，且实验证明技能具有跨模型、跨数据集的迁移能力；门控机制不依赖边信息，通用性强。
5. **算法设计简洁**：证据提取仅需保留精英路径和同父兄弟节点，不需要将整棵树发送给优化器，简洁且高效。
6. **实验覆盖广**：包含多种任务类型、多个模型规模、消融、迁移和动态分析，结论支撑度较高。
