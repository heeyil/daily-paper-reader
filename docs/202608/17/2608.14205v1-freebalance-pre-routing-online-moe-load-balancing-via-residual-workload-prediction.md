## 摘要
负载不平衡是混合专家（MoE）模型分布式推理中专家并行效率的主要瓶颈。由于路由分布倾斜，负载最重的计算节点会阻塞全局执行，直接增加延迟。虽然离线专家放置可以缓解持续不平衡，但实际的多任务服务负载表现出与层和批次相关的路由动态，使得在线负载均衡不可或缺。现有方法依赖于每个MoE路由器之后收集的路由统计，要求专家权重加载或迁移只能在路由决策可用后开始，从而将迁移开销置于推理关键路径上。在这项工作中，我们观察到，如果可以提前准确预测路由分布，在线平衡便可以在目标路由（如注意力）之前的计算中大幅重叠。因此，我们提出FreeBalance，一种无损在线负载均衡框架，通过残差工作负载预测将专家迁移与前面的计算阶段重叠。FreeBalance利用残差网络中隐藏表示的跨层相似性来构建轻量级工作负载预测器。这实现了在路由决策可用之前进行主动的专家迁移规划，在权重转移和计算密集型路由前阶段之间产生大量重叠。此外，成本模型限制了交换次数，以在可用窗口内完全隐藏同步开销。跨模型和数据集的实验表明，FreeBalance将最大与平均设备负载比降低了32.8%，端到端预填充延迟降低了13.1%。具体而言，我们的方法隐藏了每层平均5.1个专家的均衡开销，否则这些开销将占据关键路径延迟的约8.5%。

## Abstract
Load imbalance poses a major bottleneck to the efficiency of expert parallelism in distributed inference of Mixture-of-Experts (MoE) models. The most heavily loaded rank stalls global execution due to skewed routing distributions, directly increasing latency. While offline expert placement can alleviate persistent imbalance, practical multi-task serving workloads exhibit layer- and batch-dependent routing dynamics, making online load balancing indispensable. Existing approaches rely on routing statistics collected after each MoE router, requiring expert weight load or migration to begin only after routing decisions are available, consequently placing migration overhead on the inference critical path. In this work, we observe that online balancing can instead be largely overlapped with computation before target routing (e.g., attention), if routing distributions can be predicted accurately in advance. Therefore, we propose FreeBalance, a lossless online load-balancing framework that overlaps expert migration with preceding computation stages via residual workload prediction. FreeBalance leverages cross-layer similarities in hidden representations within the residual network to build a lightweight workload predictor. This enables proactive expert migration planning before routing decisions are available, creating substantial overlap between weight transfer and computation-heavy pre-routing stages. Furthermore, a cost model constrains the number of swaps to fully hide the synchronization overhead within the available window. Experiments across models and datasets show that FreeBalance reduces the max-to-mean rank load ratio by 32.8% and end-to-end prefill latency by 13.1%. Specifically, our method hides balancing overhead of an average of 5.1 experts per layer, which would otherwise account for about 8.5% of the critical-path latency.

## 1. 论文的核心问题与整体含义

- **研究背景**：MoE（混合专家）架构已成为现代大语言模型的主流设计，通过稀疏路由在增加参数容量的同时控制单 token 计算成本。在分布式推理中，专家并行（EP）将专家切分到多设备上，配合 all-to-all 通信完成计算。
- **核心问题**：路由分布倾斜导致设备间负载严重不均衡。由于 EP 组内存在全局同步（all-to-all 通信与专家计算均受最慢 rank 拖累），负载最重的设备成为系统瓶颈，使轻载设备空转等待，直接拉高端到端推理延迟。
- **现有方法的困境**：离线专家放置（如 DeepSeek EPLB）依赖历史路由统计，在实际多任务场景中路由分布随任务类型显著变化，静态映射无法及时适配。在线负载均衡虽能动态调整专家–设备映射，但专家迁移必须在路由决策完成后才能启动，迁移窗口位于路由到专家执行之间的关键路径上，额外开销直接计入延迟。
- **关键观察**：若能在路由执行之前准确预测工作负载分布，即可打破“先路由、后迁移”的顺序依赖，将专家迁移与路由前的计算密集型阶段（主要是 attention）重叠，从而隐藏均衡开销。
- **整体含义**：论文提出 FreeBalance——一种无损的在线 MoE 负载均衡框架。它利用残差网络中相邻层隐藏表示的跨层相似性，用前一层输出（hℓ−1）提前调用目标层 router 预测专家负载分布，在真实路由决策前完成专家交换规划与权重迁移，使均衡开销不再落在推理关键路径上。

## 2. 论文提出的方法论

### 2.1 核心思想

FreeBalance 的核心在于“将负载均衡从路由后搬移到路由前”。它不改变模型的最终路由决策（正常 router 仍然执行并决定 token 到专家的分配），只利用预测结果指导专家的物理放置与迁移，从而保证无损推理。

### 2.2 残差工作负载预测（Residual Workload Prediction）

- **利用跨层相似性**：残差连接使相邻层隐藏表示高度相似（hℓ = hℓ−1 + Attention + MoE 的更新量远小于隐状态本身），hℓ−1 与 hℓ 的余弦相似度接近 1。
- **双重 router 调用**：
  - 早期调用：bGℓ = gℓ(hℓ−1)，在 attention 之前即可获得早期路由 logits；
  - 正常调用：Gℓ = gℓ(Hℓ)，Hℓ 为目标层真正的 router 输入。
- **负载聚合**：对早期 logits 应用 top-k 规则得到估计的 token–专家分配，再聚合为每个专家的预测负载计数 bnℓ,e。
- **零额外参数**：两次调用共享同一组冻结的 router 参数，因此 FreeBalance 不引入任何预测器权重、训练流程或检查点状态。

### 2.3 预算化专家交换规划（Budgeted Expert-Swap Planning）

- **交换目标**：在过载 rank 与欠载 rank 之间交换专家（两两交换），以降低预测的最大 rank 负载。交换不改变每个 rank 的专家数量与内存占用，且易于回滚。
- **负载更新公式**：交换专家 ea（所在 rank a）与 eb（所在 rank b）后，rank a 的负载变为 L′ₐ = Lₐ − bnₑₐ + bnₑᵦ，rank b 同理。
- **收益评分**：目标函数 Φ(L) = max_r Lr + γ·Σ_r(Lr − L̄)²，兼顾最大负载与负载方差；仅接受收益为正的候选交换。
- **成本模型**：估计每次交换的通信代价 C(s) = αa,b + (S(ea)+S(eb))/βa,b，其中 S(e) 为专家权重大小，βa,b 为点对点带宽，αa,b 为启动开销。
- **预算约束**：可用迁移预算 Bℓ = max(0, T_attn(r(ℓ)) − δ)，即同类型 attention 的测量时间减去安全裕度。预算按链路和 rank 分别施加，防止过度订阅。
- **确定性规划**：所有 rank 基于相同的全局负载向量与放置映射，采用贪心算法枚举候选、按收益/成本比排序、依次接受，保证各 rank 本地推导出完全一致的交换序列，无需广播规划结果。

## 6. 论文的主要结论与发现

- FreeBalance 将 max-to-mean rank 负载比从 Vanilla 的约 2.01 降至 1.35，降幅最高 32.8%。

## 7. 优点

- **无损性**：预测仅用于放置调整，最终路由完全由正常 router 决定，不改变模型输出，实现零精度损失加速。
- **零额外参数**：直接复用原始 router 进行早期调用，无需预测器权重、训练流程或额外检查点状态，实现成本极低。
- **开销可隐藏**：通过提前预测，将专家迁移与 attention 等计算密集型阶段重叠，将均衡开销移出关键路径，该设计尤其有利于长序列推理。
- **规划确定性**：所有 rank 本地推导相同交换计划，无需广播，避免额外的通信和同步开销。
- **算法轻量**：贪心规划仅关注过载/欠载 rank 的前沿候选集，可在 layer 粒度实时运行。
- **自适应预算**：成本模型依据实际 attention 时间和拓扑带宽动态决定迁移数量，适配不同序列长度和网络环境。

## 8. 不足与局限

- **预测精度的上限**：顶部-k 命中率最高仅约 0.85，仍有部分层预测不准，且未深入分析预测错误对均衡效果的具体影响（剩余 5% 层未改善）。
- **单节点实验局限**：所有实验仅在单节点 8×A800 上运行，未验证跨节点/rack-scale 场景下网络带宽、拓扑差异对迁移隐藏效果的影响，实用性结论的外推需谨慎。
- **固定配置范围**：batch size 固定为 16，未测试不同 batch size 对 attention 窗口、路由分布和迁移预算的交互影响；也未分析 decode 阶段（生成）场景下的有效性。
- **依赖先验 profiling**：成本模型需要运行时初始化时校准带宽与协议开销参数，注意 attention 时间需按类型预先测量，对异构模型或动态 environment 的适应性有限。
- **路由决策保存但放置多变**：虽然推理无损，但交换后的专家放置与原始路由决策之间存在一个推理步骤的“错位”——预测基于 hℓ−1 做出的负载估计可能与真实 Hℓ 下的路由产生偏差，鲁棒性未充分讨论。
- **多任务场景模拟粒度较粗**：Mixed Tasks 仅逐 step 切换任务子集，未模拟更复杂的请求交错、抢占、在线到达等生产环境真实负载模式。
