## 摘要
理解长达数十分钟的手术视频需要长程时间推理，通过将问题锚定在跨越时间的视觉证据上，回答在手术过程各阶段之前、之后或跨阶段发生了什么。现有方法对此处理不佳：一次性视觉语言模型（VLM）将整个手术过程压缩以适应其上下文窗口，丢失了“之前”或“之后”问题所依赖的细节；而训练模型关注位置的视频智能体则数据需求大，且泛化到域外手术的效果不佳。我们构建了一个将推理与感知分离的智能体框架，通过演进上下文而非优化权重来改进。一个纯文本编排器规划需要收集哪些证据，并发出可审计的工具调用序列，而冻结的视觉语言子智能体在像素上执行每次调用，查看、裁剪、检查帧并检索外部知识。我们进一步提出了一个无梯度、奖励门控的启发式技能蒸馏循环，该循环挖掘智能体自身的低分轨迹，并且仅在候选技能提高验证奖励时才保留它，从而产生可复用的检索技能，尤其是定向重看。该循环通过增长外部技能库而非调整权重，仅从约100个标注示例中适应，远少于监督或强化微调所需的数据。为了评估该智能体，我们引入了MedClawBench，这是一个去泄漏、基于医生构建的基准，包含1,123个问题，覆盖自建的长神经外科手术录像和一个留出的公共讲座视频测试集。在两个数据集和所有四个评估维度上，我们的智能体始终优于一次性VLM和通用视频智能体框架，在长时程、域外的神经外科手术视频上提升最大。项目页面：https://fyycs.github.io/medclaw/。

## Abstract
Understanding tens-of-minutes surgical videos requires long-horizon temporal reasoning, answering what happens before, after, or across stages of a procedure by grounding the question in visual evidence spread across time. Existing approaches handle this poorly: a one-shot vision-language model (VLM) compresses the whole procedure to fit its context window and loses the detail a "before" or "after" question depends on, while video agents that train the model where to look are data-hungry and transfer poorly to out-of-domain surgery. We build an agent harness that separates reasoning from perception and improves by evolving context rather than optimizing weights. A text-only orchestrator plans which evidence to gather and issues an auditable sequence of tool calls, while frozen vision-language sub-agents execute each call over the pixels, viewing, cropping, inspecting frames, and retrieving external knowledge. We further propose a gradient-free, reward-gated Heuristic Skill Distillation loop that mines the agent's own low-scoring traces and keeps a candidate skill only when it raises a validation reward, yielding reusable retrieval skills, notably directed re-look. Growing an external skill library rather than tuning weights, the loop adapts from only about 100 labeled examples, far fewer than supervised or reinforcement fine-tuning requires. To evaluate this agent, we introduce MedClawBench, a de-leaked, doctor-grounded benchmark of 1,123 questions over self-built long neurosurgery recordings and a held-out public lecture-video test split. Across both datasets and all four evaluation dimensions, our agent consistently outperforms one-shot VLMs and general video-agent frameworks, with the largest gains on the long, out-of-domain neurosurgery videos. Project page: https://fyycs.github.io/medclaw/.

## 1. 核心问题与整体含义（研究动机与背景）

长时程手术视频（长达数十分钟）中的时序推理是医学视频理解中最具挑战性的任务之一。这类推理要求系统能够回答“某步骤之前/之后发生了什么”或“整个手术如何跨阶段演变”等问题，且答案必须锚定在跨越时间的视觉证据上，而非单一帧或局部片段。

现有方法面临两难困境：
- **一次性（one-shot）VLM**：将整个视频压缩以适应上下文窗口，导致“before/after”问题所依赖的关键细节丢失，且无法回溯细查。
- **训练式视频智能体**：通过监督微调（SFT）或强化学习（RL）训练模型决定“看哪里”，需要大量任务特定轨迹数据，过拟合训练分布，且在长时程、域外（out-of-domain）场景（如神经外科手术）中迁移能力差——而这恰是最需要该能力且标注数据最稀缺的场景。

因此，论文提出的核心问题是：**能否以“免训练”（training-free）的方式获得决定“看哪里”的能力**，核心思路是**通过演进上下文而非优化权重来提升系统能力**。

## 2. 方法论

### 2.1 核心思想

将任务需要的两种能力分离：**决定看哪里（推理）** 与**实际看（感知）**，并分别交给冻结的模型，仅在上下文层面进行协调。系统通过演进上下文（而非更新权重）来实现自我改进。

### 2.2 智能体框架（Agent Harness）三部分构成

**（1）文本编排器（Text Orchestrator，πθ）**
- 纯文本策略模型（Opus-4.8），参数冻结，不直接观看视频
- 通过“推理-行动”循环（ReAct），在步骤 t 依据累积上下文 cₜ 发出动作 aₜ，选择工具并传入参数
- 流程形式化为：aₜ = (T̂ᵢₜ, uₜ) ~ πθ(·|cₜ), oₜ = Tᵢₜ(V, uₜ)，上下文更新为 cₜ₊₁ = cₜ ⊕ (aₜ, oₜ)
- 直至发出 STOP 动作并生成最终答案，全程轨迹 ρ = {(a₁,o₁),...,(a_T,o_T)} 被完整记录，保证可审计性

**（2）工具集（Tool Suite，T）**
形成从整段视频到单帧的由粗到细的渐进式工具链：
- `view_full_video(V, q)`：两阶段定位。Stage-1 低分辨率通读生成稠密时间线（每间隔的简要描述）+ 候选时间窗口；Stage-2 高分辨率重看加宽窗口，返回包含目标事件的最紧密子窗口
- `crop_video(V, s, e, q)`：在选定时间范围内以裁剪分辨率重读，返回稠密描述
- `select_video_frame(V, t, q)`：单帧描述，作为跨模型验证
- `crop_video_frame(V, t, x₁, y₁, x₂, y₂, q)`：帧内空间区域裁剪与描述，用于区分微小/重叠结构
- `search_surgical_kb(q, type, k)`：RAG工具，从手术知识库（仅含通用手术背景，不含基准答案）检索top-k段落

**（3）冻结视觉子智能体（Vision Sub-agents，ψ）**
- 视频专家（Gemini-3.1-flash-lite / Gemini-3.5-flash）：负责 `view_full_video` 和 `crop_video`，处理需要跨时间推理的操作
- 帧验证器（GPT-5.5）：负责 `select_video_frame` 和 `crop_video_frame`，提供单帧的高分辨率独立核验

### 2.3 启发式技能蒸馏循环（Heuristic Skill Distillation, HSD）

这是论文的核心创新机制，包含三个步骤：

**（1）从失败轨迹中挖掘候选技能**
- 在挖掘集上逐一回答问题：首先“盲答”（看不到标准答案），记录答案 â 与轨迹 ρ；然后对照标准答案诊断差距
- 将差距分为三类：
  - **Type A（可操作差距）**：标准答案内容在视频中可见，但不同的观看方式可以捕捉到——这是唯一携带可操作教训的类型
  - **Type B（不可达差距）**：标准答案指向视频外信息（如画外音、手术意图、病理结果）或骨干模型分辨率不足
  - **Type C（已正确）**：无需改变
- 对于 Type A，编排器通过“原生技能管理工具”写入技能：若已有相同规则则更新，否则新增，候选技能上限为5个

**（2）奖励门控保留（Reward-gated Retention）**
- 先测量空技能库基线奖励 R₀ = E[R(a∅)]（在验证集上，四维评分均值）
- 逐一测试候选技能：单独安装、重新回答整个验证集、重新评分，得到 Rₛ = E[R(a{s})]
- **保留条件**：Rₛ > R₀ + δ（δ = 0.05，1–5分制）且不使任何单个验证问题掉分≥2分

**（3）学习的技能库**
- 实践中收敛到一个紧凑库，主导技能为 **“定向重看”（directed re-look）**：对于“事件之前/之后”类问题，答案位于事件窗口**相邻**的窗口中，而非事件窗口内部
- 该技能通过挖掘自身时序错误并奖励门控而自动发现，而非人工设计

**核心特质**：全程无梯度更新、无权重修改，只在外部技能库层面演进；仅需约100个标注样本（60个挖掘集 + 40个门控验证集），数据效率远高于SFT/RL微调。

- **视频时长仍不够长**：尽管中位数18.4分钟在同类中已领先，但真实神经外科手术常持续数小时，与真实临床场景仍有差距
- **域外泛化证据有限**：两个数据集（神经外科治疗视频、SVU讲座视频）虽互补，但覆盖面有限，未验证更广泛的手术类型（如腹腔镜、机器人手术）上的表现
- **技能库规模小**：仅收敛到以定向重看为主的少量技能，是否能在更广泛的任务中演化出更丰富的技能库尚不清楚
- **技能蒸馏依赖自我诊断**：Type A/B/C分类由编排器自我判断，存在诊断失误的可能；虽然奖励门控提供了一定保护，但门控本身依赖四维评分体系的完整性
- **未与其他医疗智能体对比**：与MedScope等更相关的医学视频智能体框架的直接对比缺失，定位略显孤立
- **编排器和视觉子智能体为闭源商业模型**：一定程度影响可复现性（尽管替换实验说明框架有一定模型无关性）
