## 摘要
大语言模型（LLM）智能体必须在长期任务中保留并利用跨步骤信息以实现连贯行动。现有方法提升了记忆的可访问性，但行动相关信息仍可能因形成、组织、优先级排序或呈现方式不当而无法指导当前决策。我们将这种访问后失败称为“记忆-行动鸿沟”。我们提出MemArbiter，一种功能感知的记忆仲裁框架，用于解决该鸿沟中由记忆管理引发的部分。MemArbiter将交互历史分解为原子条目，将其组织为五个功能性记忆库，并结合库级需求、条目级相关性、焦点-环境表示以及时间呈现门控，动态控制记忆显著性。我们在ALFWorld上，在统一的分步记忆预算下，将MemArbiter与平坦检索和平坦近因方法进行对比评估。使用开放权重动作生成模型，MemArbiter在500和750词元预算下分别达到82.8%和92.5%的成功率，比最强基线高出20.9和25.4个百分点。它还改善了失败后的恢复能力，并减少了失败动作重复和状态-动作重复。这些结果表明，功能感知的记忆仲裁能使可访问信息更有效地指导行动。

## Abstract
Large language model (LLM) agents must retain and use cross-step information to act coherently in long-horizon tasks. Existing methods improve memory accessibility, yet action-relevant information may still fail to guide the current decision because it is poorly formed, organized, prioritized, or presented. We call this post-access failure the Memory-Action Gap. We propose MemArbiter, a function-aware memory arbitration framework that addresses the memory-management-induced component of this gap. MemArbiter decomposes interaction histories into atomic items, organizes them into five functional Memory Banks, and combines bank-level demand, item-level relevance, focal-ambient representations, and a temporal presentation gate to dynamically control memory salience. We evaluate MemArbiter on ALFWorld against Flat Retrieval and Flat Recency under unified per-step memory budgets. With an open-weight action-generation model, MemArbiter achieves success rates of 82.8% and 92.5% under 500- and 750-token budgets, outperforming the strongest baseline by 20.9 and 25.4 percentage points, respectively. It also improves post-failure recovery and reduces failed-action repetition and state-action recurrence. These results show that function-aware memory arbitration enables accessible information to guide actions more effectively.

### 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：在长周期（long-horizon）任务中，LLM 智能体需要跨步骤积累和利用历史信息来做出连贯决策。现有记忆管理方法主要关注“可访问性”（accessibility），即如何存储、检索和扩展可用上下文，但即使相关信息已经进入记忆管理流程，仍可能因为**形成、组织、优先级排序或呈现方式**不恰当而无法有效指导当前动作。论文将此定义为 **Memory-Action Gap（记忆-行动鸿沟）**，并表明它不同于“遗忘”（信息未保留）或“检索失败”（信息无法找到），而是发生在信息可被记忆管理管线处理之后、但在决策时未能发挥应有影响的阶段。
- **背景**：现有研究（如上下文扩展、检索组织、摘要压缩、经验记忆等）提升了长期任务中信息的留存与回溯能力，然而信息“可访问”不等于“能影响行动”。论文引用了“lost in the middle”等现象，说明无关的信息位置和混合呈现会削弱相关记忆的决策价值。
- **整体含义**：要弥合记忆与行动之间的鸿沟，不能只做“存取管理”，还需要对记忆进行**端到端的仲裁**：如何将历史拆成原子单元、如何按决策功能组织、如何动态调整优先级和呈现形式，从而让可访问的信息真正服务于动作生成。

### 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

- **核心思想**：提出 **MemArbiter**，一个决策时（decision-time）的功能感知记忆仲裁框架。它把交互历史分解为原子记忆项，按决策功能分配到五个记忆库，并通过多层级信号和时间驱动门控，动态决定每个记忆项以何种粒度、何种位置出现在动作生成的提示中。
- **记忆项与功能角色**：
  - 一个记忆项是支持未来决策的原子信息单元，可能来自任务描述、环境观察或交互结果。
  - 记忆项被划分为五种功能角色：**Goal（目标）**、**Task State（任务状态）**、**Constraint（约束）**、**Episodic（情景）**、**Reference（参考）**。
  - 每种角色在决策中的作用不同：目标引导方向；任务状态描述当前条件；约束限制非法行为；情景记录过往尝试与结果；参考提供可复用环境知识。
  - 不同角色时间特征不同，因此需要差异化管理，而非统一扁平化存储。
- **流程框架（图 2）**：
  1. **状态解析**：解析任务目标、当前观察、上一步动作与结果、累积轨迹，形成当前决策上下文 \(c_t\)。
  2. **候选写入（Candidate Writer）**：从新观察和动作结果中提取原子信息，生成五个记忆库的候选写入；每项候选具有单一主要功能角色；通过有效性检查、去重、冲突消解后写入对应库（如任务状态替换旧快照、约束合并、情景追加、参考合并）。
  3. **双频表示（Dual-Band Representation）**：每个记忆项同时有 **focal（焦点）** 和 **ambient（环境）** 两种表示。focal 保留完整内容，ambient 使用模板化简洁提示；频段与记忆库正交，任意记忆项可以切换频段而无需重新分类。
  4. **决策相关信号（Decision-Relevance Signals）**：
     - 库级需求 \(d_{b,t}\)：衡量当前步骤对某个功能记忆角色整体的需求，控制其是否参与提示。
     - 项级相关性 \(\eta_{i,t}\)：衡量单个记忆项对当前决策的贡献，用于状态转换和排序。
     - 二者根据当前子目标、任务进展、相关实体、信息需求、上一步异常等计算。
  5. **时间呈现门控（Temporal Presentation Gate）**：
     - 状态转移公式：\( z_{i,t} = G_{b(i)}( z_{i,t-1}, d_{b(i),t}, \eta_{i,t}, h_{i,t-1}) \)。
     - 状态 \(z\) 可取 `focal`、`ambient`、`hidden`；`hidden` 是排除状态而非第三种表示。
     - 通过保留前一步状态形成连续性，结合相关性信号与相关性历史，抑制瞬时波动导致的过早降级或频繁切换。
     - 同时应用角色特定规则：Goal 和 Constraint 受保护，除非完成/失效；Task State 对应最新有效状态；Episodic 和 Reference 动态调整。
  6. **提示组装（Prompt Assembly）**：按记忆库章节组织，每个库内先 focal 后 ambient，同频段内按相关性排序，hidden 排除，最终与当前观察一起生成下一动作。

### 3. 实验设计：使用了哪些数据集 / 场景，benchmark 是什么，对比了哪些方法

- **数据集/场景**：使用 **ALFWorld**（text-based embodied household 任务），采用 `eval_out_of_distribution` 中全部 **134 个未见任务**，涵盖六类任务：Pick、Look、Clean、Heat、Cool、Pick Two。
- **智能体框架**：ReAct 范式；动作生成模型为 **Qwen3.6-27B-FP8**（开放权重），跨模型验证中使用 **GPT-5.4**（仅替换动作生成模型）。
- **对比方法**：
  - **Flat Recency**：按时间保留最近观察/动作记录。
  - **Flat Retrieval**：使用 BM25 对观察行排序，查询由任务目标、上一动作、最新观察拼接而成，取最高相关行。
  - **MemArbiter**（完整方法）。
  - **消融变体**（500-token预算下）：`w/o Functional Banks`（去掉功能记忆库，单一大池）、`w/o Dynamic Signals`（用固定分配代替动态库级信号）、`w/o Temporal Gate`（去掉时间门控）。
- **统一记忆预算**：所有方法的记忆提示块在 500 和 750 token 下比较，使用统一 tokenizer（`o200k_base`）。
- **评估指标**：
  - 累计成功率 `SR@k`（在 k 步内完成所有 134 个任务的比例），`SR@50` 为主要指标。
  - 机制诊断：失败后一步恢复率、失败动作重复率、相邻重复率、状态-动作复发率，以及失败前后 Episodic 记忆在提示中的占比变化。

### 6. 论文的主要结论与发现

- **主结果**：在 ALFWorld 上，MemArbiter 在 500-token 预算下达到 **82.84%** 成功率，比最强基线 Flat Retrieval 高 **20.90** 个百分点；在 750-token 预算下达到 **92.54%**，高 **25.38** 个百分点。Flat 方法在预算增加时收益甚微，说明额外容量只在正确的功能组织和呈现下才有价值。
- **任务类型差异**：六类任务中，MemArbiter 在 500-token 下五类最优，750-token 下全部最优；尤其在约束大量中间状态的 **Pick Two** 任务上，基线全部失败（0%），MemArbiter 达到 58.82%~70.59%，说明功能化仲裁对需要多源状态协调的任务尤为关键。
- **步数效率**：`SR@k` 曲线显示 MemArbiter 在相同步数限制下完成更多任务，且优势逐步扩大，表明其提升并非来自“多走步数”，而是更有效地利用轨迹。
- **跨模型泛化**：替换动作生成模型为 GPT-5.4 后，MemArbiter 仍比最强基线高约 10~13 个百分点，说明收益不严重依赖特定开放权重模型。
- **消融结论**：动态库级信号（-17.17）、功能记忆库（-15.68）、时间门控（-8.96）均显著影响最终成功率；时间门控在早期反而略有损失（SR@15 +2.98），但在长轨迹中收益明显，说明其价值体现在持续决策中。
- **失败恢复与复发**：MemArbiter 显著提高失败后一步恢复率（如 750-token 下比 Flat Retrieval 高 34.8 个百分点），大幅降低失败动作重复、相邻重复和状态-动作复发率；失败后的提示中 Episodic 记忆占比显著上升（+3.3% 和 +1.9%），而 w/o Temporal Gate 几乎没有变化，说明门控机制能够对失败做出及时的记忆呈现调整。

### 7. 优点

- **概念创新**：清晰区分了“可访问性”和“决策影响力”，提出 Memory-Action Gap 这一新问题，并明确其与遗忘、检索失败的差异。
- **方法论系统化**：将记忆管理建模为“形成-组织-优先级-呈现”的端到端仲裁问题，五个功能记忆库和双频表示的设计符合决策功能异质性。
- **机制完整**：库级与项级信号互补，时间门控引入状态连续性和相关性历史，避免了独立决策带来的抖动，逻辑自洽。
- **实验设计公平**：统一记忆预算和 tokenizer、固定随机种子、同一交互循环，增加了对比的可信度。
- **诊断深入**：不仅报告成功率，还分析失败后恢复、重复动作、状态-动作复发以及 Episodic 占比变化，提供机制层面的证据。
- **跨模型验证**：使用开放权重和专有模型双动作生成器验证，增强结论的普适性。

### 8. 不足与局限

- **单一环境**：仅在 ALFWorld（文本家居任务）上评估，未验证 Web 导航、多模态环境、开放式对话等场景；作者的“未来工作”也承认这一点。
- **显式角色设计**：五个记忆库和相关性信号由人工预先设定，需要领域知识；虽然透明、可审计，但不够自适应，难以直接迁移到未知任务类型。
- **基线范围有限**：仅对比扁平 Recency 和 BM25 Retrieval，未与更先进的工作记忆方法（如 HiAgent、MemAct、AgeMem、ARC 等）进行比较，因此优越性在同代方法中尚未定位。
- **机制证据为关联性**：论文指出失败后 Episodic 占比上升与更好恢复行为相关，但并未证明单个记忆项的提升/降级直接导致特定动作；需要受控干预实验才能建立因果。
- **任务内局限性**：Pick Two 任务尽管有大幅提升，但绝对成功率仍不足（58.82%~70.59%）；说明复杂约束场景下记忆仲裁仍有提升空间。
- **算力信息不透明**：未报告推理总开销或 GPT-5.4 API 成本，难以判断框架的实际效率是否优于扁平方法。
