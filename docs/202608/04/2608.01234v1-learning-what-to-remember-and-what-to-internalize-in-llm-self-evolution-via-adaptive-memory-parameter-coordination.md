## 摘要
大型语言模型智能体越来越多地运行在动态环境中，其中工具界面、API和用户需求在部署后发生变化。现有的自进化方法主要遵循两种范式：基于外部机制的方法，将反馈外化为可编辑的记忆或技能以实现快速适应；以及基于参数的方法，将经验内化到模型参数中以实现更深层次的能力提升。然而，单独使用任何一种机制都会在灵活性和性能之间产生权衡。本文探讨了智能体如何协调这两种通道以实现稳健的自进化。我们提出了COVE，一个统一的智能体自进化框架，通过任务感知路由、阶段感知调度和知识优化，将基于外部机制和基于参数的学习相结合。通过这种设计，COVE将自进化视为一种协调过程，而不是不加区分地积累经验，它会将任务和知识类型匹配到合适的学习机制。跨多个任务类别的实验表明，COVE优于单通道进化策略，在变化的环境下展现出更稳健和高效的改进。

## Abstract
Large language model agents increasingly operate in dynamic environments where tool interfaces, APIs, and user requirements change after deployment. Existing self-evolution methods mainly follow two paradigms: harness-based approaches, which externalize feedback into editable memories or skills for rapid adaptation, and parameter-based approaches, which internalize experience into model parameters for deeper capability improvement. However, using either mechanism alone creates a trade-off between flexibility and performance. This paper asks how an agent can coordinate both channels to achieve robust self-evolution. We present COVE, a unified agent self-evolution framework that combines harness-based and parameter-based learning through task-aware routing, stage-aware scheduling, and knowledge optimization. Through this design, COVE treats self-evolution not as indiscriminate accumulation of experience, but as a coordinated process that matches tasks and knowledge types to appropriate learning mechanisms. Experiments across multiple task categories show that COVE outperforms single-channel evolution strategies, demonstrating more robust and efficient improvement under changing environments.

- **研究背景**：大语言模型智能体已从被动文本生成器进化为交互式系统，能够规划、调用工具、编写代码、在具身环境中操作，并通过多步推理解决复杂任务。然而，外部世界持续变化——API 更新、数据库模式改变、新库出现、领域规范转变、以及用户引入开发时未预料的新任务，使得维持高性能智能体需要频繁的重配置或重训练，这在人力和计算上代价高昂。
- **核心问题**：现有智能体自进化方法主要分为两大范式：
  - **基于外部机制（Harness-based）**：如 Evo-Memory，将反馈外化为可编辑的记忆、技能，在推理时检索注入。其优点是快速、适应任务表面变化，但基础模型缺乏解释反馈能力时可能产生误导性或不可用的经验。
  - **基于参数（Parameter-based）**：如 WizardLM、Self-Challenging Agent，通过监督微调或强化学习将经验内化到模型权重中。其优点是可内化深层模式（如潜在策略、领域推理例程），但训练成本高、适应慢，且对接口变化等表面变化表现脆弱。
- **核心挑战**：单独使用任一种机制都会在灵活性与性能之间产生权衡。有效自进化需要**协调两种通道**，而非依赖其一。论文提出核心问题：**在自进化中，智能体如何决定该记住什么（外化到外部记忆）以及该内化什么（写入模型参数）？**
- **核心论证**：通过多项诊断实验（Lean 定理证明、WikiTableQuestions 动态工具接口），论文证明：(i) 进化通道的选择必须联合取决于任务类别和学习阶段；(ii) 自进化必须区分不同知识类型，知识**易变性（volatility）** 是决定外化还是内化的关键标准。

## 2. 论文提出的方法论

### 2.1 总体框架：COVE

COVE（Channel Orchestrated Volatility-aware Evolution）是一个统一的智能体自进化框架，将基于外部机制与基于参数的学习整合到统一流程中，由三个核心机制组成。

### 2.2 三个核心机制

**（1）任务感知路由（Task-aware Routing）**

- 将通道选择形式化为**反馈条件决策策略**而非手工设计评分函数。
- 路由器的输入为任务描述 τᵢ 和反馈 fᵢ（包含结果状态、标量分数、诊断消息），通过受限判断模型输出结构化的决策记录 dᵢ = (mᵢ, sᵢ, rᵢ)，其中：
  - mᵢ：选定的进化通道，来自 {harness_only, parametric_candidate, hybrid}
  - sᵢ：描述任务行为特征的简短描述符（如 dynamic_tool、logical_rigor）
  - rᵢ：单句决策理由
- **路由判定逻辑**：
  - `harness_only`：失败源于易变知识或上下文知识，权重更新无益
  - `parametric_candidate`：任务奖励可内化的能力，难以用提示表达
  - `hybrid`：两种信号都明确存在（如形式化推理任务同时需要工具交互）
- 路由决策保留可解释性追踪，便于审查。

**（2）阶段感知调度（Stage-aware Scheduling）**

- 引入**阶段感知进化触发器**（Stage-aware Evolution Trigger），动态决定何时调用各通道，基于三个信号：
  - **性能平台期（Plateau）**：最近 w 轮的成功率/平均奖励提升低于阈值 ε
  - **数据充分性（DataSufficient）**：高质量轨迹数 |Dq| ≥ N
  - **冷启动失败（ColdStartFailure）**：前 k 个任务成功率低于阈值 τc
- 触发条件为：Trigger = Plateau ∨ DataSufficient ∨ ColdStartFailure
- 前两个条件支持"先外部探索、后参数内化"的常见路径；第三个条件支持"先参数训练、再外部探索"的冷启动路径（如 Lean 定理证明）。

**（3）KnowledgePO：双模态知识优化**

- **目标**：将外部记忆与参数学习形成闭环——外部记忆提高训练轮次质量，参数吸收稳定知识后降低对外部记忆的依赖。
- 知识被标记为三类，依据易变性判定：
  - **易变知识（Volatile）**：依赖外部表面形式（如 API 名、表结构），应保留在外部记忆并在训练中明确防止内化
  - **稳定知识（Stable）**：持久底层模式（如算法习语、推理例程），适合参数内化
  - **策略知识（Strategic）**：高层启发式（如调试计划），保留在记忆，仅在反复证据表明稳定性后内化
- **记忆感知 rollout（Harness-assisted Parametric）**：检索 top-k 记忆注入消息列表，提高 rollout 成功率；易变条目被包裹 `<volatile>...</volatile>` 标记。训练前对易变条目中的名称随机重命名，并施加**反背诵奖励（Anti-recitation Reward）**：若模型调用旧或未观察到的易变名称，则受罚：
  
  R = R_task − λ · I[uses stale or unobserved volatile name]
  
  该惩罚机制促使模型"读当前条目并按之行动"，而非"记住并重复"。
- **记忆释放（Parametric-assisted Harness）**：训练后对每个稳定记忆做 A/B 评估（有/无该记忆），若性能下降低于阈值且该记忆此前有正向效用，则标记为已内化、从在线检索集中释放（保留存档）。易变记忆永不释放，保证知识库精简化。

### 2.3 目标函数

整体目标是最大化累积任务效用，同时约束推理与训练成本：

max Σᵢ Rᵢ − α Σᵢ C_tokⁱ − β Σₘ C_trainᵐ

其中 Rᵢ 为任务奖励，C_tokⁱ 为提示 token 成本，C_trainᵐ 为第 m 次参数更新的计算成本。

## 6. 论文的主要结论与发现

1. **单通道自进化均存在瓶颈**：Lean 定理证明中外部记忆积累几乎无法提升成功率（<3%），错误类型不随记忆增加而下降；TableQA 中参数化学习在 API 重命名后成功率从 40.5% 骤降至 16.5%、API 调用正确率从 96.5% 降至 54.0%。
2. **通道选择需联合任务类别与学习阶段**：平台期触发的参数更新优于持续训练和仅外部机制进化；冷启动领域需要先参数训练建立最低能力。
3. **知识易变性是内外化判定的关键标准**：API 名等易变表面知识必须留在外部记忆；稳定推理模式可内化为参数。
4. **COVE 优于所有单通道基线**：在 Lean4、APPS、HotpotQA、MATH 上取得最佳性能，在 TableQA 上保持竞争力，且训练 token 减少 86%。
5. **路由器的价值在于效率而非单纯性能**：COVE 路由达到 65.0 平均性能，仅用 Always-Both 16% 的参数训练成本，效率是最昂贵策略的近 6 倍。
6. **反背诵奖励有效**：在 API 重命名下保持 92.5% 的 API 调用正确率（标准微调仅 54.0%），注意力分布显示模型从依赖记忆转向依赖当前指令。
7. **自进化的本质**：应将反馈视为异质知识，按其稳定性与复用模式匹配存储与更新机制，而非统一视为训练数据。
