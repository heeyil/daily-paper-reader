## 摘要
多模态持续指令调优（MCIT）使多模态大语言模型能够顺序获取新任务，同时保留先前学习的能力。许多近期方法维护任务特定的LoRA专家，并在推理时将每个输入路由到一个或多个专家。然而，专家路由背后的任务识别问题仍未得到充分探索。我们表明，在广泛使用的MCIT基准上，路由几乎已饱和。泄露任务身份的文本指纹以及仅有少数竞争专家的4-10个任务的短序列，共同掩盖了长时程路由问题。为揭示这一挑战，我们引入了FLEX（去指纹长时程专家检验），这是一个具有削弱文本指纹的34任务长时程MCIT基准。FLEX将具有相似指令和答案格式但视觉与知识领域多样化的任务分组，归一化其外部模板，并在显著更大的专家池上评估路由。关键地，我们将渐进式LoRA路由形式化为软任务即类别的多模态类增量学习（MCIL）：每个任务定义一个增量路由类别，其完整得分分布提供LoRA混合权重，而硬路由是离散的特例。FLEX暴露了这一扩展的任务识别挑战，而MCIL公式为将CIL方法迁移到专家路由提供了原则性接口。我们将PureLoRA实例化为受控基线，并将四种CIL方法适配到四种MCIT框架，无需修改其LoRA专家或生成流程。我们的即插即用路由器将严格LoRA匹配提高了最多16.3个百分点，整体MacroScore提高了最多4.6个百分点。代码可在 https://github.com/RINC-CL/FLEX 获取。

## Abstract
Multimodal Continual Instruction Tuning (MCIT) enables multimodal large language models to acquire new tasks sequentially while retaining previously learned capabilities. Many recent methods maintain task-specific LoRA experts and route each input to one or more experts at inference. Yet the task-identification problem underlying expert routing remains under-explored. We show that routing is nearly saturated on widely used MCIT benchmarks. Textual fingerprints that leak task identity and short 4--10-task sequences with few competing experts jointly obscure the long-horizon routing problem. To expose this challenge, we introduce FLEX (Fingerprint-reduced Long-horizon Expert eXamination), a 34-task long-horizon MCIT benchmark with weakened textual fingerprints. FLEX groups tasks with similar instruction and answer formats but diverse visual and knowledge domains, normalizes their outer templates, and evaluates routing over a substantially larger expert pool. Crucially, we formulate progressive-LoRA routing as soft task-as-class Multimodal Class-Incremental Learning (MCIL): each task defines an incremental routing class, whose complete score distribution supplies the LoRA mixture weights, with hard routing as a discrete special case. FLEX exposes this expanding task-identification challenge, while the MCIL formulation provides a principled interface for transferring CIL methods to expert routing. We instantiate PureLoRA as a controlled baseline and adapt four CIL methods to four MCIT frameworks without modifying their LoRA experts or generation pipelines. Our plug-in routers improve strict LoRA matching by up to 16.3 percentage points and overall MacroScore by up to 4.6 points. Code is available at: https://github.com/RINC-CL/FLEX

- 当前主流方法采用**任务特定 LoRA 专家**机制，推理时需要先通过路由模块（router）估计输入应激活的历史 LoRA 权重，再进行生成（即"路由-组合-推理"范式，如 MoELoRA、HiDe-LLaVA、DISCO、SAME 等）。
- 论文发现：**现有 MCIT 基准上专家路由已接近饱和**——即模型几乎可以"完美"地恢复任务身份，使得任务无关的推理近似等同于任务感知的专家选择，路由能力未被真正检验。
- 这种路由饱和由两个共性原因导致：
  1. **文本指纹泄漏**：现有任务的指令中存在表面化的任务接口、模板或字段，无需图像理解即可暴露数据集身份（类似"捷径学习"）；
  2. **任务序列过短**：CoIN、UCIT、TriGap 等基准仅含 4–10 个任务，可用竞争的 LoRA 专家过少，路由空间被显著压缩。

## 论文提出的方法论

### 核心思想

- 提出 **FLEX（Fingerprint-reduced Long-horizon Expert eXamination）**——一个 34 任务的长时程 MCIT 基准，旨在弱化文本指纹并使路由更具挑战性。
- 提出一个重要理论视角：**将渐进式 LoRA 路由形式化为"软任务即类别（soft task-as-class）的多模态类增量学习（MCIL）"**——每个新任务即为一个增量类别，路由分类问题等价于类别增量分类问题，硬路由是离散特例，软路由是保留置信度的连续松弛。
- 基于该理论连接，可直接将既有 CIL/MCIL 方法迁移为"即插即用"路由器，在不修改 LoRA 专家与生成管线的前提下提升路由质量。

### FLEX 基准构造

- **任务构成**：34 个任务，分为 4 类任务格式——5 个 ImageNet-200 分类任务、2 个图像描述（captioning）、7 个多项选择、20 个短答式 VQA 任务。
- **去指纹策略**：
  - 将具有相似指令与答案格式的任务分组，仅在组内归一化外层答案格式模板；
  - 保留必要的特殊字段（如 OCR token、选择题选项块）以不改变任务本质；
  - 引入可混淆的同类任务（如 5 个 ImageNet 子集），消除"格式→任务身份"的一对一映射。
- **规模**：总计 388,856 个训练样本、85,037 个测试样本，每个大数据集采样 10,000 训练/3,000 测试，ImageNet 子集各 30,000 训练样本。

### 软任务即类别 MCIL 路由框架

- 每个任务 k 的所有样本标记为路由标签 c=k，丢弃原始目标回答，构成增量类别集 C_t={1,...,t}。
- 硬路由：选择 arg max 得分激活对应 LoRA；软路由：对任务得分做带温度τ的 softmax，输出完整分布作为 LoRA 混合权重。
- 既有方法（如 HiDe-LLaVA、DISCO）的 CLIP 原型相似度路由被重新解读为**冻结特征上的最近类均值（NCM）分类器**——只是 MCIL 路由的一个简单实例，因此可用更先进的 CIL 方法替代。

### 四种即插即用 CIL 路由器

- **HC（Hierarchical Classifier）**：为每个任务构建层次聚类原型，以输入与原型最大余弦相似度打分。
- **HC-SOINN**：通过自组织增量神经网络建立原型图，根节点距离与局部密度给出任务得分。
- **RanPAC**：对路由特征做固定随机投影+ReLU，采用闭式岭回归分类器输出任务 logits。
- **DDAS**：为每个历史任务维护一个轻量自编码器，以拼接多模态特征的负重建误差作为路由得分。
- 各方法双模态得分按目标框架的模态权重进行融合，随后按目标框架策略转为软/硬 LoRA 权重。
- 同时提出 **PureLoRA**——一个仅包含任务独立 LoRA 训练、多模态原型路由、软 LoRA 组合的受控基线，作为路由器替换的可控测试平台。

## 实验设计

### 基准与数据集

- **FLEX**（34 任务）：主要评估基准。任务涵盖 5 类 ImageNet-200 分类、2 个描述任务（Vizcap、Flickr30k）、7 个多项选择任务（ArxivQA、ScienceQA、PMCVQA、AI2D 等）、20 个短答 VQA 任务（GQA、DocVQA、ChemVQA、PathVQA 等）。
- **既有标准基准**（用于跨基准验证）：CoIN（8 任务）、UCIT（6 任务）、TriGap（10 任务）。
- 消融与诊断实验在 FLEX 的构造变体上进行（如 strong/weak 指纹、短/长序列、前缀匹配专家池缩放）。

### 对比基线

- 宿主框架：HiDe-LLaVA、DISCO、SAME，加受控基线 PureLoRA。
- 每个框架集成 4 种 CIL 路由器（HC、HC-SOINN、RanPAC、DDAS），共 16 个路由增强变体，外加各框架 Base（原始路由），合计 **20 个完整配置**。
- 还设置 Oracle（真值 one-hot 路由）作为诊断上界参考。

### 评估指标

- **MacroScore（M）**：所有已学任务最终得分的均值。
- **Macro Ground-Truth Weight（G）**：正确 LoRA 获得的平均软权重。
- **Overall Matching Rate（R）**：top-1 预测准确率（严格匹配率）。

### 主要实验发现

- 在路由敏感框架（DISCO、SAME、PureLoRA）上，12 个 CIL 迁移全部提升 M 与 G（12/12），R 提升 10/12；平均 M 提升分别为 2.41（DISCO）、2.91（SAME）、0.82（PureLoRA）。
- 最强路由器：DISCO+DDAS 提升 +4.61 至 M=54.93；SAME+RanPAC 提升 +4.05 至 M=54.21；PureLoRA+RanPAC 提升 +1.54 至 M=56.14。
- **Oracle 缺口恢复**：DISCO 恢复 47.6%、SAME 恢复 50.2%、PureLoRA 恢复 28.3% 的 Base 到 Oracle 缺口。
- HiDe-LLaVA 对路由不敏感（M 仅波动 0.26），主因是既有的 delta_mean 共享历史融合成为生成瓶颈（附录 S2.1 有系统归因）。
- 软路由校准实验显示：固定原型与专家，只调 logit 尺度时 ×80 软路由器优于 ×28 Base 和硬路由（M=56.27 vs 54.60/54.26），说明**校准的软混合可优于硬选择**。
- 强制错误专家迁移实验显示：6 组频繁混淆中 5 组错误专家显著劣于软混合（最差 ImageNet200_1→ImageNet200_2，-45.06），但 GQA→VQAv2 有 +2.13 正迁移，说明专家兼容性决定错误代价。

- 另含大量诊断性消融（如 DISCO 投影仪冻结试验、HiDe 的 4 种 remain 融合协议对比）与效率测量。

### 充分性与客观性

- **充分性评价**：实验全面，覆盖"主结果→机制分析→消融诊断→鲁棒性检验→泛化验证（换骨干、换基准）"的完整链条；在多达 20 个配置、34 个任务的长序列上验证，规模在 MCIT 领域属较高水准。
- **客观性**：引入严格的受控协议（固定专家、固定生成、仅替换路由器），使下游指标变化可归因于路由质量；对不理想的基线（如 HiDe 初始移植崩溃、DISCO 投影仪漂移）做了透明披露并标记"(fixed)"；种子鲁棒性检验排除随机因素。
- **公平性**：所有 CIL 方法在同一协议下迁移，不额外训练 LoRA，不接触生成；
- **偏差风险**：对 HiDe 的官方实现不匹配问题做了详细归因，却可能引入对照方法（即论文自身的 re-implementation）与官方配置的偏差；基准构造中保持的领域多样性虽真实，但 FLEX 仍是"构造性"基准而非自然涌现的长任务序列。

## 论文的主要结论与发现

1. **现有短路路由饱和问题被证实与诊断**：短序列 + 文本指纹使路由接近"Oracle"，任务无关推理退化为任务感知选择。
2. **FLEX 有效打破路由饱和**：在 9/9 的 G 对比、8/9 的 R 对比上均使路由难度显著上升；强指纹注入可恢复高匹配率，确认文本因素是关键成因。
3. **MCIT 路由可以自然映射为软任务即类别的 MCIL**：渐进式 LoRA 的"任务↔专家"一一对应关系提供了形式化桥梁；基于 NCM 的现有路由只是 MCIL 的简单实例。
4. **CIL 方法可作为高效即插即用路由器**：HC/HC-SOINN/RanPAC/DDAS 在路由敏感的框架上一致提升 M、G、R，且额外存储/延时开销极低。
5. **软路由优于硬路由**：校准的软混合（×80 scale）高于硬 top-1 路由（56.27 vs 54.26），保留置信度可适度复用兼容 LoRA。
6. **路由质量预测下游增益**：任务间 Spearman ρ=0.709（p=0.002）表明 top-1 匹配提升与 M 提升一致共变；GT 权重的提升若未改善 top-1 则收益有限（如 HiDe）。

## 优点

- **问题发现深刻且可验证**：通过统计（高 R/G）与可视化并借助图 1 的 Task–LoRA 匹配图直观展示路由饱和，对领域现有评估形成重要警示。
- **基准设计精细**：FLEX 不是简单"加长序列"，而是从"文本指纹"源头、任务格式分组、可混淆对手、长专家池等多个维度系统设计，且用 Strong fingerprint注入和前缀匹配池扩展两项消融分离各因素贡献。
- **理论视角创新**：路由→MCIL 的形式化连接为 CIL 方法在 MCIT 路由中的复用提供了统一的数学接口（soft/hard 统一框架），具备可推广的学术价值。
- **实验控制严谨**：受控协议（冻结专家与生成、只换路由器）、强制正迁移/负迁移诊断、软路由尺度校准、种子鲁棒、跨骨干、跨基准、任务顺序敏感性、模态融合敏感性等多角度验证，证据链完整。
- **工程实用性好**：路由器额外存储与延迟极低，即插即用，具备强部署潜力；对 HiDe/DISCO 初始移植失败做了详细分析与修正，展示了高水平的复现严谨性。

## 不足与局限

- **基准构造人为性**：FLEX 是通过手工分组/模板归一化"构造"出的去指纹长序列基准，虽贴近现实的开放域持续学习，但其任务格式分布（5/2/7/20）仍是设计者选择的产物，不能完全代表自然演化的长时程任务流。
- **软路由尺度依赖**：最优阈值（如 τ=28、κ=10⁵、T=0.03 等）需按框架手工配置；logit scale 对性能影响显著，论文未给出自动校准方案，限制了部署时的自适应性。
- **HiDe-LLaVA 路由不敏感性未被解决**：其 delta_mean 共享历史融合成为瓶颈，即使路由大幅改进下游 M 几乎不动；论文只诊断与标注了该问题，未提出对 HiDe 的修复或加速方案。
- **DDAS 的时序成本**：每个任务需额外训练一个自编码器（400 Adam steps），在更长序列中存储与巡检成本线性增长，论文虽报告了当前 34 任务的开销，但未系统评估 100+ 任务时的扩展性。
- **骨干固定**：路由特征仅来自冻结的 CLIP L/14，未验证更强/更新的视觉-语言编码器（如 SigLIP、EVA-CLIP）对路由质量上限的影响（仅有一种 InternVL 骨干补充实验）。
- **实验硬件特殊性**：T-Head Zhenwu 810E PPUs 非业界主流 GPU，训练时长的可比性有待在 A100/H100 上复现确认。
- **任务序列相对而言仍短**：34 任务虽显著大于既有 4–10 任务，但对真实开放世界持续学习（数百任务）的结论外推仍有限。
