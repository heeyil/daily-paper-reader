## 摘要
大语言模型可以通过强化学习改进搜索代理，然而现有的自对弈代理在反复生成任务时，会丢弃在成功搜索中获得的知识。我们提出了CoEvoKG框架，该框架将知识图谱转变为可验证训练任务的来源和代理进化的持久证据记忆。CoEvoKG联合训练任务生成器和搜索代理：生成器从知识图谱中采样的实体链创建多跳问题，而代理则根据奖励进行学习，奖励基于答案正确性和搜索轨迹（其实体路径由图谱证据支持）。当一次搜索成功时，CoEvoKG会验证并去重检索到的证据，然后将其写回相应的图谱节点和边。未来的轮次复用该增强图谱以生成任务和计算奖励，从而形成模型自我进化与知识积累之间的闭环。在六个问答基准（NQ、TriviaQA、PopQA、HotpotQA、2WikiMultiHopQA和Bamboogle）上使用三个骨干模型的实验表明，CoEvoKG相比对应基础模型，在Qwen2.5-3B-Instruct、Qwen2.5-7B-Instruct和Llama-3.1-8B-Instruct上的宏平均准确率分别提高了+11.2、+10.1和+11.6个百分点。在匹配的训练预算下，CoEvoKG在三个骨干模型上进一步超过了竞争性自对弈基线和搜索代理的强化学习基线，宏平均点数提高了+2.6至+3.7。代码可在https://github.com/lazzy1225/CoEvoKG获取。

## Abstract
Large language models can improve with reinforcement learning for search agents, yet existing self play agents repeatedly generate tasks while discarding the knowledge gained during successful searches. We introduce CoEvoKG, a framework that turns a   knowledge graph into both a source of verifiable training tasks and a persistent evidence memory for agent evolution. CoEvoKG jointly trains a task generator and a search agent: the generator creates multihop questions from entity chains sampled   from the knowledge graph, while the agent learns from rewards for answer correctness and search trajectories whose entity paths are supported by graph evidence. When a search succeeds, CoEvoKG verifies and deduplicates the retrieved evidence, then   writes it back to the corresponding graph nodes and edges. Future rounds reuse this enriched graph for task generation and reward computation, closing the loop between model self evolution and knowledge accumulation. Experiments on six QA benchmarks   (NQ, TriviaQA, PopQA, HotpotQA, 2WikiMultiHopQA, and Bamboogle) with three backbone models show that CoEvoKG improves macro average accuracy over the corresponding base models by +11.2, +10.1, and +11.6 points on Qwen2.5-3B-Instruct,   Qwen2.5-7B-Instruct, and Llama-3.1-8B-Instruct, respectively. Under matched training budgets, CoEvoKG further improves over competitive self play baselines and RL baselines for search agents by +2.6 to +3.7 macro average points across the three   backbones. Code is available at https://github.com/lazzy1225/CoEvoKG.

## 1. 核心问题与整体含义（研究动机和背景）

- 大语言模型（LLM）可通过带可验证奖励的强化学习（RLVR）提升搜索代理能力，但现有方法存在两个关键障碍：
  - **静态任务分布**：基于固定人工问答池训练（如 Search-R1），奖励验证容易但训练分布受限，难以扩展到更难的多跳任务；无约束生成又容易产生模糊、不可答或琐碎的问题。
  - **知识浪费**：自对弈式自我进化（如 Search Self Play, SSP）虽然让模型自生成任务，但循环不稳定（任务过易/过难/不可验证），且成功搜索后获取的证据被直接丢弃，无法积累。
- 论文核心洞察：**知识图谱（KG）实体链可同时扮演两个角色**——可验证的多跳任务源头 + 可持久累积搜索证据的外部记忆。
- 由此提出 CoEvoKG 框架，形成“模型自我进化 ⇌ 知识积累”的闭环：任务生成器从 KG 链生成问题，搜索代理求解并验证轨迹，成功证据写回图谱，后续轮次复用增强图谱。

## 2. 方法论（核心思想、技术细节、算法流程）

### 2.1 总体架构

- 联合训练两个策略：
  - **提议者（Proposer）πp**：给定证据链 `c = (e1, r1, e2, ..., eL)`，生成问题 q 和从链中选择的答案实体 a。
  - **求解者（Solver）πs**：使用搜索工具回答 q，产生多轮轨迹 τ 和最终答案 y。
- 共享一个持续进化的图谱记忆池 `Gt`，初始由 KILT 知识图谱（Wikipedia 链接结构）离线随机游走构建 2–3 跳实体链，节点携带文章段落，边带关系标签。

### 2.2 任务生成（KG 链 → 问题）

- 提议者基于链的实体路径和节点文本，生成满足以下条件的问题：
  - 问题中不出现链实体名称（防泄露）；
  - 需要至少两跳推理；
  - 答案唯一且简短（答案实体可从链中任意位置选择，避免位置泄露）。
- 每条链采样 M 个候选，通过**质量门（Quality Gate）**：
  - 轻量确定性过滤器去除损坏/泄露候选；
  - LLM 验证器检查链忠实性、真多跳需求、单一答案焦点和清晰度，并强制执行无泄露约束：
    - `Q(q,a,c) = 1[no leak] · Verify(q,a,c) ∈ [0,1]`
  - 仅保留阈值以上的候选，同一链所有候选在一次分组调用中判定，降低成本。
- 若某链无候选通过，则用种子池（人工 QA）回退填充批次，保证批次完整；种子回退率从约 0.40 降至 0.25，始终为少数。

### 2.3 奖励设计（路径支持 + 难度）

- **求解者奖励**（同步优化答案正确性和证据支持）：
  - `Rs = Rans · (1 + β Spath)`，其中 `Rans ∈ {0,1}` 为答案正确性，`Spath ∈ [0,1]` 为路径支持分数，β=0.2。
  - 路径支持验证：从轨迹中提取实体路径 `ĉτ`，与当前证据图比较，对每个相邻实体对计算确定性支持分数 `M(u,v)`（组合顺序、互提、共现，以及一跳桥接），再取几何平均：
    - `Spath = exp( (1/(L-1)) Σ log(M(êi,êi+1)+ε) )`
  - 几何平均保证任一跳缺乏支持都会显著拉低总分，防止“端点正确但中间跳随机”的投机行为。
  - 过程奖励仅对正确轨迹生效，避免奖励未支撑的猜测。

- **提议者难度奖励**：
  - 用 G 次求解者 rollouts 的成功率 `ps` 估计问题难度，采用单峰钟形奖励：
    - `Rdiff = exp( -(ps - p*(t))² / (2σ²) )`
    - 目标成功率 `p*(t)` 从高值退火到低值，使问题始终处于求解者当前能力边界附近，避免过易或不可解。
  - 问题质量由上游硬门控保证，不作为奖励项，因此提议者只在已通过质量门的候选中优化难度。

### 2.4 验证图记忆（证据写回）

- 对满足 `Rans=1` 且 `Spath ≥ τpath` 的轨迹，将其检索到的实体证据写回来源链的节点和关系，形成更稠密的图 `Gt+1`。
- 用实体序列哈希去重：新序列成为新链，已有序列仅合并新证据。
- 富化后的链返回池中，供后续轮次提议者采样和验证器参考，实现知识持久累积。

### 2.5 优化流程

- 后端：veRL + SGLang，异步多轮 rollouts，两者均使用 PPO 风格截断代理目标 + 低方差 KL 惩罚。
- 求解者：GRPO（组内相对优势，组大小 G=8）。
- 提议者：REINFORCE++（全局归一化累计折扣回报，难度奖励在终端 token 上）。
- 每轮顺序：提议者从当前池采样候选 → 质量门过滤 → 求解者对每个通过问题执行 G 条轨迹 → 更新两个策略 → 应用证据写回，进入下一轮。

## 7. 优点

- **创新闭环**：首次将知识图谱同时作为任务生成器和持久记忆，让模型进化与知识积累互为因果，解决自对弈中知识丢弃的问题。
- **可验证任务源**：用结构化 KG 链代替无约束生成，天然保证多跳性、可答性和可验证性，并通过质量门防泄露。
- **细粒度奖励**：路径支持过程奖励（几何平均）能区分“证据支撑的推理”和“侥幸答对”，难度退火奖励让任务始终贴近能力边界。
- **确定性路径验证**：无需 LLM 的轻量支持评分（顺序/互提/共现 + 桥接），可解释且高效，且可替换为更复杂模型。
- **严格的评估设计**：匹配训练预算、统一检索栈、排除评估子集的验证集划分、外部基准上的统计检验，提高了结论可信度。
- **稳定性设计**：种子回退、低方差 KL 惩罚、低概率 token 优势缩放等细节保障自对弈不塌缩。

## 9. 总体评价与研究意义

- CoEvoKG 的价值不在于某一模块的单独创新，而在于重新定义了自对弈式搜索代理的进化单元：**以知识图谱为核心，把“可验证任务”与“可积累记忆”统一起来**，从而在任务分布自动扩增的同时，将搜索成功的证据沉淀为持久知识，缓解了自我进化系统常见的“原地打转”问题。

- 实验结果表明，在相同训练预算和骨干模型下，CoEvoKG 的一致优势主要来自更高质量、更高难度的动态任务分布与更稳定的训练动态，而非额外算力或外部监督，这使其具有较好的可复现性和可扩展性。

- 从方法演进角度看，该框架把“任务生成器–求解器–记忆库”三者耦合为闭环，为后续研究提供了一个通用模板：任何可结构化的外部知识（如代码依赖图、科学论文引用图、逻辑规则库）都可替换 KG，从而将方法推广到问答之外的领域。

- 从工程角度看，轻量级路径支持评分和批量质量门控显著降低了训练成本，使其能够在 3B–8B 模型上运行，说明该方法对算力受限团队也具备可行性；但论文未公布具体硬件配置，仍是复现时的主要障碍。

- 总体而言，CoEvoKG 在方法设计、实验严谨性和结果可信度上均达到较高水准，明确提出并验证了“知识积累与模型进化协同”这一重要方向。未来工作可沿着更强的记忆一致性校验、跨图谱泛化、更大规模骨干以及更丰富的评价指标展开，以进一步提升其边界。
