## 摘要
大语言模型（LLM）智能体越来越多地承担需要持续推理、工具使用和跨多个相互依赖步骤进行修订的长时程任务。然而，现有的智能体框架（harness）在持续增长的上下文中维护任务执行、任务状态和完成度评估，使得状态难以跟踪，并允许错误的自评结果传播到后续决策中。我们将长时程执行重新表述为任务状态管理问题，并提出 LongHorizon-Harness，它在执行过程之外显式维护任务状态，并且仅使用从环境中独立验证的事实来更新状态。其管理-执行-审计（MEA）循环使用一个管理器来维护任务状态并确定下一个子任务，使用一个全新上下文的执行器来执行该子任务，并使用一个只读审计器在下一轮之前验证最终的环境状态。一个轻量级的 AgentAdapter 支持可互换的模型和框架后端，而无需修改它们的原生智能体循环。LongHorizon-Harness 在 WeaveBench 上将 Qwen~3.7-Plus 从 51.8% 提升至 80.7%，在 Terminal-Bench~2.1 上从 69.7% 提升至 77.2%，在 OSWorld~2.0 上从 2.8% 提升至 8.3%。它还在 OSWorld2.0 子集上将 Claude Opus~4.7 从 20.0% 提升至 34.3%，展示了跨模型、框架和交互领域的一致性能提升。

## Abstract
Large language model (LLM) agents increasingly undertake long-horizon tasks that require sustained reasoning, tool use, and revision across many interdependent steps. However, existing agent harnesses maintain task execution, task state, and completion assessment within a growing context, making the state difficult to track and allowing incorrect self-assessments to propagate into later decisions. We reformulate long-horizon execution as a task-state management problem and propose LongHorizon-Harness, which maintains the task state explicitly outside execution and updates it only with facts independently verified from the environment. Its Manage-Execute-Audit(MEA) loop uses a manager to maintain the task state and determine the next subtask, a fresh-context executor to perform it, and a read-only auditor to verify the resulting environment state before the next round. A lightweight AgentAdapter supports interchangeable model and harness backends without modifying their native agent loops. LongHorizon-Harness improves Qwen~3.7-Plus from 51.8% to 80.7% on WeaveBench, from 69.7% to 77.2% on Terminal-Bench~2.1, and from 2.8% to 8.3% on OSWorld~2.0. It also raises Claude Opus~4.7 from 20.0% to 34.3% on an OSWorld2.0 subset, demonstrating consistent gains across models, harnesses, and interaction domains.

## 1. 核心问题与研究动机

- **背景**：大语言模型（LLM）智能体的能力日益增强，越来越多地被用于执行**长时程任务**——这类任务需要持续的推理、工具调用，以及跨越多个相互依赖步骤的反复修订。
- **核心问题**：现有智能体框架（agent harness）在处理长时程任务时，普遍存在一个结构性缺陷——它们**在持续增长的上下文中混合同步维护三件事**：
  1. 任务执行过程（execution traces）；
  2. 任务状态（task state）；
  3. 完成度评估（completion assessments）。
- **由此引发的两大危害**：
  - **状态难以追踪**：上下文过长导致任务进度信息变得模糊、容易被模型遗忘或混淆；
  - **错误自评传播**：智能体基于自身不可靠的自评结果修正后续行为，错误一旦产生，会逐步累积并污染后续所有决策，导致任务失败。
- **总体含义**：论文主张将"长时程执行"这一过程**重新概念化为一个任务状态管理问题**——即任务能否成功，关键在于能否准确、外部化地维护和验证任务状态，而非依赖模型在长上下文中的内隐记忆与自我判断。

## 2. 方法论：LongHorizon-Harness

### 2.1 核心思想

- 将**任务状态从执行上下文中剥离**，在执行过程之外以显式结构维护；
- 任何状态更新**只能基于从环境中独立验证的事实**，禁止使用模型的主观自评直接写入状态。

### 2.2 管理-执行-审计（MEA）循环

框架采用三角色分工的循环式工作流：

- **管理器（Manager）**：
  - 维护全局任务状态，负责分析当前进度、决定下一步要执行的子任务（subtask）；
  - 每次决策都基于外部维护的状态，而不是依赖长对话历史。
- **执行器（Executor）**：
  - 以**全新上下文（fresh context）** 执行管理器指定的单个子任务；
  - 不保留历史上下文，避免长程干扰与错误累积，专注于当前子任务的完成。
- **审计器（Auditor）**：
  - 以**只读（read-only）** 方式检查执行器操作后的环境实际状态；
  - 验证执行结果是否符合预期环境事实，将验证结果反馈给管理器以更新任务状态，然后进入下一轮循环。

### 2.3 关键机制设计

- **状态更新标准**：只有经过环境独立验证的事实才能用于更新任务状态，从根本上杜绝了"模型自我感觉良好但实际错误"的状态污染。
- **AgentAdapter 轻量适配层**：
  - 支持在**不同模型后端**（如 Qwen、Claude）和**不同框架后端**之间无缝切换；
  - 无需修改各框架原生的智能体循环，大幅降低接入成本，提升了方法的普适性。

## 6. 主要结论与发现

1. **现有框架的病根在于状态内隐化**：将执行、状态与评估混在增长上下文中，是长时程任务失败的结构性原因。
2. **显式外部状态管理有效**：将任务状态移出上下文，并以独立验证的环境事实驱动更新，可从根本上缓解状态追踪困难和错误自评传播问题。
3. **"全新上下文执行"可行且高效**：执行器不保留历史上下文，既避免了长上下文的干扰，又简化了模型负担。
4. **方法具有跨模型、跨框架、跨域的通用性**：在 Qwen 和 Claude 上、在多类任务场景中都取得了一致提升，证明该思路是通用的框架层改进，而非模型特定技巧。
5. **对弱小模型的增益尤为显著**：如 Qwen 在 OSWorld 上从 2.8% 提升到 8.3%，说明框架改进可以弥补模型在长程任务中的能力短板。

## 7. 方法优点

- **问题定位精准**：将长时程失败归结为状态管理而非单纯的"上下文太长"，直击现有 agent 框架的架构性缺陷。
- **架构简洁、解耦清晰**：管理-执行-审计三者职责分明，模块化程度高，便于理解和复现。
- **强事实约束**：状态更新以环境验证事实为准，不信任模型自评，从机制设计上杜绝了错误累积。
- **无需重新训练模型**：纯推理期机制改动，对现有模型即插即用。
- **适配层设计务实**：AgentAdapter 使得框架可以方便适配不同后端，降低迁移成本，实用性强。
- **长上下文成本更低**：执行器上下文始终保持简洁，避免了超长上下文的计算与注意力开销。

- **审计器的"金标准"依赖**：审计器需要能够从环境读取客观事实（read-only 环境检查），但在某些真实应用场景中，环境可能无法提供清晰、可验证的完成信号，审计环节的效果会受限。
- **缺少对错误传播的定量分析**：论文未展示"状态管理失败率"与"最终任务成功"之间的因果关联数据，论证主要基于端到端分数提升。
- **实验细节不完整**：未见消融实验、统计显著性检验、失败模式分析，难以完全排除框架间提示词差异等混淆因素。
- **覆盖率不对称**：Claude 只在单一基准子集上验证，跨模型的比较尚不全面。

- **应用边界**：论文聚焦于"可被环境验证"的任务状态，对于开放性、生成性或主观评价类任务（如写作、创意设计），该方法适用性存疑。
