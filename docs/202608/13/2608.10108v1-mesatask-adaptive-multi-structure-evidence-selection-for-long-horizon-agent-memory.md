## 摘要
长时程智能体会积累跨越数百个交错推理、行动和观察步骤的轨迹，回答查询时可能依赖于深埋在历史中的证据。外部记忆将此类轨迹存储为结构化表示，但每种结构都提供了不同且不完整的视图。现有的多记忆系统要么对每个查询读取固定的结构集合，从而膨胀上下文并引入噪声；要么将每个查询路由到单一结构，从而无法组合互补证据。在AMA-Bench上的受控分析表明，最优的记忆配置通常既不是单一结构，也不是全部结构的并集，而是随查询和任务需求变化的多结构记忆的定制组合。受这些发现启发，我们提出了结构级动态选择：从专门的记忆结构库中选择并融合查询自适应的子集。我们提出了MESA（一种面向长时程智能体的多结构证据选择框架），它为每条轨迹构建五个互补的结构视图，并利用端到端的答案级反馈进行学习，从而为冻结的答案模型选择和融合查询特定的子集。为了在这种弱监督下学习，MESA采用带先验引导搜索的束优化和带UCB引导调度的机制，以平衡探索和利用。在AMA-Bench上，MESA以比全结构方案少41%的证据标记，比最强基线高出8.5%的性能。

## Abstract
Long-horizon agents accumulate trajectories spanning hundreds of interleaved reasoning, action, and observation steps, where answering a query may depend on evidence buried far back in the history. External memory stores such trajectories as structured representations, yet each structure provides a distinct and incomplete view. Existing multi-memory systems either read a fixed set of structures for every query, inflating context and introducing noise, or route each query to a single structure, preventing the composition of complementary evidence. A controlled analysis on AMA-Bench shows that the optimal memory configuration is typically neither a single structure nor the full union, but a tailored composition of multiple structural memories that varies with query and task demands. Motivated by these findings, we formulate structure-level dynamic selection: selecting and fusing a query-adaptive subset from a library of specialized memory structures. We propose MESA (a Multi-structure Evidence Selection framework for long-horizon Agent), which builds five complementary structure views of each trajectory and learns from end-to-end answer-level feedback to select and fuse a query-specific subset for a frozen answer model. To learn under this weak supervision, MESA employs harness optimization with prior-guided search and UCB-guided scheduling to balance exploration and exploitation. On AMA-Bench, MESA outperforms the strongest baseline by 8.5% while using 41% fewer evidence tokens than the all-structure alternative.

### 一、核心问题与整体含义（研究动机和背景）

长时程（Long-Horizon）智能体会在交互过程中积累跨越数百个步骤的轨迹，这些轨迹交织着推理、行动、观察和工具调用，后续查询所依赖的证据可能深埋在很早的历史之中。直接向长上下文 LLM 输入完整轨迹既昂贵又不可靠（存在迷失在中间的问题），而截断或压缩则会丢失关键细节。因此，外部记忆系统成为重要解决方案，其核心问题在于：**执行历史应如何被组织以及如何被动态地调用？**

现有方法存在两类极端：
- **全量融合**：对每个查询固定读取所有结构的证据，最大化召回率但引入大量噪声、膨胀上下文窗口。
- **单结构路由**：为每个查询选择单一结构，表达能力受限，无法组合跨表示的互补证据。

论文通过控制性实验证明：**最优记忆配置既非单一结构也非全部结构并集，而是随查询和任务变化的定制化多结构组合**。据此正式提出"结构级动态选择"问题，并设计 MESA 框架求解。

### 二、方法论（核心思想、关键技术、公式与算法）

**核心思想**：构建五个互补的记忆结构视图，通过学习一个可执行的查询自适应选择策略，动态挑选并融合对当前查询最有价值的结构子集，送入冻结的答案模型。

1. **五种记忆结构**（每种均包含构建器与固定访问接口）：
   - **Summary (S)**：压缩的高层状态记忆，提供全局上下文但缺乏步骤细节。
   - **Temporal Store (T)**：保存原始动作—观察序列的按时间索引存储，保留时间顺序与精确步骤。
   - **Knowledge Graph (G)**：基于 OpenIE 抽取的关系图，支持实体间关系和因果遍历，但缺乏步骤级索引。
   - **Vector Database (V)**：基于 Qwen3-Embedding-4B 的步级稠密向量索引，提供语义相似证据。
   - **Raw Episodic Trace (R)**：原始轨迹的滑窗切分与 BM25 检索，保留精确表层证据但伴随噪声。

2. **问题形式化**：
   - 选择动作空间：\( z \in \{0,1\}^{K} \)，\(\|z\|_0 \ge 1\)，共 \(2^5-1=31\) 个非空子集。
   - 选择策略：\( z_i = S_\rho(q_i, c_i) \)。
   - 证据融合：\( E_i(z_i) = \text{Compose}(\{ \Gamma_k(q_i, M_i^{(k)}) \mid z_i^{(k)}=1 \}) \)。
   - 答案生成：\( \hat{y}_i(z_i) = F(q_i, E_i(z_i)) \)。
   - 优化目标（验证集）：\( \mathcal{J}_{\text{val}}(\rho) = J_{\text{val}}(\rho) − \lambda C_{\text{val}}(\rho) \)，其中 \(\lambda=10^{-6}\)，权衡准确率与证据 token 成本。

3. **Prior-Guided Harness Optimization（先验引导的束优化）**：
   - 为应对"答案级稀疏反馈下的信用分配"难题，将搜索空间限制在先验方向集合 \( A \) 上，覆盖需求推断、后端价值估计、子集构建、证据感知选择、鲁棒性与成本控制五个维度（共 20 个方向）。
   - 使用 **UCB 引导调度**（\(\beta=0.08\)）平衡探索与利用：每轮 LLM proposer 根据 UCB 统计和当前策略的反复错误，生成三个候选（利用候选、探索候选、修复失败候选）。
   - 候选策略在训练集上拟合、验证集上评估，更新策略档案；搜索预算 \( T=30 \) 轮后，返回验证目标最高的策略冻结测试。

### 三、实验设计（数据集、基准、对比方法）

1. **AMA-Bench**（主基准）：
   - 真实世界子集：208 个 episode，每个 12 个专家级 QA 对，共 2496 题。
   - 覆盖 6 个智能体域：Web 任务执行、开放世界工具 QA、Text2SQL、软件工程、游戏、具身 AI。
   - 覆盖 4 种记忆能力：回忆、因果推断、状态更新、状态抽象。
   - 划分方式：episode 级 2:2:6 训练/验证/测试，随机 5 次划分取均值。

2. **LoCoMo**（泛化性验证）：
   - 10 个多会话长对话，1986 个 QA 对；排除 446 个对抗性问题后评估 1540 题（含单跳、多跳、时间性、开放域）。
   - 对话级 2:2:6 划分。

3. **对比基线**（四个家族，共 11 个方法）：
   - 长上下文直接输入（Long-context）。
   - 检索方法：BM25 稀疏检索、Qwen3-Emb-4B 稠密检索。
   - 长期记忆系统：MemGPT、HippoRAG2、Mem0、MemoRAG、A-Mem、EMem。
   - 多结构记忆：Hindsight、AMA-Agent（基准专用 SOTA，同为最强基线）。

4. **评估指标**：AMA-Bench 采用 LLM-as-judge 准确率（judge 与答案模型同骨干）；LoCoMo 采用 Token-F1。

### 六、主要结论与发现

1. **最佳结构组合是中间态且任务相关**：全子集扫描表明，最优组合既非单一结构也非全部结构的并集，且随域和 QA 能力变化，不存在全局最优的固定组合。
2. **MESA 显著优于最强基线**：在 Qwen3-32B 骨干下整体准确率 65.1%，比 AMA-Agent 高 8.5 个百分点，比长上下文人读入高 12.5 个百分点；在 Gemma-4-31B 骨干下高达 69.4%，也远超各种基线。
3. **同时实现高效性**：MESA 平均选择 2.8 个结构、使用 11.0k 证据 token/查询，比全结构方案（18.7k token，63.7% 精度）高 1.4% 精度并少用 41.2% 的 token。
4. **学到的策略可解释且可泛化**：最终策略为可读的查询条件路由规则（如关键词映射），且能泛化到 LoCoMo 对话记忆场景（F1 49.0%，优于 EMem 1.8 分）。
5. **组件均有贡献**：先验方向消融使精度下降 2%，UCB 消融使精度下降 0.8% 且方差显著增大，说明两者共同稳定搜索。

### 七、优点（方法或实验设计上的亮点）

1. **问题定义清晰且富有洞见**：通过全子集扫描实验确立"中间子集更优 + 无固定最优组合"两个经验发现，将模糊的"记忆读取策略"问题精确形式化为结构级动态选择，填补了现有方法中"固定全读"和"单一路由"之间的空白。
2. **强可控性的实验范式**：保持记忆构建器、检索器、答案模型全部冻结，仅学习选择策略，隔离了选择机制本身的贡献，因果归因干净有力。
3. **弱监督下有效的优化设计**：先验方向将巨大提示/程序搜索空间压缩到有意义的结构选择机制上；UCB 调度解决了稀疏答案级反馈下的探索—利用平衡问题；最终策略为显式可读的规则，可解释性强。
4. **成本意识明确**：优化目标直接纳入证据 token 惩罚，实验同时报告精度与 token 成本，评估了效率—性能的帕累托改进。
5. **全面的实验验证**：跨两个骨干模型、两个基准、6 个域、4 种能力、多种消融与鲁棒性测试，实验面广且严谨。

### 八、不足与局限

1. **因果推理能力相对偏弱**：在 Qwen3-32B 骨干下，MESA 在 Causal Inference 上（63.6%）比 AMA-Agent（65.0%）低 1.4%，说明当前框架对跨事件、跨结构依赖的显式建模不足，且未针对这类问题设计专门的补偿机制。
2. **结构覆盖面有限**：仅采用五种代表性结构，其他记忆表示形式（如分层记忆、场景图、多模态记忆等）尚未纳入，限制了框架的扩展性。
3. **全部组件需要异质信息构建**：五种结构共享需要额外的 OpenIE 抽取、向量嵌入、摘要压缩等处理。离线构建时间（73.3 秒/轨迹）高于 AMA-Agent（38.2 秒），在需要快速冷启动的生产场景或轨迹规模极大时可能成为瓶颈。
4. **LoCoMo 评估规模偏小**：仅含 10 个长对话，且主表仅报告单次划分结果，统计效力较弱。
5. **算力统计缺失**：未报告总体 GPU 消耗和训练时间，复现成本难以估算。
6. **仅支持离线构建与优化**：当前框架要求先构建记忆再离线训练选择器，对持续更新、流式产生的轨迹记忆的适应性尚未验证。
7. **弱监督优化的搜索预算有限**：30 轮优化迭代对复杂策略空间的覆盖可能不充分，但对 LLM 生成候选也构成可行的计算约束，未来可探索更高效的空间搜索方法。
