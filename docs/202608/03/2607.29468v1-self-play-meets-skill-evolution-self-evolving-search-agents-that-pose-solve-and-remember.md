## 摘要
自博弈代理无需目标基准中的问题即可生成训练问题，但其课程缺乏持久状态：失败会影响梯度，但不会明确塑造未来的练习。外部技能记忆保留了程序性经验，但通常是从固定的任务分布中学习的。我们引入了SESA（自进化技能增强代理），它将程序性记忆作为工具增强搜索自博弈的演化状态。一个挑战者提出问题，而一个单独参数化的求解器独自检索技能。信息性失败被提炼为可复用的技能并写回记忆。更新后的记忆会改变求解器的行为和成功率，从而改变挑战者的奖励和未来问题的分布；由此产生的边界产生新的失败，从而重写记忆。这种双向循环使任务生成和技能记忆共同进化。由于检索到的技能塑造了同策略训练轨迹，它们的好处既能进入模型参数，也能保留在外部库中，从而实现无记忆部署和可选的推理时检索。在七个开放域和多跳问答基准上，在多种骨干网络上，SESA相对于SSP的平均准确率提高了1.2–3.2个百分点，并在统一评估协议下超越了技能增强的SkillRL基线0.9个百分点。在Qwen3模型上，SESA-Off相对于SSP保持了1.8–2.2个百分点的提升，而最终技能库又增加了0.5–1.0个百分点。这些结果表明，进化技能记忆不仅仅是一个推理时的插件：它改变了策略学习和未来的训练分布，同时保留了作为可选外部记忆的价值。我们的代码可在https://github.com/Zenghuang-Fu/SESA-Self-Evolving-Search-Agents获取。

## Abstract
Self-play agents can generate training problems without questions from target benchmarks, but their curricula lack persistent state: failures affect gradients yet do not explicitly shape future practice. External skill memories preserve procedural experience but are typically learned from fixed task distributions. We introduce \textbf{SESA} (Self-Evolving Skill-Augmented Agent), which makes procedural memory an evolving state of tool-augmented search self-play. A challenger poses problems, while a separately parameterized solver alone retrieves skills. Informative failures are distilled into reusable skills and written back to memory. The updated memory changes solver behavior and success, which changes the challenger's reward and the distribution of future problems; the resulting frontier produces new failures that rewrite memory. This bidirectional loop makes task generation and skill memory co-evolve. Because retrieved skills shape on-policy training trajectories, their benefits can enter the model parameters as well as remain in the external bank, enabling memory-free deployment and optional inference-time retrieval. Across seven open-domain and multi-hop question-answering benchmarks, SESA improves average accuracy over SSP by 1.2--3.2 points across multiple backbones and surpasses the skill-augmented SkillRL baseline by 0.9 points under a unified evaluation protocol. On Qwen3 models, SESA-Off retains 1.8--2.2 points of improvement over SSP, while the final skill bank adds a further 0.5--1.0 points. These results show that evolving skill memory is not merely an inference-time plug-in: it changes policy learning and the future training distribution while retaining value as optional external memory. Our code is available at https://github.com/Zenghuang-Fu/SESA-Self-Evolving-Search-Agents.

## 1. 核心问题与整体含义（研究动机与背景）

- **问题起点**：自博弈（Self-Play）智能体能通过内生方式生成训练问题，无需外部基准问题集，但其课程缺乏**持久状态**——失败轨迹仅贡献一次策略梯度便被丢弃，无法显式塑造未来的练习内容。与此同时，外部技能记忆（Skill Memory）虽能保留程序性经验，但通常从**固定任务分布**中学习，并不参与任务生成过程。
- **镜像缺陷**：自博弈"决定练什么却忘记教训"，技能增强RL"记住教训却来自非自选的任务"。本文的核心动机是构建一个**既能自主选择练习边界、又能保留自身失败教训**的统一框架。
- **解决思路**：将程序性记忆作为工具增强搜索自博弈中的**演化状态（evolving state）**，让任务生成与技能记忆形成**双向反馈闭环**，共同演化。

## 2. 方法论

### 2.1 总体框架

SESA（Self-Evolving Skill-Augmented Agent）构建于零数据搜索自博弈（Search Self-Play, SSP）之上，核心包括两个角色和一个记忆模块：

- **挑战者（Proposer）**：负责任务生成，提出带有可验证目标的问题；
- **求解器（Solver）**：负责解题，检索技能并调用搜索工具；
- **技能记忆库 B（Skill Bank）**：非参数化的可检索策略集合，由求解器自身失败蒸馏产生。

### 2.2 关键技术与公式

**1. 技能表示**：每个技能存为五元组：

s = (u, c, a, z, m)

其中 u 为描述、c 为触发条件、a 为规避线索（反模式）、z 为可复用查询模板、m 为检索/有用/有害计数（用于记忆维护）。

**2. 记忆初始化（Memory Priming）**：B₀ = B_seed ∪ B_warm，包含 15 条手写技能 + 142 条自博弈引导阶段挖掘的技能，共 157 条初始条目。

**3. 不对称自博弈（Asymmetric Self-Play）**：挑战者和求解器使用**独立参数**。技能检索仅暴露给求解器，挑战者看不到记忆内容，防止解法策略泄漏，保持"出题—解题"对抗的非对称性。

**4. 目标函数**：基于 GRPO（Group Relative Policy Optimization）无评论家策略梯度。求解器对每个问题采样 G 条搜索轨迹，奖励为可验证的答案正确性：

r_s(τᵢ, a*) = 1{Judge(âᵢ, a*) = 1}

检索到的技能上下文 R(q; Bₜ) 进入 on-policy 轨迹生成，因此技能能**重塑策略梯度的轨迹分布**。

**5. 边界塑造（Frontier Shaping）**：使用铃形、端点惩罚的奖励函数引导挑战者生成"求解器当前能力边界附近"的问题：

r_p(x) = −λ（当 p̂_s ∈ {0,1}），否则 4(ℓ + p̂_s)(h − p̂_s)

即完全答对或完全答错的问题均被惩罚，奖励在中等成功率处达到峰值，持续推动挑战者随着求解器提升而提出更难的问题。这一设计避免了简单"1−准确率"奖励对不可解问题的过度奖励。

**6. 失败蒸馏（Failure Distillation）**：三步生命周期——

- **检索**：用稠密编码器（E5-base-v2）检索与问题最相关的 top-3 技能；
- **失败收集**：有信息量的边界失败进入 300 条待处理队列，每 10 步且累计≥20 条时触发合并，优先选择重复失败和检索技能后仍失败的样本，每次最多合并 30 条；
- **合并（Consolidation）**：用 DeepSeek-v4-pro 将失败抽象为技能卡片（含触发条件、区分证据、规避线索、查询模板），并要求与现有库的余弦相似度 ≤ 0.93 才允许入库；非种子技能在检索≥3次且"有用数−有害数"为负时被淘汰，库容量上限 800 条。

**7. 双路径技能复用**：训练完成后的部署有两种模式——

- **SESA-Off（无记忆部署）**：仅用训练后的策略参数，技能收益已内化；
- **SESA-On（记忆增强部署）**：推理时同时启用最终技能库进行检索。

## 6. 主要结论与发现

- SESA 在多个骨干模型上一致提升：对 Qwen3 系列较 SSP 提升 2.3~3.2 个平均点，LLaMA-3.1-8B 上提升 1.2 点，且高于对应 Base 模型 7.0~10.9 个点。
- **技能收益主要驻留在策略参数中**：SESA-Off 在 Qwen3 上较 SSP 保留 1.8~2.2 点增益；启用最终技能库再增加 0.5~1.0 点。即技能驱动的训练是"训练机制"而非"推理提示技巧"。

- 训练动态显示：验证质量稳定上升、问题提取成功率持续提高、活跃技能先增后减，体现了记忆的"自我精炼"特性。

## 7. 优点
