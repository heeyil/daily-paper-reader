## 摘要
大型语言模型代理越来越多地被评估为自主工具使用者，但大多数基准测试侧重于具有即时成功标准的有限任务。实际部署通常需要长期连贯性，即在长时间范围内保持有目的行为并适应累积证据作出决策的能力。评估这种能力需要一个持久环境，其中行动限制未来选择，反馈以异构延迟到达，不一致的行为产生可衡量的累积效应。卖方端电子商务通过产品采购、列表与定价控制、现金流管理以及混合延迟反馈适应中的重复和相互依赖决策，为此评估提供了合适的环境。我们引入了MerchantBench，一个基于98,843条真实电商产品记录的365天订单级模拟，并配备了26个用于代理交互的工具。MerchantBench将即时可观察的上游供应商事件与延迟的下游订单结果相结合，要求代理跟踪单个订单生命周期并重新审视早期决策。我们在两个代理框架下评估了八个LLM，进行了48次运行，每次跨越365个模拟日。我们的结果揭示了即使是最新的LLM与人类参与者之间也存在显著差距，最佳LLM配置仅达到人类参与者平均最终净资产的27.3%。

## Abstract
Large language model agents are increasingly evaluated as autonomous tool users, yet most benchmarks focus on bounded tasks with immediate success criteria. Real-world deployments often require Long-Term Coherence, the capacity to preserve purposeful behavior across extended horizons while adapting decisions to accumulated evidence. Evaluating this capacity requires a persistent environment in which actions constrain future choices, feedback arrives at heterogeneous delays, and incoherent behavior produces measurable cumulative effects. Seller-side e-commerce provides a suitable setting for this evaluation through recurrent and interdependent decisions over Product Sourcing, Listing and Pricing Control, Cash-Flow Management, and Mixed-Latency Feedback Adaptation. We introduce MerchantBench, a 365-day order-level simulation grounded in 98,843 real e-commerce product records and equipped with 26 tools for agent interaction. MerchantBench couples promptly observable Upstream Supplier Events with delayed Downstream Order Outcomes, requiring agents to follow individual order lifecycles and revisit earlier decisions. We evaluate eight LLMs under two agent frameworks in 48 runs, each spanning 365 simulated days. Our results reveal a substantial gap between even the latest LLMs and human participants, with the best LLM configuration attaining only 27.3\% of the mean final net assets achieved by human participants.

### 3. 实验设计

- **基准环境**：MerchantBench 本身即为基准，环境参数固定（初始现金 RMB 2,000、保证金 RMB 1,000、最多 50 个在售商品）。
- **数据集**：1688 平台 2025-06-01 至 2026-05-31 的真实产品、供应商与需求数据。
- **评估对象**：

  - **2 个代理框架**：ReAct（轻量控制）与 Hermes（含代码执行、记忆、技能管理等内置能力）；

  - 业务表现：最终净资产、GMV、净利润率、订单数；

### 6. 论文的主要结论与发现

- **整体性能差距显著**：最佳 LLM 配置（Hermes + Qwen3.7-Max）仅达到人类参与者平均最终净资产的 **27.3%**，GMV、订单量等指标也大幅落后。
- **框架影响明显**：Hermes 相比 ReAct 平均提升最终净资产 53.3%、GMV 71.5%、订单数 71.2%，但收益因模型而异（如 Kimi K2.6 反而下降 4.1%）。
- **长期连贯性失败模式**：
  - **操作性连贯性衰退**：部分代理随运行推进减少环境干预，持续窗口率最低可至 10.6%；如 Qwen3.7-Max 的窗口率从 62% 降至 37%（Hermes）或从 68% 降至 23%（ReAct）。
  - **战略性连贯性缺失**：表现为控制回路窄化（退化为被动响应供应商事件）、过早放弃（某 Kimi K2.6 运行在第 104 天判定店铺不可恢复后近乎停止行动）、目标漂移、以及不依据证据调整策略（如错误记忆、虚假推断导致货架持续收缩）。
- **风险传导与适应差异**：较好模型能将延迟订单结果归因到具体产品并替换；较差模型只做异常检测而缺乏“归因—移除风险—需求保持替换”的完整链条；店铺评分下降还会跨产品压制需求。
- **采购与需求对齐**：人类参与者的月度需求对齐百分比持续上升（从 56.1 升至 80+），而多数 LLM 改善较弱或不稳定；且仅对齐需求不够，还需保证货架宽度与利润转化。

- **评估体系完备**：除最终资产外，还设计了店铺可靠性、长期活动度、持续窗口率、月度需求对齐、时间感知采购增益等指标，能刻画不同层面的连贯性失败。

### 8. 不足与局限

- **统计稳健性不足**：每个配置仅 3 次运行，LLM 行为方差大（如 Hermes 下 Qwen3.7-Max 变异系数 55.1%），结论可能受随机性影响；未做显著性检验。
- **缺乏消融实验**：未系统分析各组件（如延迟反馈、店铺评分、供应商事件、现金流约束）对长期连贯性的独立贡献；也未对工具集进行删减测试。
- **人类基线样本小**：仅 3 名无经验参与者，不能代表熟练商家；人类操作通过专门仪表板完成，与 LLM 的交互方式不完全可比。
- **上下文管理干扰**：两种框架都使用历史压缩/摘要，压缩质量可能成为能力差异的混杂因素；摘要模型即被测模型本身，存在偏差风险。
- **模拟简化**：采用单件代发货模型，未涵盖库存预置、广告投放、多店铺协同等真实电商运营要素；平台规则与真实 1688 平台存在简化。
- **应用限制**：基准为中文电商环境，结论可能不完全迁移到其他平台或品类；任务提示中隐含“最大化净资产”单一目标，未考虑多目标权衡（如品牌、客户满意度）。
- **资源成本未披露**：无法评估复现所需计算开销，不利于社区进行大规模扩展测试。
