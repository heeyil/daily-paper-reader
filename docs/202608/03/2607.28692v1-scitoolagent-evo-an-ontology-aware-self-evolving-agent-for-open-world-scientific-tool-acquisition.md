## 摘要
大型语言模型（LLM）智能体在科学研究中越来越多地被用于组织和调用专用计算工具。然而，它们对具有静态语义的预定义工具空间的依赖，限制了其在开放世界科学工作流中的适用性，因为在开放世界中，工具需求、能力和边界会动态演变。为此，我们提出了 SciToolAgent-Evo，一个面向开放世界科学工具获取的 ontology 感知自进化智能体。它由技能、经验和 ontology 化工具图的演化记忆驱动，在积累过程中从对比轨迹中提炼通用知识，而在推理过程中，它提出主动请求并利用基于 LinUCB 的 bandit 门控来动态平衡探索与利用。一旦获得新工具，其科学 ontology 会在线补全，以无缝集成到已知图中。此外，我们推出了 OpenSciToolBench，一个包含四个难度级别共 900 个现实任务的基准。大量评估表明，SciToolAgent-Evo 达到了最先进的性能，验证了其鲁棒性和泛化能力。

## Abstract
Large language model (LLM) agents have been increasingly adopted in scientific research for organizing and invoking specialized computational tools. However, their reliance on predefined tool spaces with static semantics limits their applicability to open-world scientific workflows, where tool requirements, capabilities, and boundaries evolve dynamically. To this end, we propose SciToolAgent-Evo, an ontology-aware self-evolving agent for open-world scientific tool acquisition. Driven by an evolving memory of skills, experiences, and an ontologized tool graph, it distills generalizable knowledge from contrastive trajectories during accumulation, whereas during inference, it formulates active requests and utilizes a LinUCB-based bandit gate to dynamically balance exploration and exploitation. Once a novel tool is acquired, its scientific ontology is completed online for seamless integration into the known graph. Moreover, we introduce OpenSciToolBench, a benchmark containing 900 realistic tasks across four difficulty levels. Extensive evaluations show that SciToolAgent-Evo achieves state-of-the-art performance, validating its robustness and generalization.

## 2. 论文提出的方法论

### 2.1 核心思想
SciToolAgent-Evo 采用**两阶段设计**，围绕一个不断演化的记忆系统展开：

- **阶段一：知识积累（Knowledge Accumulation）**——从对比轨迹中提炼可复用知识。
- **阶段二：Ontology 感知推理（Ontology-Aware Inference）**——通过主动请求与 bandit 门控实现动态工具获取。

核心创新在于将科学工具获取建模为**部分可观测马尔可夫决策过程（POMDP）**，并通过持续演化的记忆 M = (G_K, K, E) 最大化正确答案生成概率。

### 2.2 关键技术细节与公式

**（1）四个核心定义**

- **Ontology**：o_t = (b_t, h_t)，其中 b_t 为基本属性（功能、输入输出类型、类别），h_t 为高级科学属性（适用对象、科学场景）。未知工具初始仅暴露最小基本属性。
- **Skill**：k_i = (N_i, Z_i, E_i)，任务级工具链指导单元，包含技能名称、简洁描述、可复用工具链。
- **Experience**：e = (d_e, s_e, a_e, h_e)，非参数化提示，提供细粒度工具选择指导。
- **Bandit Gate**：基于 LinUCB 的决策模块，构造四维上下文向量 x_j = [f_j, m_j, s_j, p_j]^T，分别表示已知工具可行性、候选置信度边际、ontology 对齐分数、未知工具探索历史成功先验。

**（2）知识积累阶段**

- **对比轨迹生成**：对每个训练任务，先生成确定性基线轨迹（T_base = 0），失败后再以不同温度 T_exp ∈ {0.2, 0.5, 0.8} 采样 N-1 条探索轨迹。若探索轨迹成功，则构造对比对 (ξ_base, ξ_+)。
- **轨迹批判与知识蒸馏**：识别关键分叉点，生成诊断文本，蒸馏出**领域特定经验**（domain-specific）和**通用经验**（general）。通过余弦相似度阈值 θ_sim = 0.85 进行去重。

**（3）Ontology 感知推理阶段**

- **技能与任务路由**：先检查是否有匹配技能；无匹配则评估难度，简单任务使用轻量 CoT，复杂任务进入主动工具获取。
- **主动工具获取**：
  - 检索经验增强上下文：E_q = E_gen ∪ TopK(E_dq, q, K)
  - 生成主动工具请求集 R_q = {r_1, ..., r_l}
  - 初始检索集：C_j^0 = TopK{S(r_j, t) | ∀t ∈ V_K}
  - 经过图探索与组合重排序得到最终候选集 C_j
- **LinUCB 门控决策**：
  - a_j = argmax_{a∈{a1,a2}} [θ̂_a^T x_j + α√(x_j^T A_a⁻¹ x_j)]
  - a1 和 a2 分别代表已知工具利用和未知工具探索
- **知识更新**：成功探索后，补全新工具 ontology 并迁移到已知图 G_K；更新 bandit 参数 A_a ← A_a + x_j x_j^T, b_a ← b_a + r x_j；将轨迹抽象为技能存入 K。

## 6. 论文的主要结论与发现

- **SciToolAgent-Evo 显著优于所有基线**：
  - OpenSciToolBench 上：相比亚军方法，答案准确率分别提升 12.11 分（GPT-5.4-mini）和 9.55 分（Gemini-3-flash）
  - SciToolEval 上：对应提升 6.11 分和 2.89 分
  - 相比 SciToolAgent 提升 17%-31%，体现开放世界自适应能力的核心价值
- **复杂任务优势更明显**：在 Level-3/4 的高难度任务上，SciToolAgent-Evo 大幅领先 ReAct 和 Reflexion（超过 20-30 个点），表明演化记忆对长工具链规划至关重要。
- **各组件均不可或缺**：移除知识积累导致 14.87 分下降；禁用工具迁移是最大降幅来源；技能和经验分别贡献 3.23 和 1.57 分。
- **鲁棒性验证**：即使 70% 工具初始未知，仍能达到 59.01% 的准确率。
- **知识积累呈边际递减**：0%→25% 进度时性能增长最快，之后趋缓，说明有限数据即可建立稳健先验。
