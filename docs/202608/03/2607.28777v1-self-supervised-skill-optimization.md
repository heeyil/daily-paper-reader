## 摘要
代理技能为冻结的大型语言模型（LLM）代理提供可重复使用的程序性指导，近期研究表明，此类技能可以通过真实标签（GT）反馈进行优化。然而，许多应用缺乏GT标签、任务分数、奖励或可靠的任务特定评估器。因此，我们引入了自监督技能优化（SSO），这是一种仅从未标记的任务实例中学习可重用技能的比较框架。在每一步中，SSO在未标记的批次上运行当前技能，使用生成执行结果的一个子集来生成完整的技能探针，并在同一批次上运行这些探针。LLM裁判对生成的结果答案、轨迹、产物或最终状态进行比较。一个独立的行为提取器在不查看裁判决策的情况下识别行为差异。SSO利用这些决策跨实例汇总支持与反对所观察行为的证据。然后，它根据所得证据对行为进行排序，并从排名最高的行为中生成一个新的完整技能。仅当新技能在未标记的验证集上优于当前技能时，更新才会被接受。SSO在封闭式与开放式任务上均优于现有的无GT提示优化器。在封闭式基准上，SSO在不使用任何GT反馈的情况下，接近甚至有时超过最强的基于GT的技能优化器。

## Abstract
Agent skills provide frozen large language model (LLM) agents with reusable procedural guidance, and recent work shows that such skills can be optimized with ground-truth (GT) feedback. Many applications, however, lack GT labels, task scores, rewards, or reliable task-specific evaluators. We therefore introduce Self-Supervised Skill Optimization (SSO), a comparative framework that learns a reusable skill from unlabeled task instances alone. At each step, SSO runs the current skill on an unlabeled batch, uses a subset of the resulting executions to generate complete skill probes, and runs the probes on the same batch. An LLM judge compares the resulting answers, trajectories, artifacts, or terminal states. A separate behavior extractor identifies behavioral differences without seeing the judge's decisions. SSO uses these decisions to aggregate evidence for and against the observed behaviors across instances. It then ranks the behaviors by the resulting evidence and renders a new complete skill from the highest-ranked behaviors. The update is accepted only if the new skill outperforms the current one on an unlabeled validation set. SSO outperforms existing GT-free prompt optimizers on both closed-ended and open-ended tasks. On closed-ended benchmarks, it approaches and sometimes exceeds the strongest GT-based skill optimizer without using any GT feedback.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：大型语言模型（LLM）智能体在处理多步推理、工具调用与环境交互等任务时，越来越依赖可复用的“技能”（skill）——即以自然语言编写的持久化文档，指导冻结的智能体完成程序性任务。技能可作为可编辑、可跨任务复用的“可训练状态”。
- **现有瓶颈**：已有技能优化工作（如 SkillOpt）虽然有效，但其更新方向与接受决策均依赖**真实标签（GT）反馈**（任务分数、奖励、任务特定评估器等）。然而在许多实际场景中，这些反馈不可得：开放式任务没有参考答案、企业任务只有源文档与执行轨迹、交互式任务缺乏可靠评估器。收集标签或构建评估器会削弱“冻结智能体 + 技能文档自适应”带来的收益。
- **核心问题**：能否**仅从未标注的任务实例**出发，优化一个可复用技能？论文将该问题形式化为 **GT-free skill optimization**（无真值技能优化）。
- **核心贡献**：提出 **SSO（Self-Supervised Skill Optimization）**，一种完全无需 GT 反馈的对比式技能优化框架。在闭式与开放式任务上均超越现有无 GT 提示优化器；在闭式基准上接近甚至超过最强基于 GT 的技能优化器。

## 2. 方法论：核心思想、关键技术细节与算法流程

### 2.1 核心思想
- **比较式优化**：不依赖外部评分，而是通过 LLM 判断器对“当前技能执行结果”与“候选探针技能执行结果”做**成对比较**，从偏好信号中提取可迁移的行为证据。
- **行为级证据聚合**：不同于现有无 GT 提示优化器（SPO、PDO 等）在“完整候选提示”层面做选择，SSO 将执行差异拆解为可观察的**行为（behavior）**，跨探针、跨任务聚合对行为的正/负证据，再渲染出**不匹配任何单一探针**的新技能。
- **自我验证**：候选技能仅在**未标注验证集**上通过比较式“胜出”时才被接受，防止回归。

### 2.2 算法流程（每步迭代）
1. **探针生成与锚定比较（Probe Generation and Anchored Comparison）**
   - 从未标注训练集 \(D^{tr}\) 选取批次 \(X_t\)，用当前技能 \(S_t\) 执行得到锚定执行 \(r^o_i = f_{exec}(S_t, x_i)\)。
   - 基于当前技能与历史执行子集 \(H_t\)，由 LLM 探针生成器 \(f_{gen}\) 联合生成 \(K\) 个**完整技能探针** \(\{P_k\}_{k=1}^K\)（每个探针是完整文档，可多处修改，且互不相同）。
   - 将每个探针在**同一批次**上执行：\(r^k_i = f_{exec}(P_k, x_i)\)。
   - 固定 LLM 判断器 \(f_{judge}\) 将每个探针执行与锚定执行配对比较：\(y^k_i \in \{-1, 0, +1\}\)（探针胜/平/锚定胜），并采用**顺序随机化**以缓解位置偏差。
2. **行为提取与聚类（Behavior Extraction and Clustering）**
   - 仅对存在非平局比较的任务，由行为提取器 \(f_{beh}\) 提取行为记录 \(B_i = \{(\beta_{ij}, \alpha_{ij})\}_{j=1}^{J_i}\)，其中 \(\beta_{ij}\) 为行为描述，\(\alpha_{ij}(r) \in \{1, 0, \bot\}\) 表示该行为在执行 \(r\) 中“存在/不存在/不清楚”。
   - **关键防偏设计**：行为提取器不看到判断器的决策，避免比较结果污染行为描述。
   - 聚类器 \(f_{cluster}\) 仅根据行为描述将语义等价行为分组，聚类代表保留原始描述而非新生成摘要，保证不改含义。
3. **证据聚合与排序（Evidence Aggregation and Ranking）**
   - 对每个非平局比较 \((i, k)\)，找出行为激活状态在探针与锚定间明确不同的聚类集合 \(A^k_i\)。
   - 激活差异：\(d^k_{ic} = \alpha_{ic}(r^k_i) - \alpha_{ic}(r^o_i) \in \{-1, +1\}\)。
   - 证据分配（**归一化**以保证每个比较的总影响相等）：\(e^k_{ic} = \frac{y^k_i \cdot d^k_{ic}}{|A^k_i|}\)，因此 \(\sum_c |e^k_{ic}| = 1\)。
   - 聚类得分：\(Q_c = \sum_{i,k} e^k_{ic}\)，证据总量 \(E_c = \sum_{i,k} |e^k_{ic}|\)。
   - 由 \(Q_c\) 符号决定行为意图（鼓励/抑制），按 \(|Q_c|\) 降序排列，以 \(E_c\) 和贡献任务数为平局决胜；按预算 \(U\) 保留最高排名聚类作为行为单元 \(U_t\)。
4. **整体技能渲染与无标签验证（Whole-Skill Rendering and Unlabeled Validation）**
   - 若 \(U_t\) 非空，渲染器 \(f_{render}\) 根据当前技能与所选行为单元生成候选技能 \(\tilde{S}_{t+1}\)（鼓励的行为加强、抑制的行为移除/弱化，不引入无证据支持的反向行为）。
   - 在验证集 \(V_t\) 上执行当前技能与候选技能，用同一判断器比较得到 \(v_m \in \{-1, 0, +1\}\)。
   - **接受准则**：仅当候选胜场数 \(W_t >\) 败场数 \(L_t\) 时接受 \(S_{t+1} = \tilde{S}_{t+1}\)，否则保持 \(S_{t+1} = S_t\)。

### 2.3 与现有方法的本质区别
- 已有的 GT-free 提示优化器以“完整提示候选”为优化单元，SSO 以“行为”为优化单元，可组合不同探针各自的好行为，产出高于任何单一探针的技能。
- 优化全程（生成、排序、接受）均不使用 GT 标签、分数、奖励或任务特定评估器，仅依赖 LLM 判断器的成对比较。

## 6. 主要结论与发现

- **SSO 是闭式任务上最强的无 GT 方法**：在 GPT-5.5、GPT-5.4-mini、Qwen3.5-4B 上相对 No skill 平均提升分别达 20.4、16.6、14.2 个百分点。
- **逼近甚至超越最强 GT 基线**：GPT-5.5 下 SSO 恢复 SkillOpt 增益的 86.8%；GPT-5.4-mini 下超过 SkillOpt 1.2 个点；Codex harness 下较 No skill 提升 22.9 分、距 SkillOpt 仅差 1.9 分。
- **开放式任务全面占优**：SSO 对 No skill、SPO、PDO 的平均成对胜率分别为 62.4%、63.6%、62.5%，在全部任务与模型组合上均高于 50%。
- **行为级聚合优于候选级选择**：渲染候选表现持续优于事后最佳探针，说明跨探针聚合行为证据、渲染新技能是有价值的。
- **验证门有效**：接受更新逐步提升保留技能，验证门拒绝了回归的候选，支持迭代式细化。
- **总体结论**：完全无需任何真值反馈即可高效优化可复用技能，显著拓展了智能体技能学习的应用场景。

## 7. 优点（方法/实验设计亮点）

- **问题形式化清晰**：首次明确提出“GT-free skill optimization”问题，给出形式化定义与可复现的算法（Algorithm 1）。
- **防偏设计周到**：行为提取器与判断器隔离（提取器看不到比较结果）、聚类器只看描述不看激活态、比较顺序随机化、聚类代表保留原始描述——这些设计显著降低了 LLM 流水线中常见的级联偏差。
- **证据归一化机制**：每个非平局比较的总证据影响恒为 1，防止“涉及多个行为差异的比较”对整体产生过大影响，使证据聚合更公平。
- **“行为”作为优化单元**：突破候选级选择范式，将执行差异解耦为可跨任务传播的语义行为，支持从不同探针组合出更好的技能。
- **无标签验证门**：用未标注验证集上的成对比较而非 GT 分数来接受/拒绝更新，保持全程无 GT 的一致性，同时防止性能回退。
- **实验矩阵较完整**：多模型、多基准、多场景、消融+敏感性+动态分析组合，结论覆盖面广。

- **无真值场景的代表性有限**：虽然覆盖 6+3 个任务，但开放式任务仅 MT-Bench-101 三项，未覆盖真实企业生产、多智能体协作、长程具身交互等更复杂场景。
- **更新接受阈值简单**

**更新接受阈值简单**：验证门仅以胜场数是否多于败场数（\(W_t > L_t\)）作为接受标准，未考虑偏好幅度、判断器置信度或统计显著性；在验证集规模较小（\(|V_t| \in [16, 40]\)）、比较噪声存在的情况下，可能误接受或误拒绝候选，影响迭代收敛的稳定性与可解释性。

整体来看，SSO 在“无真值技能优化”这一新问题上提出了行为级证据聚合的原创性框架，防偏设计细致、实验覆盖面广，是技能学习与提示优化交叉领域的重要进展。其核心价值在于证明了一个反直觉的可能性：**不依赖任何外部标签或奖励信号，仅通过对比式自我验证，就能训练出堪比甚至超越有监督方法的可复用技能**。这为开放式任务、企业私有场景、缺乏评估器的交互环境中的智能体自适应提供了切实可行的技术路径。

未来值得探索的方向包括：将判断器扩展为多模型交叉验证或学习型奖励模型以降低同源偏差；引入置信度加权或统计检验优化验证门；将 SSO 迁移到更复杂的长程多智能体协作与真实生产环境；以及开源全部代码与超参数配置，提升可复现性，推动该方向在更大规模的社区验证中走向成熟。
