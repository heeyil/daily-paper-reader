## 摘要
视觉与语言导航（VLN）使机器人能够在未见过的环境中遵循指令行动。近年来，一种免训练范式应运而生：机器人查询多模态大语言模型以理解其观察并规划下一步动作。然而，基于图像流或稠密地图的长时程导航不可避免地引入了不断增长的记忆与推理瓶颈。我们提出HAM-VLN，一种决策耦合、智能体自生成的记忆机制，为机器人配备了一个持久且基于深度信息的世界图。在与选择下一步动作相同的模型调用中，HAM-VLN同时记录语义与反思性信息——包括房间类型、物体、导航进度和失败笔记。近期路径点以逐字形式保留在有限窗口内，而更早的历史则仅通过基于相关性、近因性和显著性的检索，并配合一跳拓扑扩展重新进入上下文。该设计在逐路径点决策之外无需额外的LLM调用。与先前方法相比，HAM-VLN不仅提升了多种导航指标，还将上下文长度减少了65%以上。具体而言，HAM-VLN在VLN-CE R2R上达到了61.0%的成功率（SR），在VLN-CE RxR上达到了52.7%的SR，在HM3D-v2 ObjectNav上达到了79.7%的SR，且无需任何训练。

## Abstract
Vision-and-language navigation (VLN) enables robots to follow instructions in previously unseen environments. Recently, a training-free paradigm has emerged: the robot queries a multimodal LLM to understand its observations and plan the next action. However, long-horizon navigation based on either image streams or dense map inevitably introduces a growing memory and reasoning bottleneck. We present HAM-VLN, a decision-coupled, agent-authored memory that equips the robot with a persistent, depth-grounded world graph. In the same model call used to select the next action, HAM-VLN also records semantic and reflective information---including room type, objects, navigation progress, and failure notes. Recent waypoints remain verbatim within a bounded window, while older history re-enters the context only through retrieval scored by relevance, recency, and salience, together with one-hop topological expansion. This design requires no additional LLM calls beyond the per-waypoint decision. Compared to previous methods, HAM-VLN not only improves various navigation metrics but also reduces the context length by more than 65%. Specifically, HAM-VLN achieves 61.0% Success Rate (SR) on VLN-CE R2R, 52.7% SR on VLN-CE RxR, and 79.7% SR on HM3D-v2 ObjectNav without any training.

### 背景
- **任务定义**：视觉与语言导航（Vision-and-Language Navigation, VLN）要求机器人在无先验地图的未知环境中，遵循自然语言指令完成导航并抵达目标位置或目标物体。
- **现有范式**：近年来兴起的**零样本（training-free）VLN**利用预训练多模态大语言模型（MLLM）直接进行推理与决策——在每个路径点，机器人调用模型理解当前观测并选择下一步动作，无需任何任务特定训练。

### 核心问题
- 作者指出，长时程导航面临一个根本性挑战：**记忆瓶颈**（memory bottleneck）。
  - 基于**稠密语义地图**的方案：存储随覆盖面积线性增长，且地图构建与导航决策彼此分离，语义匹配困难；

  - 两种方式的共同缺陷：**MLLM 无法自主决定保留什么信息以支持后续决策**。

### 核心含义
这篇论文的总体目标是：**为零样本 VLN 设计一种决策耦合的、智能体自生成的记忆机制**，使机器人在长轨迹导航中既能高效管理上下文长度，又能保留任务相关的语义、空间拓扑和失败经验，从而在不进行任何训练的前提下提升导航性能和推理效率。

## 二、方法论

### 2.1 核心思想
HAM-VLN 提出**分层智能体记忆（Hierarchical Agentic Memory）**，核心设计理念是：

> **让每一次 MLLM 调用同时完成动作决策和记忆写入**——在同一模型调用中，除了输出下一步动作外，还以结构化形式记录场所语义、观察到的物体、指令进度和失败证据，形成“决策耦合的”记忆维护，无需额外 LLM 调用。

### 2.2 双过程架构（Dual-Process Architecture）
采用类人认知的双系统设计，将策略分解为：

```
At = πrobot( φ1( φ2(T, Ot, Mt), Dt, Pt, Kcam ) )
```

| 组件 | 角色 | 实现 |
|------|------|------|
| **System 2（慢速深思）** | 高层决策：选择方向、回溯或停止，输出结构化 JSON（动作 + 进度分析 + 理由） | 大型 MLLM（Gemini-3.1-Pro），每路径点调用一次 |
| **System 1（快速反应）** | 将高层意图落地为像素级目标，预测边界框 | 轻量级 grounding MLLM（Qwen3.6-35B） |
| **控制器（Controller）** | 将像素目标通过深度图反投影到 3D 世界，结合里程计位姿执行短时程轨迹 | 快速行进（fast-marching）规划 + 轻量局部可通行图 |

### 2.3 分层智能体记忆的具体构成

**记忆状态形式化表示**（决策路径点 t）：

```
Mt = Wt ⊕ Lt ⊕ R(Gt, qt)
```

- **Wt**：工作记忆——最近 K 个路径点的原始视觉帧（有界窗口，逐字保留；实验取 K=1）；
- **Lt**：指令进度记录（有序）；
- **Gt**：长期世界图；**qt**：当前子目标；
- **R**：子目标条件检索算子。

**稀疏基础世界图**：

```
Gt = (VPt, VOt, EPP_t, EPO_t)
```

- **地点节点（VP）**：通过增量单链接聚类形成，聚合空间锚点（spatial anchors）、智能体作者语义上下文、访问统计和可选失败证据；
- **对象节点（VO）**：深度基础类别观测 + 开放词表描述；
- **边**：PP 边编码导航连通性，PO 边编码语义包含关系与置信度；
- **特点**：存储量随发现的地点/实体数量增长，而非地图面积；保留可回溯的几何与拓扑。

**四个功能记忆视图**：

| 记忆视图 | 功能 | 检索中的作用 |
|----------|------|--------------|
| 工作记忆 | 保留最近 K 窗口内的原始帧 | 提供逐字视觉证据 |
| 情景记忆 | 读取访问轨迹和时间元数据 | 提供**近因性** |
| 语义记忆 | 读取地点-对象内容和拓扑 | 提供**相关性** |
| 反思记忆 | 返回已检索地点的失败证据 | 提供**失败规避** |

### 2.4 子目标条件检索

**地点评分公式**：

```
s_t(p) = α·rel(qt, p) + β·rec_t(p) + γ·sal(p)
```

- `rel`：查询-地点余弦相似度（使用本地 bge-large-en-v1.5 编码器，零 API 成本）；
- `rec_t(p) = ρ^(t−τ(p))`：近因性，ρ=0.85；
- `sal`：基于路标一致性（landmark agreement）和对象丰富度的重要性；
- 参数 α=1.0，β=0.3，γ=0.3。

**拓扑感知读取**：种子预算 Ks=3，最终地点预算 Kp=5——取最高分地点作为种子，一跳扩展，包含当前地点邻域。

### 2.5 失败记忆与回溯机制

- 当 System 2 决定回溯到先前访问点 bt 时，被放弃的轨迹后缀 Bt 被映射到对应的地点状态，决策理由 rt 作为**基础失败证据**存储；
- 证据是**建议性**的：不改变检索分数，不阻止访问；仅当相关区域被检索到时重新进入上下文，由 System 2 在当下子目标下重新解读；
- 回溯因此同时改变机器人的位姿和记忆状态——从“动作-失败”到“基础写入-条件性回忆-修正动作”形成闭环。

### 2.6 算法流程（Algorithm 1 概括）
1. 从指令初始化进度记录 L0，G0 和 W0 为空；
2. 每个决策路径点：接收当前观测 → 提取当前子目标 → 组合记忆上下文 Mt → MLLM 输出动作+结构化写入 → 更新进度与图结构；
3. 若为回溯：将失败后缀写入图；
4. 若为前进：System 1 预测边界框，控制器执行运动；
5. 更新工作窗口。

## 六、主要结论与发现

### 性能结论
- **R2R-CE**：NE 降至 3.92m，OSR/SR/SPL 达到 78.7%/61.0%/48.1%，相比此前最强零样本基线 Three-Step Nav（NE 5.87），NE 下降 1.95m，SR 提升 27 个百分点；
- **RxR-CE**：SR 52.7%、SPL 35.7%、nDTW 54.3%，显著超越所有先前零样本方法（此前最优 SR 33.8%）；
- **HM3D-v2 ObjectNav**：SR 79.7%、SPL 43.2%，不仅超越所有零样本方法，还**超过了表中所有监督学习方法**（最佳监督方法 FiLM-Nav SR 77.0）。

### 效率结论
- 每个决策仅需 17.9k System 2 tokens，每 episode 244.9k API tokens；
- 相比 K=3 原始历史减少 45.1%/34.8%（决策/episode token），相比全历史减少 69.0%/67.2%；
- **更大的原始视觉上下文并不必然带来更好性能**——K=3→Full 的扩展使 SR 下降 4.7 点、SPL 下降 6.6 点，说明任务相关记忆选择比单纯增加上下文更重要。

### 消融结论
- 移除世界图是**最大性能损失来源**（SR −9.3 点，NE +1.05m）；
- 反思记忆对**路径效率贡献显著**（移除后 SPL −11.2 点）；
- 情景和语义记忆各贡献约 7.7 点 SR；
- 三者全移除后 SR 降至 50.7、SPL 降至 31.5，证明图结构本身不足以保证性能，必须配合功能记忆视图。

## 七、方法局限性与未来方向

### 7.1 局限性
- **对商用 MLLM 的高度依赖**：System 2 依赖 Gemini-3.1-Pro 的推理质量，实验结果受其能力上限约束；如果后端模型更换，记忆机制的收益可能发生显著变化；
- **参数依赖人工设定**：检索权重（α、β、γ）、近因性折扣率 ρ、种子/地点预算（Ks、Kp）均为固定经验值，未对全参数空间进行敏感性分析；
- **评估子集规模有限**：三个基准均仅使用 100-episode 子集，虽然引用其他工作证明其与完整划分偏差较小，但无法完全排除个别困难 episode 的偶然性影响；
- **未验证跨域泛化**：实验仅覆盖室内连续环境；对于室外、多楼层、动态障碍物等更复杂场景，分层记忆的适用性尚未讨论；
- **未与在线学习机制结合**：该方法是完全免训练的，因此无法利用导航过程中的反馈来微调记忆编码器或检索策略。

### 7.2 未来方向
- **动态化超参数**：将检索权重与近因性折扣率改为基于当前轨迹状态的自适应调节；
- **扩展记忆维度**：引入对象级实体记忆的显式引用，进一步支持“查找目标物体后返回”类任务；
- **多智能体共享记忆**：将分层记忆从单体导航扩展到多机器人协作场景，使失败经验可在群体间共享；
- **真实世界部署验证**：在实体机器人上评估记忆机制的鲁棒性，特别是遮挡、光照变化和位姿漂移对图结构更新的影响；
- **与训练范式结合**：探索将分层记忆作为可微模块嵌入强化学习或模仿学习框架，以实现端到端训练与记忆优化。

## 八、总体评价

### 8.1 核心贡献
本文提出 HAM-VLN，为零样本 VLN 提供了一种**决策耦合、自生成、分层组织**的智能体记忆机制。其关键创新包括：

1. **记忆与决策耦合**：通过在每次 MLLM 调用中同步输出动作与结构化记忆写入，避免了传统记忆维护的额外 API 开销；
2. **分层记忆组织**：将工作记忆、情景记忆、语义记忆和反思记忆统一在稀疏世界图之上，同时提供近因性、相关性和失败规避三种互补的检索信号；
3. **轻量检索算子**：使用本地编码器完成子目标条件评分与拓扑感知扩展，保证零额外 API 成本；
4. **作为零样本方法的全面优势**：不仅在两个 VLN 基准上大幅刷新零样本 SOTA，更在 HM3D-v2 ObjectNav 上超越了已有的监督学习方法，证明“免训练 + 良好记忆机制”可以逼近甚至超过需要大规模数据的训练范式。

### 8.2 学术意义
该工作为“长时程通用导航”提供了一个重要的范式参考：与其无限扩大上下文窗口或显式构建稠密地图，不如让智能体具备**自主选择记忆内容**的能力，将稀缺的推理资源集中在任务相关的信息上。这种思路与认知科学中“工作记忆-情景记忆-反思记忆”的三层模型高度一致，也为未来多模态大模型在机器人领域的应用提供了一种可插拔的架构设计。

### 8.3 工程实用性
- 每 episode 仅 244.9k API tokens 的推理成本在商用场景下具备实用性；
- 记忆维护完全由模型自身生成的结构化 JSON 驱动，不依赖外部工具或标注，易于接入现有 VLN-CE 系统；
- 检索和记忆存储均可本地化部署，对网络带宽和 API 调用频率敏感的真实机器人场景较为友好。

## 九、结论

HAM-VLN 通过**分层智能体记忆**成功缓解了零样本 VLN 中的记忆瓶颈问题，在 R2R-CE、RxR-CE 和 HM3D-v2 ObjectNav 三个基准上均取得显著优于现有零样本方法、部分指标超越监督学习方法的实验结果。记忆不仅没有带来额外 API 负担，反而通过减少无效上下文的注入降低了 token 消耗（相比全历史削减 67.2%）。该工作验证了一个核心观点：**在免训练导航中，“记什么”比“记得多”更重要，而“如何记忆”应服务于“如何决策”。**
