## 摘要
记忆对于长时程LLM智能体至关重要，然而现有的记忆系统主要保留交互内容，而不是建模哪些智能体可以被信任以及在什么条件下被信任。这一局限性在多智能体系统中尤为重要，因为中央模型可能无法直接验证看似合理或相关的对等响应。我们提出了 $Σ$-Mem，一种在线可靠性记忆，它记录了个体对等体的历史能力证据以及整个对等体集合中的对等关系证据。这两种证据都以实对称状态维护，并根据决策后的正确性反馈进行更新。根据Weyl不等式，每次事件级更新引起的谱变化是有界的，从而无需重新训练底层模型即可实现稳定的在线适应。$Σ$-Mem提供了一种通用的读写接口：同一记忆可用于中央模型的残差引导、免响应对等体路由或可靠性加权投票。在五个Qwen系列模型上，$Σ$-Mem适应了反事实可靠性变化，并泛化到未见过的对等体和任务领域。直接记忆读取在整个OOD评估集上也优于多数投票和最佳固定对等体。此外，随着更多正确性反馈的可用，性能持续提升，表明$Σ$-Mem逐步积累可操作的可靠性信息。这些结果确立了可靠性记忆作为基于LLM的多智能体系统中自适应协调的可复用基础。

## Abstract
Memory is central to long-horizon LLM agents, yet existing memory systems primarily preserve interaction content rather than modeling which agents can be trusted and under what conditions. This limitation is particularly important in multi-agent systems, where a central model may be unable to directly verify plausible or correlated peer responses. We introduce $Σ$-Mem, an online reliability memory that records historical competence evidence for individual peers and peer relationship evidence across the peer set. Both forms of evidence are maintained as real symmetric states and updated from post-decision correctness feedback. By Weyl's inequality, the spectral change caused by each event-level update is bounded, enabling stable online adaptation without retraining the underlying models. $Σ$-Mem provides a general write-and-read interface: the same memory can be used for residual steering of a central model, response-free peer routing, or reliability-weighted voting. Across five Qwen-family models, $Σ$-Mem adapts to counterfactual reliability shifts and generalizes to unseen peers and task domains. Direct memory readouts also outperform majority voting and the best fixed peer over the full OOD evaluation set. Moreover, performance improves consistently as more correctness feedback becomes available, indicating that $Σ$-Mem progressively accumulates actionable reliability information. These results establish reliability memory as a reusable foundation for adaptive coordination in LLM-based multi-agent systems.

## 1. 核心问题与整体含义（研究动机和背景）

- **现有记忆系统的局限**：长时程LLM智能体依赖外部记忆保存交互内容，但现有系统只建模“发生了什么”，不建模“谁能被信任、何时信任”。在多智能体系统（MAS）中，中心模型需要协调多个对等体（peer）智能体，而正确的协调决策往往取决于对每个peer的可信度判断，而非仅仅依赖内容回放或摘要。
- **中心模型难以验证**：中心模型往往无法直接验证peer响应的正确性，尤其在支持证据缺失（如RAG检索上下文被隐藏）或验证本身与生成同样困难时。多peer给出的一致回应可能反映共享偏差或相关错误，而非独立证据。
- **信任决策的关键性**：MAS的失败常发生在信任决策环节——错误地拒绝了正确响应或接受了错误响应。因此需要一种**可靠性记忆**，持续记录任务条件下的peer可信度，并利用外部反馈在线更新。
- **本文贡献**：提出Σ-Mem，一种在线可靠性记忆，记录两类证据——个体历史能力证据与peer间关系证据——并提供统一的读写接口，支撑残差引导、免响应路由和加权投票等多种协调机制，而无需重新训练底层模型。

## 2. 方法论

### 2.1 核心思想
- 将可靠性证据建模为**实对称矩阵**，利用矩阵谱的稳定性保证在线更新的平稳性。
- 维护两类状态：
  - **历史能力证据**：每个peer $p$ 有一个对称矩阵 $M_p \in \mathbb{R}^{r\times r}$，记录其在各类任务方向上的历史正确性表现。
  - **peer关系证据**：一个对称矩阵 $G \in \mathbb{R}^{P\times P}$，记录peer之间正确性信号的支持或对立关系。

### 2.2 更新机制（写入接口）
- **能力证据更新**：
  \[
  M_p^{(t+1)} = \gamma M_p^{(t)} + \eta c_{p,t} \phi(x_t)\phi(x_t)^\top,
  \]
  其中 $\gamma \in (0,1)$ 为衰减因子，$\eta>0$ 为更新因子，$c_{p,t}\in\{+1,-1\}$ 为peer $p$ 在事件 $t$ 上的外部正确性标签，$\phi(x_t)$ 为任务输入 $x_t$ 导出的单位能力方向。秩一更新保持对称性。
- **peer关系更新**：
  \[
  q_{p,t} = c_{p,t} - \frac{1}{P}\sum_j c_{j,t},\quad G^{(t+1)} = \gamma_G G^{(t)} + \eta_G q_t q_t^\top,\ \mathrm{diag}(G^{(t+1)})=1.
  \]
  $G_{p,q}>0$ 表示peer $p$ 与 $q$ 的正确性趋势相互支持，反之则相互对立。
- **稳定性保证**：利用Weyl不等式 $\lambda_i(M+E)-\lambda_i(M) \le \|E\|_2$，每次事件级更新的谱变化被有界，重复一致证据沿稳定方向积累，孤立噪声被衰减。定理1证明：在一致性方向 $\phi^*$ 上，信号项 $\propto \frac{1-\gamma^T}{1-\gamma}$ 增长，噪声项与 $T$ 无关，信噪比随 $\gamma$ 增大而单调提高。

### 2.3 读取与决策（读取接口）
- **残差引导**：将记忆读出向量 $r_{p,t}=M_p^{(t)}\phi(x_t)$ 经投影 $P$ 和标量增益 $g$ 映射为peer特定的残差引导 $\delta_{p,t}=gP M_p^{(t)}\phi(x_t)$，注入中心模型的上层decoder block，使注意力计算对peer历史可靠性条件化。
- **效用评估**：中心模型计算候选答案的 Yes/No 对数似然对比 $U_{p,t}$，结合peer间关系构造后验分布，并通过精确枚举选择期望正确性最高的peer作为最终答案。
- **免响应直接读取**：仅利用当前任务方向与记忆矩阵计算可靠性分数 $s_{p,t}=\phi(x_t)^\top M_p^{(t)}\phi(x_t)$，据此进行路由（M-route）或加权投票（M-vote），不依赖中心模型对当前答案的语义判断。

## 3. 实验设计

### 3.1 数据集与基准
- **训练集**：2,963个事件，来自GSM8K（数学）、SQuAD（检索问答）、APPS（代码）三个领域，由三个固定peer生成响应并标注正确性。
- **peer模型**：Gemma-3-4B-it（数学）、Phi-4-mini-instruct（RAG）、Qwen2.5-Coder-7B-Instruct（代码），构成明显的领域能力差异。
- **中心模型**：五个Qwen系列模型——Qwen3-0.6B、Qwen3-4B、Qwen3-8B、Qwen3.5-4B、Qwen3.5-9B。
- **反事实攻击基准**：从九个数据集（MATH-500、AMC23、OlympiadBench、CollegeMath、HotpotQA、TriviaQA、HumanEval、MBPP、LiveCodeBench）构建2,685个任务，通过将强peer响应与弱peer响应交换，构造CF@0、CF@50、CF@70、CF@90四种可靠性偏移比例。
- **OOD基准**：PIQA、MMLU、OpenBookQA、SciQ、BBH、SuperGLUE，覆盖常识推理、知识理解、科学问答、复杂推理和语言理解。
- **扩展peer池**：在测试时加入未见过的Llama-3.2-3B-Instruct和BitCPM-CANN-3B，形成4/5-peer设置。
