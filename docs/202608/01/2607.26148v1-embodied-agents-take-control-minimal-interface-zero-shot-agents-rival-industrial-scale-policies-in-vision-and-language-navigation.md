## 摘要
自主具身智能体必须维持一个长期的决策循环，其中涉及感知、行动、验证和在多步骤中的自我修正。当前系统通过特定任务的工作流程或具身策略来维持这一循环。我们研究了第三种形式，即智能体式具身控制，其中通用智能体自行持有该循环。以零样本导航作为受控测试平台，我们评估了仅提供单目RGB相机和离散动作的三种软件工程智能体框架。在这种严格最小条件下，复制的默认努力配置达到70.7±3.5%的成功率（opus-5，三次运行的平均值），而fable-5在最大努力下达到78%。当将训练好的路点工具与基本动作一起作为可选能力暴露时，混合fable-5智能体在默认努力下达到76.7±0.6%的成功率，且使用的环境步数仅为最大努力基本动作运行的一半，墙钟时间不到其四分之一。受控干预表明，能力主要围绕模型中心：模型选择强烈影响成功率，框架效应是描述性的，而强制路点接口有助于较弱的模型，但可能阻碍较强的模型。然而，在更长视野的任务中，性能急剧下降，而延迟和上下文增长限制了持续运行。这些结果表明，智能体式控制在零样本导航中已具有竞争力，且模型、框架和接口为自主具身智能体提供了互补的路径。

## Abstract
Autonomous embodied agents must sustain a long decision-making loop that involves perceiving, acting, verifying, and self-correcting over many steps. Current systems sustain this loop through task-specific workflows or embodied policies. We study a third form, agentic embodied control, in which a general-purpose agent holds the loop itself. Using zero-shot navigation as a controlled testbed, we evaluate three software-engineering agent harnesses given only a monocular RGB camera and discrete actions. Under this strictly minimal condition, replicated default-effort configurations reach 70.7$\pm$3.5% success (opus-5, mean over three runs), and fable-5 reaches 78% at maximum effort. When a trained waypoint tool is exposed alongside primitives as an optional capability, the hybrid fable-5 agent reaches 76.7$\pm$0.6% at default effort, using half the environment steps and less than one quarter of the wall time of the maximum-effort primitive run. Controlled interventions show that capability is primarily model-centered: model choice strongly changes success, harness effects are descriptive, and a forced waypoint interface helps weaker models but can hinder stronger ones. Performance nevertheless falls sharply on longer-horizon tasks, while latency and context growth limit sustained operation. These results show that agentic control is already competitive in zero-shot navigation and that models, harnesses, and interfaces offer complementary paths toward autonomous embodied agents.

## 1. 核心问题与整体含义（研究动机与背景）

- **核心问题**：自主具身智能体需要维持长期的决策循环（感知→行动→验证→自我修正）。现有系统通过“训练策略”（policy loop，如NaVid）或“人类编写的工作流”（workflow loop，如NavGPT、MapGPT）来驱动这一循环。本文提出第三种形式——**agentic embodied control（智能体式具身控制）**：由通用智能体模型本身持有并主导交互循环，而非被外部环境循环或预定义流水线调度。
- **研究动机**：前沿视觉语言模型（VLM）已具备跨轮次感知、空间推理、进度追踪和长视野工具使用能力；软件工程智能体的成功也表明模型能在通用循环中维持扩展的工具介导交互。本文质疑：导航能力是否必须内嵌于策略权重或人工脚手架，模型自身能否直接承担具身控制？
- **整体含义**：在零样本VLN导航中，仅凭**单目RGB相机+四个离散动作**的最小接口，通用软件工程智能体框架即可达到与工业级训练策略竞争的性能水平。这表明“模型-框架-接口”三者互补，为自主具身智能体提供了一条不依赖任务特定导航脚手架的路径。

## 2. 方法论

### 核心思想
- 用通用软件工程智能体框架替代零样本导航系统中的导航专用脚手架，模型自行决定何时观察、移动、恢复、停止。无导航训练、无地图、无搜索、无显式记忆、无位姿/深度/碰撞反馈。

### 关键技术细节
- **最小接口（Minimal-Interface Probe）**：
  - `observe()`：返回单张512×512前视RGB图像（HFOV 90°），不推进环境。
  - `step(actions)`：执行离散动作序列，包括FORWARD（0.25 m）、LEFT/RIGHT（15°）、STOP（终止episode），每次最多50个动作，总计500步预算。
  - 工具仅报告执行的动作数和剩余预算，无图像或碰撞信号。
- **Agentic循环**：模型在每个步骤调用`observe()`查看效果、决定动作序列、自行判断何时停止。
- **混合接口**：可选暴露训练好的**waypoint预测器**（基于深度的候选路点），让模型自行决定何时使用路点（粗粒度）或原语（细粒度），而非强制使用。

## 6. 主要结论与发现

- **最小接口已具竞争力**：默认配置opus-5达到70.7±3.5% SR，fable-5最大努力达78% SR，超越使用地图、记忆、搜索的AgenticNav（55 SR），与训练策略的工业系统（66-72 SR）持平。在zero-shot R2R-CE上是最强结果。
- **能力以模型为中心**：固定harness/接口时，模型选择产生5-72 SR的跨度，是研究中最宽的变化范围。推理努力（effort）影响是模型特定的，只有fable-5从max effort中明显获益（+9.7 SR）。
- **Harness效应是描述性的**：mini-swe-agent与vendor harness在6个模型对上差异为2-7 SR，方向不一致，属于描述性而非因果性的差异。
- **waypoint接口是补偿性的**：强制waypoint接口对弱模型（Qwen3.5-4b/9b）增益37-38 SR，对最强模型增益仅0.7-1.3 SR；在VLNVerse上甚至反转（-4-6 SR，碰撞率上升4-6倍）。
- **混合接口更优**：将waypoint作为可选工具而非强制路径，fable-5默认努力达76.7±0.6 SR，接近最大努力原语运行的78 SR，但仅用一半环境步数、不到四分之一墙钟时间。
- **长视野是能力天花板**：同一配置下R2R-CE 75 SR降至RxR-CE 26 SR（primitive）或39 SR（waypoint），原因是上下文增长导致信息稀释、延迟不可控。
- **失败是无声的**：25个失败episode中23个由模型自愿STOP，22个明确声称成功；所有4类失败中只有4个曾进入3 m成功区域。典型的失败机制是“错误的指称绑定”（12/25）和“stop决策锚定错误”（6/25），核心认知缺陷是**自诊断但无自纠正**。

## 7. 优点

- **概念创新**：明确区分policy/workflow/agentic三种“谁控制循环”的形式，提出并实例化了“agentic embodied control”这一新范式。
- **极简接口的诊断性**：最小接口（单目RGB+4个离散动作）系统地移除了导航特定脚手架，使能力归因更清晰。
- **可控的单轴消融**：模型、harness、接口、推理努力四轴分离，避免了常见“一锅端”式对比的混淆。
- **混合接口的洞见**：证明“可选工具优于强制工具”——训练好的模块在agent控制下比作为固定路径更具价值（更好、更快、更便宜）。
- **诚实的失败分析**：25个失败episode逐帧审计、4类分类、verbatim推理引用，诊断严重性高、形式透明。
- **物理机器人的迁移验证**：从模拟器到真实硬件，不仅验证了推理迁移，还暴露了身体意识缺失、空间记忆缺失等真问题。

## 8. 不足与局限

- **对比公平性受限**：与训练策略对比使用不同split（full val-unseen vs. rand100子集）；不同模型通过不同服务路径（本地、云端API），延迟/效率不可直接比较。
- **评估成本导致单次运行**：多数单元仅进行一次run，运行间标准差1.2-3.5 SR，个别结论可能受噪声影响。作者强调基于大跨度对比而非小差异。
- **未系统测试上下文窗口管理**：长视野分解（window/capping）作为因果机制未被测试，只是假设性讨论。
- **改进循环未验证**：第5节的“bootstrapping cycle”（脚手架生成数据→训练更强模型→简化脚手架）仅是假设性框架，没有任何实验验证。
- **物理实机实验缺乏对照基准**：31个episode是探索性的，没有成功率的统计报告，也没有统一的评估指标。
- **长期自主性不足**：延迟（中位206秒/动作序列）、上下文无限增长、缺乏持久内存与恢复机制，离“数小时自主运行”仍有系统性差距。
- **失败模式有安全性风险**：模型在距离目标44.6 m时仍声称成功，且无碰撞反馈/位姿信息时无法恢复几何陷阱，这在真实部署中不可接受。
