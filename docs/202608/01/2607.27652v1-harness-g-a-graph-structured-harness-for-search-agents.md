## 摘要
强化学习（RL）搜索代理通常将检索建模为自由形式的自然语言查询生成，并使用最终答案奖励来优化多轮交互。当前研究主要利用更密集或更结构化的信用信号来改进训练，但很少审视检索在策略-环境界面（policy-environment interface）上的建模是否恰当。我们在Search-R1训练中观察到显著的检索混叠（retrieval aliasing）：同一问题的暂存序列（rollouts）持续生成不同的查询字符串，但其累积的证据集（evidence sets）重叠程度日益增加。我们将此现象称为检索等价性坍缩（retrieval-equivalence collapse）；在该状态下，轨迹（trajectories）在检索决策方面趋近于效用等价，导致组内回报（within-group returns）缺乏有效的检索对比度。为解决这一问题，我们提出了Harness-G，一种图结构检索框架，重新设计了这一界面。它将自由形式的查询生成重构为有限动作选择（finite action selection）：策略选择一个证据句子或实体，或选择作答，而环境负责构建选项菜单、跟踪检索状态，并验证和执行每一选择。该界面减少了语言混叠，使同一状态下的备选动作可直接比较。基于这一界面，我们引入了结构化非近视信用（SNC），利用冻结的答案评分器（frozen answer scorer）将所选动作与其备选方案进行比较，并将下游收益分配至使其成为可能的早期动作。在六个问答基准测试中，Harness-G在两种评估模型规模下均取得最高的平均F1分数，在1.5B规模下比最强基线Graph-R1高出10.74分，在3B规模下高出3.98分。

## Abstract
Reinforcement learning (RL) search agents commonly model retrieval as free-form natural-language query generation and optimize multi-turn interactions using final-answer rewards. Current studies mainly improve training with denser or more structured credit signals, but rarely examine whether retrieval is properly formulated at the policy-environment interface. We observe pronounced retrieval aliasing during Search-R1 training: rollouts for the same question continue to generate distinct query strings, yet their accumulated evidence sets increasingly overlap. We call this phenomenon retrieval-equivalence collapse; in this regime, trajectories approach utility equivalence with respect to retrieval decisions, leaving within-group returns with little effective retrieval contrast. To address this problem, we propose Harness-G, a graph-structured retrieval framework that redesigns this interface. It reformulates free-form query generation as finite action selection: the policy selects an evidence sentence or entity, or chooses to answer, while the environment constructs the menu, tracks retrieval state, and validates and executes each choice. This interface reduces linguistic aliasing and makes same-state alternatives directly comparable. Building on this interface, we introduce Structured Non-myopic Credit (SNC), which uses a frozen answer scorer to compare the selected action with its alternatives and assigns downstream gains to the earlier actions that enabled them. Across six QA benchmarks, Harness-G achieves the highest average F1 at both evaluated model scales, outperforming the strongest baseline, Graph-R1, by 10.74 points at 1.5B and 3.98 points at 3B.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究动机**：现有 RL 搜索智能体（如 Search-R1）将检索建模为**自由文本查询生成**，用最终答案奖励优化多轮交互。以往改进集中在信用信号（credit signal）的密度与结构上，却忽略了**策略-环境接口（policy-environment interface）**本身的设计缺陷。
- **关键发现——检索等价性坍缩（Retrieval-Equivalence Collapse）**：在 Search-R1 训练中观察到显著检索混叠（retrieval aliasing）——同一问题不同 rollout 生成的查询字符串表面多样，但累积证据集（accumulated evidence sets）重叠度越来越高。作者将此定义为**检索等价性坍缩**：
  - 轨迹在检索决策层面趋于"效用等价"（utility equivalence），组内回报差异消失，GRPO 的组内对比信号失效；
  - 表面查询多样性（query-form diversity）远高于检索结果多样性（retrieval-outcome diversity），形成"**虚假探索**"（illusory exploration）。
- **导致的两种直接问题**：
  1. **优势消失（Vanishing advantages）**：相同证据→相同答案→组内优势趋零，rollout 组内缺乏真正的检索对比样本；
  2. **检索信用混淆（Confounded retrieval credit）**：检索相同证据却产生不同答案时，回报差异反映的是下游推理而非检索质量，难以对检索动作可靠归因。
- **核心论点**：问题不仅在于"如何评估轨迹"，更在于"**一个 rollout 组内是否包含真正不同的检索决策**"。过程奖励能细化已采样轨迹的监督，但无法解决自由查询到检索结果的多对一映射，因而无法从根本上恢复检索层面的有效对比。**接口设计本身应作为与奖励设计互补的优化轴**。

## 2. 提出的方法论

### 2.1 Harness-G 总体框架
- **核心思想**：将自由文本查询生成**重构为图引导的有限动作选择**（graph-guided finite action selection）——策略只做"选择哪个证据句子/实体"这一语义决策，**环境负责构建查询、执行检索、验证并更新状态**。
- **离线构建三分图（Tripartite Graph）**：从原始语料构建段落-句子-实体（paragraph–sentence–entity）无关系图：
  - 段落-句子边：保留文档上下文；
  - 句子-实体边：记录提及关系，支持跨句子/跨文档跳跃；
  - 句子-句子边：连接相邻句子，支持局部上下文扩展；
  - 实体-实体边：表面形式归一化、标题锚定、缩写匹配、可选嵌入邻居，仅用于候选召回。
  - 构建过程使用句子切分、NER（spaCy）、稠密编码等**程序化手段，不调用生成式 LLM** 做事实/关系抽取，近线性时间完成，跨运行复用。

### 2.2 菜单环境（The Menu Environment）
- **动作空间**（策略只能输出动作 ID，不能输出自然语言查询）：
  - `Select(s)`：将可见句子 s 加入已提交证据集 C_t；
  - `Lookup(e)`：围绕实体 e 检索缺失信息，查询由环境确定性地构建（拼接问题与已提交证据）而非模型生成；
  - `Answer`：终止检索，基于 C_t 生成答案；可选变体 `Answer_With(s1,...,sk)` 单步提交并终止。
- **三个构造性质**：
  - **有限性（Finiteness）**：菜单大小被 K_s 与 K_e 上限约束；
  - **可验证性（Verifiability）**：动作带显式类型与目标，非法动作从可行集剔除而非事后惩罚；
  - **可预览性（Previewability）**：任何候选动作可只读展开（Read-only Preview），返回其将引入/提交的句子，方便同状态对比。

### 2.3 结构化非近视信用（SNC: Structured Non-myopic Credit）
SNC 完全由环境计算，无需外部奖励模型、无需额外 rollout，包含两项互补信用：

**（1）前沿相对优势（Frontier-relative Advantage, r_fr）**
- 用冻结答案器（frozen answerer）g(O) = P(y* | q, O)（长度归一化教师强制的金标答案概率）打分；
- 每个信息获取动作的边际增益：p_t(a) = g(O_t ∪ Ũ(a)) − g(O_t)；
- 采样有界反事实前沿 F_t ⊆ M_t \ {a_t}（类型分层、去重、上限 K_f），计算备选平均增益 p̄_t；
- 前沿相对优势：**r_fr = p_t(a_t) − p̄_t**——只有优于同状态真实备选项的动作才获得正信用；早先出现过的文本再出现增益为零。

**（2）结构化使能信用（Structured Enablement Credit, r_en）**
- 记录来源边（provenance edge）(t, u)：当步骤 u 消费了步骤 t 产生的句子/实体时建边（有向无环）；
- 按逆拓扑序传播：R_u = p_u(a_u) + γ·r_en_u；r_en_t = Σ_{(t,u)∈D} R_u / |Pred(u)|；
- 下游增益沿整条使能链回传，教会"先找桥实体，再查其属性"的非近视模式。

**（3）与 GRPO 的整合**
- 总步进信用：r_SNC = r_fr + r_en；
- 每步信用均匀分布在动作 token 上，经批级全局尺度归一化、裁剪至 [−c, c]，得 Â_SNC；
- token 级优势为两流加性组合：**Â_i,k = Â_out + λ·Â_SNC**，用标准裁剪代理目标与 KL 正则优化；环境注入的观察 token 不参与 loss。

- **接口消融**：菜单界面在两种信用机制下比自由查询高出 17+ F1 分，MuSiQue 在 outcome-only 下高出 35+ 分；SNC 进一步带来 2.9–4.6 分的多跳提升；
- **训练稳定性**：六数据集训练 F1 单调上升、梯度范数有界（≤12.7），无持续性后期崩溃；GRPO/DAPO/PPO/REINFORCE++ 四种 RL 算法均稳定；
- **泛化能力**：跨数据集 O.O.D. 平均 F1 从 44.10 提升至 47.38（+3.29），30 对中胜 21 对；多跳目标增益（+6.45）远大于单跳（+0.12）；零样本跨领域（医疗、农业、CS、法律、混合域）平均 F1 超过 Graph-R1 3.16 分；
- **交互效率**：结构化导航增加交互轮数（3.6 vs 2.3–2.9）却不增加总 token 成本，响应更短；
- **总体论断**：**动作空间设计与奖励设计是互补的优化轴**——仅使过程奖励更密集无法解决自由文本检索的结构性混叠问题。

## 7. 优点

- **问题定义清晰、诊断扎实**：精确定义"检索等价坍缩"并用训练过程数据（查询形式多样性与检索结果多样性曲线、零优势组比例）定量验证，现象刻画可信；
- **界面重构而非增量修补**：直面策略-环境接口的根本缺陷，与单纯加过程奖励的现有方法形成本质区别；匹配转换实验（transition-matched）隔离了"动作暴露方式"这一唯一变量，因果论证严谨；
- **SNC 新颖且高效**：前沿相对优势利用了"有限动作集可枚举"的性质，将开文本空间中无法计算的同状态反事实对比变成确定性的环境操作；使能信用沿来源图逆拓扑传播，解决早跳信用延迟问题，且**零额外 rollout、零外部奖励模型、仅 9–11% 开销**；
- **工程考量务实**：图构建完全程序化（$0 API 成本、近线性时间），代码开源；无效目标过滤、重复检索去重等环境约束设计细致；
- **评估覆盖面广**：多跳+单跳、多骨干、多 RL 算法、O.O.D. 泛化、零样本迁移、成本对比、定性轨迹分析，多角度证据链完整；
- **附录详实**：动作空间筛选过程（表 10、11）透明呈现了从 L0 到最终接口的每一步演化，展现了科学的设计迭代过程。

## 8. 不足与局限

- **单数据集短板**：3B 下 NQ 的 F1 仍落后 Graph-R1 1.84 分（42.91 vs 44.75），说明菜单在单跳开放域问题上未必优于自由查询+LLM 构建图；
- **基线不对称**：GraphRAG 家族基线用 GPT-4o-mini 做 LLM 抽取式构建（成本高、可能引入噪声），Harness-G 程序化构建零成本，比较公平性部分被资源不对等削弱；主结果表 1 中部分基数为已发表跨栈参考值而非完全复现；
- **可迁移性限制**：SNC 的前沿相对优势依赖"可枚举的同状态动作集"这一前提，无法直接移植到自由查询空间；对非图结构检索环境适用性未验证；
- **领域覆盖有限**：主实验仅限 Wikipedia 域问答，虽然附录加了几类垂直领域零样本测试，但未做训练数据的领域内验证；备选集规模（128 测试问题）偏小，单点波动不可忽视；
- **依赖 NER 质量**：图构建依赖 spaCy 的实体识别与归一化，跨语言/低资源领域的鲁棒性存疑；实体-实体边仅用表面归一化+嵌入阈值，复杂指代消解场景可能失效；
- **纯文本局限**：方法仅支持文本证据，多模态证据（图表、PDF 布局等）的扩展作为未来工作被简略提及但未验证；
- **规模上限未知**：最大训练模型仅 3B（骨干对比中 Qwen3.5-4B 单数据集），更大规模下接口重构的优势是否保持未得到检验。
