## 摘要
将每个查询路由到具有成本效益的大型语言模型（LLM）对于平衡质量和成本至关重要，然而大多数路由器依赖集中式任务中心来预测模型性能，这造成了信息-风险错配，并随着模型池的增长产生可扩展性瓶颈。我们提出了一种基于市场的路由范式，通过反向拍卖将事前预测转移到LLM提供商，提供商以自我预测的成功概率和执行成本进行投标。为了考虑提供商预测和中心评估中固有的噪声，我们引入了误差感知反向拍卖机制（EA-RAM），该机制显式建模了这种固有的双重误差。我们证明了EA-RAM在双重误差下是贝叶斯激励相容且个体理性的，建立了中心理性的充分条件，并推导出显式的福利损失上界。我们进一步识别了鲁棒性效应：异号误差可以相互抵消；尾部消失的链接函数（如逻辑函数）通过饱和稳定明确的情况；额外噪声平滑信念映射，减少了边际操纵的收益。在仿真和真实世界基准上的实验表明，EA-RAM对双重误差具有鲁棒性，并实现了比集中式基线更优的成本-性能帕累托前沿，当提供商贡献本地信息时还有额外收益，验证了其实际有效性。

## Abstract
Routing each query to a cost-effective large language model (LLM) is critical for balancing quality and cost, yet most routers rely on a centralized task center to predict model performance, creating an information-risk mismatch and a scalability bottleneck as the model pool grows. We propose a market-based routing paradigm that shifts ex-ante prediction to LLM providers via a reverse auction, where providers bid with self-predicted success probabilities and execution costs. To account for inherently noisy provider predictions and center evaluations, we introduce the \textit{\textbf{E}rror-\textbf{A}ware \textbf{R}everse \textbf{A}uction \textbf{M}echanism} (EA-RAM), which explicitly models this inherent Dual Error. We prove that EA-RAM is Bayesian incentive compatible and individually rational under the Dual Error, establish sufficient conditions for center rationality, and derive an explicit welfare-loss bound. We further identify robustness effects: opposite-signed errors can cancel, vanishing-tail link functions (e.g., logistic) stabilize clear-cut cases via saturation, and extra noise smooths belief maps, reducing the gains from marginal manipulation. Experiments on simulations and real-world benchmarks show that EA-RAM is robust to the Dual Error and achieves a better cost--performance Pareto frontier than centralized baselines, with additional gains when providers contribute local information, validating its practical effectiveness.

## 1. 核心问题与整体含义

随着大语言模型（LLM）生态的迅速扩张，如何为每个查询路由到成本效益最优的模型成为关键问题。现有的大多数路由系统（如 EmbedLLM、RouteLLM 等）都采用**集中式估计范式**：由任务中心预测每个模型在给定查询上的性能，再决定分配。该范式存在两个结构性缺陷：

- **信息-风险错配**：任务中心承担路由失败的风险，却缺乏关于各模型真实能力/成本的信息；而模型提供方拥有更丰富的私有知识，却不承担决策风险。
- **可扩展性瓶颈**：中心需要为每个新模型进行性能画像或训练，即使是无训练路由也需额外开销，阻碍模型池的快速扩展。

论文提出一种**基于市场的路由范式**：将“事前性能预测”从中心转移到 LLM 提供方，通过**反向拍卖**实现路由。提供方提交自我预测的成功概率和成本，中心只负责模型无关的“事后评估”。由于该场景中天然存在两类噪声——提供方事前预测的主观误差与中心事后评估的客观误差——论文设计了 **误差感知反向拍卖机制（EA-RAM）**，显式建模这种“双重误差”，从而在现实条件下保证激励相容与经济效益。

## 2. 方法论

### 2.1 核心思想
- 任务中心（买方）与一组风险中性的 LLM 提供方（卖方）参与每一轮独立查询的反向拍卖。
- 每个卖方 `i` 有私有类型 `θ_i = (p_i, c_i)`，其中 `p_i` 是真实成功概率，`c_i` 是执行成本。
- 由于存在双重误差：
  - 中心事后评估受噪声 `ε_post` 影响，真实接受概率为 `h_i = σ(φ_i + ε_post)`；
  - 提供方事前预测受独立噪声 `ε_ante,i` 影响，其主观信念为 `g_i = σ(φ_i + ε_post + ε_ante,i)`。
- 链路函数 `σ` 单调递增、连续可微且全局 Lipschitz（如 logistic）。

### 2.2 机制流程（对应算法 1）
1. 每个卖方提交报告 `(p̂_i, ĉ_i)`，等价于报告评分 `ŝ_i = V·p̂_i - ĉ_i`。
2. 买方按报告评分选择最大正分者；若所有评分≤0，则选择空分配（无模型执行）。
3. 获胜者 `j` 执行任务，真实结果 `μ_j ~ Bernoulli(p_j)`，评估信号 `μ̃_j ~ Bernoulli(h_j)`。
4. 支付规则：`r_j = V·μ̃_j - H`，其中 `H = max(0, max_{k≠j} ŝ_k)` 为次高报告评分；未获胜者支付为零。
5. 社会福利 `W = V·μ_j - c_j`。

### 2.3 理论保障
论文证明了在双重误差下 EA-RAM 仍具备以下性质：

- **贝叶斯激励相容（BIC）**：卖方真实报告其“误差调整后有效剩余” `T̄_i = V·g_i - c_i` 是最优贝叶斯响应（定理 3.2）。
- **个体理性（IR）**：均衡真实报告下，任何卖方的期望效用非负（定理 3.3）。
- **中心理性（CR）**：给出两组充分条件——(A) `E[H] ≥ V·Δ_gate`（次高得分缓冲区足够大）或 (B) 评估偏向保守（`E[p_1 - h_1] ≥ 0`）（定理 3.4）。
- **福利损失上界**：与无误差基准相比，期望福利损失满足 `0 ≤ E[W_{i⋆}] - E[W_{i†}] ≤ 2V·L_σ·(M_post + M_ante)`，其中 `M` 为误差的二阶矩半径（定理 3.7）。

### 2.4 结构性鲁棒性洞见
- **异号误差补偿**：当事前误差与事后误差符号相反时，福利损失上界可收紧至 `2V·L_σ·max{M_ante, M_post}`（命题 3.8）。
- **饱和鲁棒性**：对尾部趋零的链路函数（如 logistic），当 `|φ|` 很大时，噪声对输出概率的影响趋近于零，机制在“实力差距明显”的查询上天然稳定（命题 3.9）。
- **噪声诱导平缓化**：额外独立噪声通过卷积使信念映射的最大斜率不增，降低边际操纵收益（命题 3.10）。

- **对比方法**：

- **评估指标**：相对于无误差上界的福利差距（越低越好），分别考察评估噪声 `σ_post` 和预测噪声 `σ_ante` 的变化。

## 6. 主要结论与发现

1. **EA-RAM 在双重误差下保持稳健**：理论证明 BIC/IR 成立，福利损失有界；仿真中 EA-RAM 的福利表现接近完美上界，而忽略误差的朴素基线明显恶化。
2. **帕累托前沿优于集中式基线**：在 RouterBench 的全部评测集上，EA-RAM（基本设置）的 AIQ 均高于 EmbedLLM、RouteLLM、FrugalGPT 等基线；引入提供商本地信息后，前沿进一步向左上方移动，成本-质量权衡更优。
3. **对评估噪声稳健**：在 LLM-as-a-judge 的噪声注入下，EA-RAM 的福利损失始终最小。
4. **中心侧延迟近恒定**：随着模型池扩大，EA-RAM 的中心计算延迟几乎不变（约 0.04s），而集中式路由器的延迟从 0.118s 升至 0.383s，加上重训练后总延迟远高于 EA-RAM。
5. **通信开销线性增长但可控**：反向拍卖的通信量随 N 线性增长，但在普通高带宽文本路由场景下（吞吐阈值约 0.34–0.38 MB/s）不易成为瓶颈。

## 8. 不足与局限

论文在结尾明确列出以下限制：

- **理论适用范围有限**：未考虑有界惩罚、非负支付等支付规则变体，这些变体可能改变 BIC/IR/CR 保证。
