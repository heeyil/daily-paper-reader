## 摘要
随着记忆在任务和会话间不断累积，长期LLM智能体的性能同时依赖于针对查询的检索和持续的记忆精炼。然而，现有方法通常要么优化记忆访问（通过迭代查询改写或自适应检索策略），要么优化记忆演化（如结构更新）。这种分离忽视了一个基本反馈循环：检索决定了哪些记忆获得使用信号，而更新后的记忆库又会重塑未来的检索。我们提出\textbf{CoEvo-Mem}，一个用于协同演化检索策略和记忆库的闭环框架。对于每个查询，一个冻结的LLM生成路径特定的查询改写和路由先验，由轻量级残差路由器在线修正。检索到的上下文作为两个学习过程之间的耦合接口：任务结果将信用分配给路由决策，而轨迹条件化反馈更新记忆值和图关系。这些更新改变了后续查询中记忆的排序和选择方式，从而闭合了反馈循环。为缓解耦合引起的非平稳性，CoEvo-Mem在固定记忆库更新路由器与固定检索策略演化记忆库之间交替进行。在七个多样化基准上，\textbf{CoEvo-Mem}实现了最先进的性能，证明了检索-记忆协同演化的重要性。

## Abstract
As memories accumulate across tasks and sessions, the performance of long-term LLM agents depends jointly on query-specific retrieval and continual memory refinement. However, existing methods typically optimize either memory access, through iterative query refinement or adaptive retrieval policies, or memory evolution such as structural update. This separation overlooks a fundamental feedback loop: retrieval determines which memories receive usage signals, while updated memory bank reshape future retrieval. We propose \textbf{CoEvo-Mem}, a closed-loop framework for co-evolving the retrieval policy and memory bank. For each query, a frozen LLM generates route-specific query rewrites and a routing prior, which a lightweight residual router corrects online. The retrieved context serves as the coupling interface between the two learning processes: task outcomes assign credit to routing decisions, while trajectory-conditioned feedback updates memory values and graph relations. These updates alter how memories are ranked and selected for subsequent queries, thereby closing the feedback loop. To mitigate coupling induced non-stationarity, CoEvo-Mem alternates between updating the router with the memory bank fixed and evolving the memory bank with the retrieval policy fixed. Across seven diverse benchmarks, \textbf{CoEvo-Mem} achieves state-of-the-art performance, demonstrating the importance of retrieval-memory coevolution.

- 单独优化任何一方都会导致另一方的状态失配，无法实现系统级持续改进。这是本文要解决的核心问题。

**论文含义**
- 提出检索策略与记忆库的"协同演化"（co-evolution）范式，将二者统一到一个闭环学习框架中。该思路将长期记忆系统从"静态配对"的检索-存储关系升级为"动态互适应"的耦合系统，代表了长期智能体记忆研究的一个新方向。

## 2. 方法论：CoEvo-Mem 框架

### 2.1 核心思想
- 冻结回答 LLM，仅训练一个**轻量残差路由器**和**持久化带类型关系的记忆图**；
- 检索到的上下文是"路由器学习"与"记忆演化"之间的**耦合接口**；
- 通过**交替训练阶段**（固定一方、更新另一方）缓解耦合带来的非平稳性。

### 2.2 关键模块与技术细节

**（1）自路由查询改写器（SR-QR）**
- 冻结 LLM 对每个查询返回结构化输出：稠密改写（保留语义）、稀疏改写（保留实体/精确词）、路由先验 p⁰_t ∈ Δ¹、置信度特征 ξ⁰_t；
- 若输出失效则回退到原始查询 + 均匀先验。

**（2）残差路由器（Prior-Guided Residual Router）**
- 可训练查询编码器 φψ 与策略头 fω 生成残差修正：
  - πt = softmax(log p̄⁰_t + Δt)
  - 策略头末层零初始化，使初始策略恰好等于 LLM 路由先验；
- 路由器训练阶段使用 Beta 分布采样探索（ζt ∼ Beta(κπd_t, κπs_t)），记忆阶段/推理时用均值策略 πt；
- 损失函数 = score-function 估计器 + KL 正则：
  - L_router = −sg[Ât] log pθ(ζt | qt, ot) + β_KL · D_KL(Cat(πt) ∥ Cat(p̄⁰_t))
  - 其中优势 Ât = Rt − Bt−1，Rt 为任务奖励（EMA 基线）。

**（3）Q加权混合检索器**
- 稠密检索按描述嵌入相似度排序，稀疏检索按 BM25 排序；
- 加权倒数秩融合（RRF）同时考虑路由权重与学习到的记忆效用：
  - St(m; P) = Σ_a w_at · (1/N_a) Σ_i 1/(η + rank_ta,i(m; P)) + λQ/(η + rank_tQ(m; P))
- **时间图扩展**：将 top-k 候选的记忆的时间邻居加入候选池，重新计算所有排序。

**（4）带类型关系的记忆图（Typed Relational Memory Graph）**
- 节点存储：内容、稠密描述、稀疏关键词、时间元数据、来源轨迹、效用值 Qt(m)；
- 边类型：Dense（语义近邻）、Sparse（词法重叠）、Time（时间先后，有方向）；
- 图的字段与检索通道直接对齐，而非一个通用知识图谱。

**（5）记忆演化（轨迹条件化）**
- 每条训练轨迹（无论成功与否）被蒸馏为一条新记忆；
- 新记忆效用继承自产生它的上下文：Q̂(m_new) = 上下文均值（或中性初值 Qinit）；
- TD 式效用残差：δt(m) = Rt·ut(m) + γ·Q̂(m_new) − Qt(m)，其中 ut(m) 为逐记忆归因分数；
- **关系信用传播**：沿最多 D 跳的带类型路径，用衰减因子 ρc 计算最强路径系数，对未直接暴露但相关的记忆进行价值更新；
- 同步快照更新：Qt+1(v) = Π[Qmin,Qmax](Qt(v) + αQ·Δt(v))。

**（6）交替协同演化（Alternating Co-Evolution）**
- Router 阶段：记忆图只读，采样混合检索权重，只更新路由器 θ；
- Memory 阶段：路由器冻结，使用确定性均值策略，逐条顺序更新记忆图；
- 每个阶段完整遍历一次训练集后切换，反复交替；若图初始为空，先预置一个 Memory 引导阶段。

## 6. 主要结论与发现

1. **检索与记忆存在强反馈耦合**：检索决定记忆接收反馈的机会，记忆更新改变后续检索的排序，二者必须协同优化而非孤立调整；
2. **CoEvo-Mem 在全部评估设置上取得 SOTA**：证明"检索-记忆协同演化"比单独优化任意一方更优；
3. **路径特化检索与关系型记忆演化互补**：SR-QR 主要贡献于 GPQA（+8.33）与固定图 MC 检索精度；记忆演化主要贡献于 GPQA（+10.00）、LiveCodeBench（+7.62）与 BFCL 思考模式（+5.94）；
4. **交替训练优于同步更新与两阶段训练**：交替分别高出 1.92 和 3.33 个宏平均分，说明固定一方再更新另一方的分块调度能有效控制耦合非平稳性；
5. **训练曲线显示泛化**：LoCoMo 上训练精度 87%、验证 84%，协同演化的收益可推广到留出问题。

## 8. 局限性与潜在不足

**（1）表达能力的边界**
- 回答 LLM 被完全冻结，所有自适应能力集中在轻量路由器与记忆图上。当任务需要记忆条目本身被改写、压缩或重表述时，框架缺少对记忆内容的参数化更新手段（仅能新增痕迹、调整效用值与图连接），可能限制记忆表征的演进上限。

**（2）归因与信用分配的准确性依赖**
- 逐记忆归因分数 ut(m) 与上下文均值效用继承等设定，隐式假设了"上下文各条目对奖励的贡献可近似线性分离"。在长上下文、多记忆混合导致奖励的情形下，归因误差会通过 TD 残差累积，且论文未对归因噪声进行敏感性分析。

**（3）理论保证缺失**
- 交替训练调度、TD 式效用更新与路由器策略优化之间的联合动态没有收敛性分析；没有对路由策略的遗憾界、记忆效用的估计偏差给出理论刻画。论文只提供了经验层面的验证。

**（4）超参数量与敏感性未报告**

- 未报告训练总时长、GPU 时数、能耗等资源指标；部分基线（如 OpenAI、Full Context 的 LoCoMo 行）为文献引用值而非同环境重跑；GPT-4 骨干的 MC 结果属于跨主干迁移参考而非等算力对比。

**（7）协议限制**
- LoCoMo-MC 与 LongMemEval-MC 协议为满足"固定记忆"要求禁用了记忆演化，使得在这些协议下无法验证完整闭环；自由问答下的 SOTA 是闭环结果，但单轮检索协议下的增益部分来自路由器而非记忆演化，二者贡献难以在 MC 设置下解耦验证。

**（8）安全性与隐私未涉及**
- 记忆图中存储的长时对话痕迹包含用户敏感信息的可能性、多用户共享记忆的隔离策略、记忆被投毒（poisoning）后经关系传播污染大范围节点的鲁棒性，均未讨论。

---

## 9. 未来研究方向

1. **理论化协同演化**：建立交替训练与 TD 记忆更新的联合收敛框架，刻画路由器策略偏移上界与记忆效用估计误差的传播规律；
2. **参数化记忆内容更新**：允许在冻结主 LLM 的前提下对记忆条目进行轻量改写、摘要压缩与合并去重，弥补当前"只增不改"的表征局限；
3. **大规模扩展与遗忘机制**：研究图规模增长时的稀疏更新策略、基于效用阈值的驱逐机制以及 Dense 边重建的增量算法；
4. **跨智能体与隐私记忆**：将协同演化推广到多智能体共享记忆场景，并探索差分隐私、加密存储与投毒检测；
5. **更强的耦合感知探索**：在 Router 阶段引入对图效用不确定性的显式探索（如效用方差引导的路由采样），使路由决策主动为高不确定性记忆创造反馈机会；
6. **统一评估协议**：构建同时允许检索策略与记忆更新学习的长期评测基准，避免"固定记忆"协议割裂闭环带来的评估盲区。

## 10. 总体评价

CoEvo-Mem 的价值主要体现在**问题识别**与**框架设计**层面：它清晰地指出长期智能体记忆系统中检索与存储之间存在被广泛忽视的正反馈耦合，并将强化学习中的值估计、策略梯度与残差路由技巧组合为一个轻量、端到端可交替训练的闭环系统。实验覆盖多任务类型并全面取得 SOTA，消融设计有说服力地验证了交替训练与两大组件的必要性。其局限主要在于理论深度、超参敏感性分析的缺失以及资源信息的不透明，但作为该方向的开创性工作，它为后续研究提供了清晰的框架坐标和基准结果。

**总体判断**：方法论有创新性，实验充分且结果一致，是长期智能体记忆研究中的一项里程碑式工作，但距离大规模真实部署仍需解决记忆管理、理论保障与隐私安全等后续问题。
