## 摘要
现有技能生成方法主要依赖启发式规则或流水线式整合，这些方法必须针对不同的证据来源进行专门设计。相比之下，基于学习的方法提供了一种更统一的方式来对跨异构来源的技能生成进行建模。然而，基于学习的技能生成仍然具有挑战性，因为技能缺乏基于相关性或正确性的自然监督信号；其价值在很大程度上只能通过它们是否改善智能体在下游任务中的行为来确定。为应对这一挑战，我们提出了Skill-$\alpha$，一种用于渐进式生成高质量智能体技能的强化学习方法。具体而言，我们将技能生成形式化为一个顺序编辑过程，将技能构建分解为可单独评估的编辑，并引入一种新颖的回滚奖励，通过在锚定查询上比较原始技能与编辑后技能的下游执行情况来评估每次编辑。大量实验表明，在文档到技能和经验到技能两种设置下，Skill-$\alpha$生成的有效技能均优于基于启发式或流水线的方法。在主要的GPT-4o工作器下，与最强的技能生成基线相比，Skill-$\alpha$在CL-Bench上将平均下游成功率提高了3.3个百分点，在tau2-bench上提高了6.7个百分点。进一步的消融实验验证了回滚奖励和渐进式生成的重要性。

## Abstract
Existing skill generation methods largely rely on heuristics or pipeline-style consolidation, which must be specially designed for different evidence sources. In contrast, learning-based approaches offer a more unified way to model skill generation across heterogeneous sources. However, learning-based skill generation remains challenging because skills lack a natural supervision signal based on relevance or correctness; their value can largely be determined only by whether they improve the behavior of the agent on downstream tasks. To address this challenge, we propose Skill-$α$, a reinforcement learning method for progressively generating high-quality agent skills. Specifically, we formulate skill generation as a sequential editing process that decomposes skill construction into individually evaluable edits, and introduce a novel rollback reward that evaluates each edit by comparing downstream execution under the original and edited skills on an anchored query. Extensive experiments show that Skill-$α$ generates more effective skills than methods based on heuristics or pipelines in both document-to-skill and experience-to-skill settings. Under the main GPT-4o worker, Skill-$α$ improves average downstream success rates over the strongest skill-generation baseline by 3.3 points on CL-Bench and 6.7 points on tau2-bench. Further ablations validate the importance of rollback reward and progressive generation.

## 1. 论文的核心问题与整体含义

- **研究背景**：大语言模型（LLM）智能体在执行多步推理、长程规划和工具调用任务时，通常依赖外部技能（skills）作为可复用的程序化模块来调节推理过程。因此，如何从文档或经验中**自动生成高质量技能**成为关键问题。
- **核心挑战**：技能的质量缺乏类似数学推理或检索任务中那种显式事实答案或执行结果的自然监督信号。一项技能的价值**只能通过其是否改善智能体在下游任务中的行为来判断**——流畅的文字技能可能是冗余、过度具体甚至误导性的；而一个精炼的编辑却可能显著提升工作智能体的表现。
- **现有方法的不足**：既有技能生成方法（如 Ctx2Skill、AutoSkill、Trace2Skill、SkillPro 等）大多依赖启发式规则或针对特定证据源设计的流水线式整合，难以统一建模来自异构来源（文档 vs. 经验轨迹）的证据，也缺乏对"每条证据应如何改变技能"的明确指导。
- **研究意义**：本文提出将技能生成从一个"一次性生成文本"的问题，转化为**统一的、基于学习的渐进式决策问题**，填补了基于强化学习（RL）训练技能编辑策略的空白。

## 2. 论文提出的方法论

### 核心思想

将技能生成形式化为**序列化局部编辑过程**：从初始技能状态 $z_0$ 出发，策略逐步读取证据单元，每一步决定如何编辑当前技能（新增、修改、合并、删除或保持不变），最终生成完整技能 $z_T$。核心训练信号是**回滚奖励（rollback reward）**，通过在锚定查询上对比"编辑前"与"编辑后"技能的下游执行结果，实现编辑级别的执行接地信用分配。

### 关键技术细节

1. **渐进式技能生成**（Progressive Skill Generation）
   - 每一步：$A_t \sim \pi_\phi(\cdot | z_{t-1}, x_t)$，$z_t = \text{Edit}(z_{t-1}, A_t)$
   - 一次性生成将抽象、去噪、冲突消解、压缩等操作纠缠在一起，导致信用分配弱、训练困难；渐进式分解使每一步决策可单独评估。

2. **五元动作空间** $A = \{CREATE, UPDATE, MERGE, PRUNE, NOOP\}$
   - CREATE：新增缺失规则/流程；UPDATE：修正不完整或不准确的规则；MERGE：整合重叠内容；PRUNE：删除有害、过度具体或冗余内容；NOOP：当前技能已足够，保持不变。

3. **回滚奖励**（Rollback Reward）
   - 每一步编辑附带一个来自同一证据源的锚定查询 $q^{anc}_t$ 和基准专用验证器 $V_t$；
   - 分别用原始技能 $z_{t-1}$ 和编辑后技能 $z_t$ 让固定工作智能体（GPT-4o）回答同一锚定查询，得到 $r^{ctrl}_t$ 和 $r^{edit}_t$；
   - 奖励公式：
     - 非 NOOP 动作：仅当 $r^{edit} > r^{ctrl}$ 时奖励为 1；
     - NOOP 动作：仅当没有其他有效采样编辑超过控制分数时奖励为 1；
     - 其余情况为 0。
   - **关键优势**：直接奖励编辑后滚动执行不足，因为正确结果可能来自工作智能体自身能力或查询简单；回滚对比通过同一查询下新旧技能的差异将信用归于编辑本身。

4. **训练流程**（两阶段）
   - **SFT 预热**：用 DeepSeek-V4-Pro 从三个基准的训练集合成监督数据（6,481 条），学习动作语法与结构化编辑格式；
   - **GRPO 强化学习**：使用 Qwen3-8B 初始化，GRPO 优化（组大小 $G=8$），RL 数据集为 2,048 个局部编辑状态（CL-Bench 768、SpreadsheetBench 512、tau2 各域 256）；
   - 验证器：CL-Bench 用 GPT-5.5 官方 rubric 评判，SpreadsheetBench 和 tau2-bench 用基准环境直接反馈。

## 7. 优点

- **统一框架**：将文档到技能与经验到技能统一为同一个渐进式编辑决策问题，一个可学习生成器即覆盖异构证据源，这是对现有"按证据类型分别设计流水线"范式的实质突破；
