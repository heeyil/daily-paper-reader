## 摘要
自进化方法通过从底层LLM中采样轨迹并从中学习来提升LLM智能体的能力。然而，这些方法难以在智能体的固有能力边界之外进行学习，因为智能体无法在困难示例上采样出正确轨迹以进一步改进。在本文中，我们提出了一种零阶自进化框架，通过扰动LLM参数来适应困难示例，而无需任何轨迹标注，从而使智能体能够超越其能力边界进行学习。具体来说，我们扰动LLM的LoRA参数，运行智能体，计算在扰动参数和原始参数下的损失，并利用损失差异来估计梯度并进一步更新LoRA参数。我们使用更新后的LLM采样轨迹进行监督微调，以突破智能体的能力边界，从而形成闭环的自进化循环。我们引入了并行扰动推理机制和自适应查找机制，以减少零阶优化中的时间消耗，并使用答案困惑度损失来提供平滑且稳定的零阶损失值。在多个深度研究基准上的实验表明，我们的方法获得了显著更多的成功轨迹，并且在困难示例上持续优于强基线。代码和已发布的工件可在https://github.com/hidk1911/ZOForLLMAgents获取。

## Abstract
Self-evolving methods improve the capabilities of LLM agents by sampling trajectories from the underlying LLMs and learning from these trajectories. However, these methods struggle to learn beyond the inherent capability boundary of the agents, since the agents cannot sample correct trajectories on difficult examples for further improvements. In this paper, we propose a zeroth-order self-evolution framework that enables agents to learn beyond their capability boundary by perturbing LLM parameters to adapt to difficult examples without any trajectory annotations. Specifically, we perturb LoRA parameters of LLMs, run the agent, compute the losses under the perturbed and original parameters, and use the loss difference to estimate gradients and further update the LoRA parameters. We sample trajectories using the updated LLMs for supervised fine-tuning to break through the capability boundary of the agents, forming a closed self-evolution loop. We introduce a parallel perturbation inference mechanism and an adaptive lookup mechanism to reduce time consumption in zeroth-order optimization, with an answer perplexity loss that provides smooth and stable zeroth-order loss values. Experiments on multiple deep research benchmarks show that our method obtains substantially more successful trajectories and consistently outperforms strong baselines, especially on difficult examples. The code and released artifacts are available at https://github.com/hidk1911/ZOForLLMAgents.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- 论文聚焦于 **LLM 智能体的自进化（Self-Evolving）** 问题。自进化方法通常让智能体从自身采样的轨迹中学习（如通过 SFT 或 RL），从而持续提升能力。
- 现有关键瓶颈：**能力边界（capability boundary）** 问题——当智能体本身无法在困难样本上采样出正确轨迹时，就无法获得高质量训练信号，自进化过程失效或停滞。
- 论文提出了一种 **零阶优化（Zeroth-Order Optimization）自进化框架**，其核心洞察是：即便智能体无法直接生成正确答案，也可以通过**扰动模型参数、观察损失变化**来估计梯度并调整策略，从而在“无轨迹标注”的条件下引导模型探索出正确轨迹。
- 整体意义：首次将零阶优化用于 LLM 智能体的自进化，使智能体能够**突破自身能力边界**，在困难样例上获得新的成功轨迹，再通过 SFT 形成闭环提升。

## 2. 论文提出的方法论

### 2.1 核心思想
- 对每个实例构建**实例专用的 LoRA 模块** `w = [A, B]`，通过零阶梯度估计更新该 LoRA。
- 只依赖 **QA 对（query-answer pairs）** 作为监督信号，不依赖中间推理轨迹标注。
- 更新后的智能体能采样出成功轨迹，将这些轨迹加入高质量缓冲区，用于后续 SFT，实现闭环自进化。

### 2.2 关键技术细节
- **零阶梯度估计**：
  - 对 LoRA 参数施加随机扰动：`θ_perturbed = θ + (B + σϵ_B)(A + σϵ_A)`。
  - 在扰动策略下 rollout 出完整轨迹 `τ⁺`，计算答案损失 `ℓ⁺`。
  - 同时用原始策略 rollout 得到基线轨迹和基线损失 `ℓ⁰`。
  - 梯度估计为：`ĝ = (ℓ⁺ - ℓ⁰) / σ * ϵ`，再用 Adam 更新 LoRA。
- **并行扰动推理（Parallel Perturbation Inference）**：
  - 利用 LoRA 结构，将 backbone 输出 `θx` 只计算一次，多个扰动分支（不同 `A,B` 扰动）并行计算低秩部分 `(B+ϵ_B)(A+ϵ_A)x`，显著降低多扰动 rollout 的耗时。
- **自适应查找机制（Adaptive Lookup Mechanism）**：
  - 维护工具调用结果缓存池；对 `search` 使用语义相似匹配，对 `visit` 使用 URL/目标的严格匹配，减少重复网络调用，提升多扰动采样的时间效率。
- **答案困惑度损失（Answer Perplexity Loss）**：
  - 用轨迹条件（去掉生成答案后）下的标准答案负对数似然作为损失：
    `ℓ_ans = -1/M Σ log πθ(y_j | q, τ\ans, y_<j)`
  - 相比二值/相似度损失，该损失更平滑、更具判别性，适合零阶梯度估计。

### 2.3 算法流程（文字说明）
1. 对每个训练 QA 对初始化实例 LoRA。
2. 采样 K 个随机扰动方向，并行 rollout 得到扰动轨迹，计算答案困惑度损失。
3. 用零阶梯度估计更新 LoRA。
4. 用优化后的智能体重新采样轨迹，筛选低损失/正确轨迹。
5. 将高质量轨迹用于 SFT，更新共享策略，完成闭环。

## 8. 不足与局限

- 作者自述的局限：**尚未扩展到多模态智能体领域**，只在纯文本 LLM agent 上验证。
- 受控实验仅在有限 backbone（Qwen-3-4B/8B）和有限训练数据（304 个 QA 对）上进行，泛化到更大模型、更多领域仍需验证。
- 零阶优化本身采样成本较高，虽然引入了并行机制，但整体 rollout 仍比单次采样昂贵，实际部署时计算预算可能受限。

- 依赖外部搜索和网页解析工具，工具不稳定时可能影响轨迹质量和优化效果。
- 对“无轨迹标注”的强调虽好，但答案困惑度损失仍需要标准答案，在开放域任务中答案获取本身可能困难。
