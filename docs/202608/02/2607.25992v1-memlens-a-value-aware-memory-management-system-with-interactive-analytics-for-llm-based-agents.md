## 摘要
近年来，内存管理已成为基于LLM的智能体的关键基础设施，因为它直接影响长期推理、个性化响应和知识复用。然而，现有的LLM内存系统通常采用粗粒度（价值无关）的方式，将异构的用户-LLM交互记录统一处理，导致内存库中冗余且低影响的记录持续存在。为应对这一挑战，我们提出了MemLens，一种价值感知的内存管理系统，将内存记录作为一等数据对象。MemLens提供了一个端到端的交互式分析仪表板，展示完整的内存生命周期，包括Shapley式内存评估、价值感知存储和内存辅助响应。通过一个学习助手应用，该系统使用户能够检查内存价值、可视化分层内存结构，并在响应质量、检索延迟和Token消耗方面比较各种内存管理策略。因此，我们的MemLens可以作为面向LLM智能体的高效、可解释且个性化的长期内存管理系统。

## Abstract
Recently, memory management has become a key infrastructure for LLM-based agents, as it directly affects long-horizon reasoning, personalized responses, and knowledge reuse. However, existing LLM memory systems typically adopt a coarse-grained (utility-agnostic) manner that treats heterogeneous user-LLM interaction records uniformly, leading to redundant and low-impact records persisting in the memory repository. To address this challenge, we present MemLens, a value-aware memory management system that takes memory records as first-class data objects. MemLens provides an end-to-end interactive analytics dashboard that exposes the complete memory lifecycle, including Shapley-style memory evaluation, value-aware storage, and memory-assisted response. Through a study-copilot application, the system enables users to inspect memory values, visualize hierarchical memory structures, and compare various memory management strategies in terms of response quality, retrieval latency, and token consumption. Therefore, our MemLens can serve as an efficient, interpretable, and personalized long-term memory management system for LLM-based agents.

- **研究背景**：内存管理已成为 LLM 智能体的关键基础设施，直接影响长期推理能力、个性化响应和跨会话知识复用。实际中，智能体记忆具有异构性，不仅包括对话历史，还包括中间推理轨迹、检索文档和工具执行输出等。随着会话延长，记忆库持续膨胀，管理难度也不断增大。
- **核心问题**：现有 LLM 记忆系统普遍采用**粗粒度、效用无关**的管理方式：
  - 要么近乎全量保留所有候选记录；
  - 要么通过摘要式启发式方法进行压缩；
  - 不显式建模“哪些记忆单元对未来任务真正有用”，导致冗余和低影响记录长期占用存储空间，稀释任务相关上下文、扩大检索空间，并造成不必要的 token 消耗。
- **深层挑战**：记忆的有用性**既非均匀、也非静态**——同一记忆单元对某些查询有帮助而对另一些则无关；其贡献还取决于已有哪些其他记忆单元同时存在。因此，有效的记忆管理不能仅依赖通用摘要，而需要一种有原则的方法来估计异构记忆单元的下游效用，同时保证估计效率足以支撑实际的存储与检索决策。
- **整体含义**：论文提出 **MemLens**，一个价值感知的记忆管理系统，将记忆记录作为一等数据对象，以 Shapley 值为核心工具显式量化记忆的下游效用，并贯穿记忆评估、存储与响应三个环节，为 LLM 智能体的长期记忆管理提供了高效、可解释、个性化的新范式。

## 2. 论文提出的方法论：核心思想、关键技术细节与公式

### 2.1 整体框架

MemLens 由三个相互衔接的核心模块构成，形成一个统一的“价值感知记忆生命周期”：

- **记忆数据评估**（Memory Data Evaluation）
- **价值感知存储**（Value-Aware Memory Storage）
- **记忆辅助响应**（Memory-Assisted Response）

### 2.2 记忆数据评估

该模块分两步完成记忆价值的量化：

**(1) 记忆单元构建：**

- 将原始的用户-LLM 交互记录切分为**句子级原子单元**；
- 利用 LLM 将原子单元分组聚合为**多级抽象摘要**，形成层次化记忆结构；
- 保留从摘要节点到原子单元的**溯源链接**，避免信息丢失；
- 这一设计允许系统将多个低效碎片替换为单个高价值记忆，提升存储效率与记忆质量。

**(2) 记忆价值估计：**

- 采用 **LLM-as-Judge** 作为效用评分工具，由一个独立于记忆估值过程的裁判模型衡量记忆单元对下游推理任务的贡献；
- 核心直觉是：一个记忆单元如果能显著提升一个**轻量级代理模型 M_𝑝**（默认使用 Qwen2.5-7B，用户可在仪表板切换）的输出质量，则该单元具有较高价值；
- 效用函数定义为：给定用户查询 q 和记忆单元子集 S，其效用为代理模型在注入记忆前后输出得分之差：

V_q(S) = Score(M_𝑝(q ⊕ S)) − Score(M_𝑝(q))

- 在此基础上，论文定义了 **Memory Shapley Value（MS-value）**，即每个记忆单元 mᵢ 对所有不包含 mᵢ 的子集 S 的边际贡献的加权平均：

ϕ(mᵢ) = Σ_{S⊆M\{mᵢ}} [ |S|!(M−|S|−1)! / M! ] × [V_q(S∪{mᵢ}) − V_q(S)]

- MS-value 继承了 Shapley 值的公平性性质：**零玩家性（无搭便车）**、**对称性**和**线性可加性**；
- 为降低计算开销，论文采用**分层采样策略**近似记忆值：按子集大小分层、按比例抽样，将时间复杂度从指数级降至 **O(ρM)**，其中 ρ 为采样预算，通常设为 **20～100**，以满足交互式分析的实时性要求。

### 2.3 价值感知存储

- **选择性保留**：设置价值阈值 τ，仅保留 ϕ(mᵢ) ≥ τ 的记忆单元，为用户提供“存储成本 vs. 推理性能”的可调权衡；系统支持交互式阈值调节并即时反馈记忆规模、压缩率和预期效用；
- **层次化组织与整合**：利用前一步产生的多级抽象构建记忆树——叶节点为原子记忆单元，内部节点为高层语义摘要。新记忆单元进入时，通过 **LLM 辅助整合算子**决定三种处理方式：
  - 合并到现有节点；
  - 更新现有节点；
  - 作为新节点插入；
  - 判断依据是语义相似度：高度相似→合并，部分重叠→更新，无关→新增。
- **交互式记忆分析**：提供用户画像（从保留的高价值记忆中生成结构化摘要并注入系统提示）、词云可视化、价值分布、记忆规模与压缩率等统计视图。

### 2.4 记忆辅助响应

- **响应生成**：
  - 先以用户偏好画像作为系统提示，保持跨会话一致性；
  - 从向量数据库中检索相关记忆，并根据 MS-value 对检索结果**重新排序**，优先注入既语义相关又有实证高价值的记忆单元到 LLM 上下文；
- **记忆归档**：用户可将完成的会话归档，送入价值感知管线，依次经过记忆单元构建、价值估计和选择性存储，形成**闭环记忆生命周期**，持续适应用户行为变化。

## 6. 论文的主要结论与发现

- 现有记忆管理的粗粒度、效用无关策略会导致冗余记忆累积，损害响应质量并增加 token 开销；
- Shapley 式记忆价值评估能够有效刻画记忆单元对下游任务的边际贡献，为选择性保留提供有原则的依据；
- 价值感知存储策略在 EduMemBench 上**一致地改善了响应质量、检索延迟和 token 消耗之间的权衡**；
- MemLens 的可视化仪表板使记忆价值、层次化组织和策略对比对用户透明，提升了记忆系统的可解释性；
- MemLens 作为高效、可解释、个性化的长期记忆管理系统，为 LLM 智能体的记忆管理提供了新范式。

## 7. 优点：方法与实验设计的亮点

- **问题切入精准**：直指现有系统“效用无关”这一根本缺陷，以“价值感知”重构记忆生命周期，问题定义清晰且有实际意义；
- **理论根基扎实**：引入 Shapley 值为记忆单元定义价值（MS-value），继承了公平性公理（零玩家性、对称性、线性可加性），相比启发式打分更加有原则；
- **效率设计合理**：通过分层采样将 Shapley 值计算从指数级降为 O(ρM)，使价值估计在交互式场景下可落地；
- **闭环生命周期设计**：记忆评估→存储→响应→归档形成完整闭环，记忆可以持续演化适应新需求，而不是一次性静态处理；
- **可解释性与透明性**：记忆树可视化、颜色编码价值分布、词云、用户画像等设计让用户能够直接理解记忆系统的内部运作；
- **系统定位中立**：MemLens 是 benchmark 无关的，可扩展至 LoCoMo、LongMemEval 等公开基准；
- **实用导向**：提供多种 LLM/代理模型选项、FAISS 等不同向量后端、阈值可调等灵活配置，便于不同场景适配。

## 8. 不足与局限

- **实验验证不足**：没有提供具体数值结果（响应质量得分、延迟数值、token 节省比例等），缺少消融实验和敏感性分析（如阈值 τ、采样预算 ρ 的影响），说服力有限；

- **单一场景限制**：仅在数据库课程学习（study-copilot）这一特定场景验证，缺乏跨领域、跨应用的泛化证据；

- **Shapley 值的静态假设**：记忆价值基于历史数据计算，若用户兴趣发生剧烈漂移，历史高价值记忆可能不会及时反映新偏好（虽有闭环机制，但缺乏加速适应的设计）；
