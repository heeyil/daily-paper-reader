## 摘要
基于大型语言模型的购物代理正越来越多地部署在真实世界的电子商务平台上，产生了大量的用户交互日志，这些日志为改进这些代理提供了宝贵的监督信号。然而，现有方法主要依赖离线训练信号，如用户-物品交互或合成偏好数据，而很大程度上忽视了用户自然对话反馈中所包含的丰富监督。此外，可用的在线反馈是异构、稀疏且含噪的，这使得自动将其转化为可靠的学习信号变得困难。为了解决这些挑战，我们提出了LOFA，一个无需人工标注即可让购物代理直接从真实在线交互日志中学习的框架。LOFA将基于可验证购买结果的强化学习与反馈感知的在线策略蒸馏相结合，后者能识别用户对话中的指令并将其转换为密集的令牌级监督。这些互补的目标同时捕捉了协作行为模式和用户特定偏好。在真实电子商务日志上的大量实验表明，LOFA在推荐质量、响应有用性和用户满意度对齐方面持续优于强基线，突显了从真实在线用户反馈中学习购物代理的有效性。

## Abstract
Large language model-based shopping agents are increasingly deployed in real-world e-commerce platforms, generating massive amounts of user interaction logs that provide valuable supervision for improving these agents. However, existing approaches primarily rely on offline training signals, such as user-item interactions or synthetic preference data, while largely overlooking the rich supervision contained in users' natural conversational feedback. Moreover, the available online feedback is heterogeneous, sparse, and noisy, making it difficult to transform into reliable learning signals automatically. To address these challenges, we propose LOFA, a framework that enables shopping agents to learn directly from real online interaction logs without human annotation. LOFA combines reinforcement learning over verifiable purchase outcomes with feedback-aware on-policy distillation, which identifies users'in-dialogue directives and converts them into dense token-level supervision. These complementary objectives capture both collaborative behavioral patterns and user-specific preferences. Extensive experiments on real-world e-commerce logs demonstrate that LOFA consistently improves recommendation quality, response helpfulness, and user-satisfaction alignment over strong baselines, highlighting the effectiveness of learning shopping agents from real online user feedback.

## 2. 论文提出的方法论

### 2.1 核心思想

LOFA 的核心思想是：从真实在线交互日志中自动提取两类互补监督信号，并通过顺序训练管道进行优化。

- **显式行为反馈**（如购买结果）→ 提供结果级、可靠的监督，回答“推荐是否成功”。
- **对话内指令反馈**（如用户批评、偏好细化）→ 提供细粒度、令牌级的监督，回答“用户为何满意或不满”。

### 2.2 技术细节

#### （1）显式行为反馈学习：GRPO 强化学习

- **数据构造**：从在线日志中筛选出最终成功购买的会话，保留完整交互轨迹、用户画像（元画像、短期偏好、购物记忆），以购买商品作为可验证的奖励信号。
- **奖励函数设计**（两种互补奖励）：
  - **格式奖励（Format Reward）**：若响应符合预定义格式（含 `<think>`/`<answer>` 标签、足够的推荐数量、有效商品ID）则为 0，否则为 −1：

    ```
    R_fmt(τ) = 0（格式合规） 或 −1（格式违规）
    ```

  - **推荐奖励（Recommendation Reward）**：以购买商品为目标，计算推荐列表的 NDCG@10 作为奖励：

    ```
    R_rank(τ) = NDCG@10(τ)
    ```

  - **总奖励**：

    ```
    R(τ) = −1（若格式违规），否则 = R_rank(τ)
    ```

- **优化算法**：使用 GRPO（Group Relative Policy Optimization）进行强化学习优化。

#### （2）对话内指令反馈学习：反馈感知的在线策略蒸馏

- **反馈挖掘（Feedback Mining）**：
  - 使用 LLM（DeepSeek-V3.2）分析用户后续反馈，将其分为五类：
    1. **显式批评（Explicit Criticism）**：用户明确指出现有推荐违反了之前声明的需求。
    2. **隐含推断（Implicit Deduction）**：用户提出了可从画像/上下文/常识推断的约束。
    3. **纯负面反馈（Pure Negative Feedback）**：用户拒绝推荐但未给出具体改进方向。
    4. **比较性偏好（Comparative Preference）**：用户通过产品间比较表露细粒度偏好。
    5. **话题转移/放弃（Topic Shift/Abandonment）**：该类不包含可行动的监督信号，直接丢弃。
  - LLM 同时生成简要解释，描述用户不满或偏好细化的潜在原因。

- **反馈感知教师模型构建**：
  - **学生模型**仅能看到部署时信息：`X_S^t = [P_u; H_t; q_t; o_t]`
  - **教师模型**额外获得特权反馈信息：`X_T^t = [C_t; a_t; q_{t+1}; c_t; e_t]`，其中包含上一轮代理响应、后续用户反馈、反馈类别和解释。
  - 教师模型与基础模型共享参数，但通过“特权未来反馈”增强监督能力。

- **在线策略蒸馏（On-Policy Distillation）**：
  - 学生策略生成响应序列后，教师模型基于特权上下文对该生成轨迹进行逐 token 评估。
  - 优化目标为**反向 KL 散度**：

    ```
    L_OPD = E[ D_KL(p_s || p_t) ]（按 token 平均）
    ```

  - 这种设计将稀疏的对话反馈转化为密集的令牌级监督信号。

#### （3）顺序训练管道

- 两个反馈源的数据粒度不同（会话级 vs. 回合级），因此 LOFA 采用**顺序训练**而非联合优化：
  1. **第一阶段**：先用 GRPO 从购买结果中学习，使模型学习导致成功购买的推荐行为。
  2. **第二阶段**：再用在线策略蒸馏从对话反馈中学习，增强模型对用户偏好和响应质量的把握。
- 由于两类监督均可自动从真实日志中提取，LOFA 天然支持周期性模型更新。

## 6. 论文的主要结论与发现

1. **行为反馈学习大幅提升推荐质量**：+RL 在 NDCG、Recall、MAP 上均显著优于 Base，说明购买结果提供可靠结果级监督。
2. **指令反馈学习显著提升对话质量**：+OPD 的 Success Rate 远高于 Base，说明对话反馈可有效转化为行动监督。
3. **两类反馈互补**：+RL 主要改善推荐排名，+OPD 主要改善响应质量；结合两者取得最佳综合表现。
4. **训练顺序重要**：RL→OPD 一致优于 OPD→RL，说明“先学习可靠结果级监督，再学习细粒度指令监督”是更优策略。
5. **优于推理时自反思**：基于参数更新的反馈学习显著优于仅靠推理时自我修正的 Self-Reflection 基线。
6. **推理能力至关重要**：NoThink 显著劣于所有保留推理模式的方法，说明显式推理对购物代理至关重要。
7. **SFT 效果有限**：由于在线日志缺乏推理轨迹，SFT 损失了多步推理能力，效果不如 RL 和 OPD。
8. **消融发现**：
   - 推荐奖励是行为反馈学习中最关键的组件（移除后性能下降最大）。
   - 隐含推断是最有价值的指令反馈类型（移除后 Success Rate 下降最大）。
9. **框架具有骨干无关性**：LOFA 在 4B 和 8B 规模的模型上均取得一致改进。
