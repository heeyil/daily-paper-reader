## 摘要
复杂系统作为人工生命研究的核心对象，通过非线性、反馈驱动的相互作用建模多种现象，产生涌现行为，其应用涵盖从种群动力学、生物学到经济政策和战略决策等领域。然而，预测反馈结构如何产生涌现行为——这是人工生命领域的一个核心开放问题——使得目标导向的设计极具挑战性。在既定实践中，系统结构用诸如DYNAMO或STELLA等专用建模语言编写，这加剧了挑战，因为劳动密集型的工作流程限制了采用并阻碍了及时决策。为应对这些挑战，我们引入CEDAR，一种自主方法，利用大语言模型（LLM）智能体来发现满足用户指定行为目标的复杂系统。我们的关键创新在于将LLM驱动的蒙特卡洛树搜索（MCTS）与复杂系统深度耦合：在每次迭代中，LLM评判器根据指定目标评估涌现行为，LLM编辑器提出改进变体，其中评判器充当适应度函数，编辑器充当变异算子，类似于进化计算中的生成-评估循环。我们将复杂系统表示为具有领域特定原语的受限、可运行的Python子集，使LLM能够直接修改系统动力学。CEDAR将此形式化为一种MCTS变体，具有LLM参数化的转移核和值函数，从而在保持解多样性的同时实现复杂系统行为的目标导向发现，其基于LLM的可解释性揭示了结构变化如何驱动涌现行为。CEDAR减少了人工工作量，同时实现了现有方法难以达成的能力，促进了复杂系统在各领域的更广泛采用。

## Abstract
Complex systems, core objects of study in artificial life, model diverse phenomena through nonlinear, feedback-driven interactions that produce emergent behavior, with applications from population dynamics and biology to economic policy and strategic decision-making. Yet the difficulty of predicting how feedback structure gives rise to emergent behavior, a central open problem in artificial life, makes goal-directed design exceptionally challenging. In established practice, system structures are written in specialized modeling languages such as DYNAMO or STELLA, compounding the challenge with labor-intensive workflows that limit adoption and hinder timely decision-making. To address these challenges, we introduce CEDAR, an autonomous method that uses Large Language Model (LLM) agents to discover complex systems satisfying user-specified behavioral goals. Our key innovation is an LLM-driven Monte Carlo Tree Search (MCTS) deeply coupled with complex systems: at each iteration, an LLM Judge evaluates emergent behavior against specified goals and an LLM Editor proposes improved variants, with the Judge acting as a fitness function and the Editor as a variation operator, akin to a generate-and-evaluate loop in evolutionary computation. We represent complex systems as a restricted, runnable subset of Python with domain-specific primitives, letting LLMs modify system dynamics directly. CEDAR formalizes this as an MCTS variant with an LLM-parameterized transition kernel and value function, enabling goal-directed discovery of complex system behaviors while preserving solution diversity, and its LLM-based interpretability reveals how structural changes drive emergent behavior. CEDAR reduces human effort while enabling capabilities difficult to achieve with existing approaches, facilitating broader adoption of complex systems across domains.

## 2. 论文提出的方法论

### 2.1 核心思想

- 将复杂系统发现问题**形式化为进化搜索过程**，由 MCTS 提供结构化候选种群：
  - **LLM Judge（评判器）** 充当适应度函数（fitness function），评估涌现行为与目标的契合度；
  - **LLM Editor（编辑器）** 充当变异算子（variation operator），生成改进的系统变体。
- CEDAR 是一个带 **LLM 参数化转移核与值函数**的 MCTS 变体，在保持解多样性的同时实现目标导向的行为发现。

### 2.2 统一表示（Unified Representation）

- 将复杂系统表示为**受限的、可运行的 Python 子集**，包含四个必要组成部分：
  1. 初始化（初值 x₀）；
  2. 中间计算（辅助变量）；
  3. 导数评估（计算 f(x_t, t)）；
  4. 欧拉法积分（x_{t+∆t} = x_t + ∆t·f(x_t, t)）。
- 以 Python 代码替代 DYNAMO / STELLA 专用语言，利用 LLM 的强编码能力；同时加入**内联文档与领域特定数学原语**（如 graph、delay、smth1 等），帮助 LLM 理解语义、生成符合约束的代码。

### 2.3 算法流程（MCTS 搜索）

CEDAR 的搜索流程（Algorithm 1）如下：

1. **初始化**：以初始系统 P₀ 为根节点建立搜索树 T，执行系统得到记录 R₀，由 LLM Judge 评估得到 (A₀, S₀)。
2. **节点选择（Select）**：从可扩展节点集合 V_exp 中选择得分最高的节点 v：
   - SCORE(v) = S_v + α·√(ln(c_p+1)/(c_v+1))·I[c_v < τ] + γ·DEPTH(v)
   - 其中 S_v 为节点性能得分，c_v/c_p 为节点及其父节点的扩展次数，τ 为扩展次数上限，α 控制探索程度，γ 控制深层节点偏好（广义 UCT，结合渐进展宽与深度奖励）。
3. **扩展策略选择**：从 8 种策略（breakthrough、aggressive、amplify、exploratory、targeted、contrarian、balanced、conservative）中均匀采样。
4. **节点扩展（Expand）**：LLM Editor 基于父系统 P_v、分析 A_v、策略 s 与目标 G 生成新系统变体 P_u ← LLMEDITOR(P_v, A_v, s, G)；执行 P_u 获得记录 R_u；LLM Judge 产生分析-得分对 (A_u, S_u)。
5. **更新与回溯**：将新节点加入树；若 c_v ≥ τ 则从可扩展集合移除；若 S_u 优于当前最优则更新 P*。
6. **输出**：返回最佳系统 P*。

### 2.4 理论连接

- **节点选择**是 UCT 的泛化，结合了渐进展宽（Progressive Widening）与深度奖励。
- **LLM Editor** 充当随机转移核：P_u ∼ P_θ(· | P_v, A_v, s, G)，连接学习转移的 MCTS 与基于模型的强化学习。
- **LLM Judge** 充当学习值函数，提供有界的有噪奖励；在奖励噪声有界且非对抗时，UCT 的一致性理论可部分适用。
- 论文明确指出：**MCTS 与 LLM 结合的收敛性与遗憾界保证仍是开放问题**。

## 7. 优点

- **表示创新**：以受限 Python 子集 + 领域原语统一表示复杂系统，避免另造 DSL，充分利用 LLM 的代码能力，且代码可直接运行与检查。
- **方法创新**：将 LLM 作为变异算子与适应度函数嵌入 MCTS，形成生成-评估的进化搜索环路；理论层面与 UCT、渐进展宽、学习转移核、学习值函数建立明确连接。
- **保持多样性**：树形搜索天然保留分支解，支持开放探索与敏感性分析，契合人工生命对涌现行为多样性的追求。
- **可解释性**：每一步编辑都有 LLM 生成的文字理由，显著降低复杂系统设计的理解门槛。
- **可扩展性**：自适应上下文子采样使方法可处理大规模树与数千步长记录（60 变量、4000 步），远超以往同类工作（4 变量、12 步）。
- **实验设计相对严谨**：在为基线提供完整公式先验结构（严格优于 CEDAR 的输入信息）的情况下，仍能取得更优性能，结论具有说服力。

## 8. 不足与局限

- **循环性风险（circularity）**：LLM Judge 既打分又与 Editor 共享模型类别，抽象目标设定仍依赖 LLM 自身判断，可能引入自我确认偏差。
- **统计显著性不足**：论文报告的是趋势而非严格统计声明；缺少多种子、多样本的标准差与显著性检验。
- **实验覆盖有限**：深入实验仅聚焦两个系统；20 个数据集中的其余系统未做充分评估；未与经典进化算法、多目标优化方法系统对比。
- **理论保证缺失**：MCTS + LLM 方法的收敛性与遗憾界仍是开放问题，现有理论只能提供部分保证。
- **成本与稳定性**：每次运行需 $10–$50 与约 30 分钟；LLM 可能违反格式约束（虽有重试机制但仍有失败概率），对 LLM 供应商能力有一定依赖。
- **可解释性边界**：LLM 分析是辅助人工审查的理由陈述，而非经过验证的"结构→涌现"因果解释，该核心开放问题仍未解决。
- **真值系统的随机性**：记录拟合中真值本身含随机死亡率，CEDAR 的记录一般落在真值变异范围内，但精确匹配受噪声地板限制。
