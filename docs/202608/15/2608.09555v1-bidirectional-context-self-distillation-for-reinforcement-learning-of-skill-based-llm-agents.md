## 摘要
外部自然语言技能为大型语言模型（LLM）智能体提供了可复用且可编辑的指导，以解决复杂任务。然而，其有效性不仅取决于技能质量，还取决于策略能否将提供的指导转化为合适的行动。然而，专门用于提升这种技能利用能力的方法在很大程度上仍未得到充分探索。在实践中，基于技能的智能体通常使用以任务级奖励为中心的强化学习目标进行训练，这类目标提供的监督有限，难以捕捉策略在利用所提供技能时有效性的细微差异。我们提出了BCSD（双向上下文自蒸馏，Bidirectional Context Self-Distillation），一个将自蒸馏与强化学习相结合的框架，用于训练LLM智能体更有效地使用外部技能。与依赖于单一特权上下文的先前自蒸馏方法不同，BCSD从两个互补的技能上下文视角评估每条轨迹。增强视角引入了更高级别的元技能（Meta-Skill）指导，而缩减视角则修剪通用指导以突出任务特定技能。它们互补的令牌级信号被结合起来以重新缩放强化学习优势。在ALFWorld和WebShop上的实验表明，BCSD在多种模型规模下取得了最强的整体性能，使智能体能够更有效地利用外部技能。消融研究进一步验证了增强和缩减上下文视角的互补贡献。代码将发布以确保完全的可复现性。

## Abstract
External natural-language skills provide large language model (LLM) agents with reusable and editable guidance for solving complex tasks. Yet their effectiveness depends not only on skill quality, but also on whether the policy can translate the provided guidance into appropriate actions. However, methods specifically designed to improve this skill-utilization ability remain largely underexplored. In practice, skill-based agents are commonly trained with reinforcement learning objectives centered on task-level rewards, which offer limited supervision and struggle to capture subtle differences in how effectively the policy uses the provided skills. We propose BCSD (Bidirectional Context Self-Distillation), a framework that combines self-distillation with reinforcement learning to train LLM agents to use external skills more effectively. Unlike prior self-distillation methods that rely on a single privileged context, BCSD evaluates each trajectory from two complementary skill-context views. The augmented view introduces higher-level Meta-Skill guidance, while the reduced view prunes general guidance to highlight task-specific skills. Their complementary token-level signals are combined to rescale the RL advantage. Experiments on ALFWorld and WebShop demonstrate that BCSD achieves the strongest overall performance across model scales, enabling agents to utilize external skills more effectively. Ablation studies further verify the complementary contributions of the augmented and reduced context views. Code will be released to ensure full reproducibility.

## 2. 方法论：BCSD框架

### 2.1 核心思想

BCSD（Bidirectional Context Self-Distillation，双向上下文自蒸馏）将**自蒸馏**与**强化学习**结合，通过围绕基础上下文构建**两个互补的上下文视角**，产生比单一特权上下文更可靠的token级监督信号，并利用该信号重缩放GRPO优势（advantage），从而训练智能体更有效地利用外部技能。

### 2.2 关键技术细节与算法流程

**（1）基础上下文设置**

- 采用分层SkillBank结构。对查询 Q（任务类型 c），基础上下文为：
  - C₀ = (Q, G, S_c)，其中 G 为通用技能（General Skill），S_c 为检索到的任务特定技能（Task-specific Skill）。
- 从策略 π_θ 在 C₀ 下采样 K 条轨迹，由GRPO计算组内相对优势 A_GRPOⁱ = (r_i − μ_r)/(σ_r + ε)。

**（2）Meta-Skill提取与动态刷新**

- **定义**：Meta-Skill是总结当前策略在各轨迹中应用技能的有效/无效方式的高层文本指导，捕获\textbf{策略相关}的技能使用经验，仅供教师（privileged context）使用，不参与学生推理或推理期。
- **初始化**：收集每个任务技能 S_c 相关的成功/失败轨迹证据集 E_c,+ 和 E_c,−，由冻结的外部LLM对比两类证据生成初始 Meta-Skill M_c⁽⁰⁾。
- **动态更新**：每个验证窗口结束后，使用窗口内新收集的轨迹证据刷新 Meta-Skill：M_c⁽ᵏ⁺¹⁾ = Extract_LLM(S_c, M_c⁽ᵏ⁾, E_c,₊⁽ᵏ⁾, E_c,₋⁽ᵏ⁾)，随后重置证据缓冲区。这使得Meta-Skill能持续跟踪策略演化。

**（3）双向上下文构建**

- **增强视角（Augmented View）**：C₁ = (Q, G, S_c, M_c)，在基础上下文上追加Meta-Skill，提供如何应用技能的高层指导（"如何更好地使用这些技能？"）。
- **缩减视角（Pruned View）**：C₂ = (Q, G_p, S_c)，用外部LLM一次性修剪通用技能 G 为精简版本 G_p（保留核心程序性指导，去除冗余），从而减少干扰信息，聚焦任务特定技能运用。

**（4）Token级优势重缩放**

- 对固定轨迹 τᵢ，用同一策略分别计算在 C₁ 和 C₂ 下相对于 C₀ 的token级对数概率差：
  - Δ_augⁱᵗ = log π_θ(yᵢ,ₜ|C₁, yᵢ,<ₜ) − log π_θ(yᵢ,ₜ|C₀, yᵢ,<ₜ)
  - Δ_pruⁱᵗ = log π_θ(yᵢ,ₜ|C₂, yᵢ,<ₜ) − log π_θ(yᵢ,ₜ|C₀, yᵢ,<ₜ)
- **融合两方向信号**：Δᵢ,ₜ = αΔ_augⁱᵗ + (1−α)Δ_pruⁱᵗ，α 为权重系数（实验设为0.9）。
- **重缩放优势**：
  - wᵢ,ₜ = clip(exp(sign(A_GRPOⁱ)·Δᵢ,ₜ), 1−c, 1+c)
  - A_BCSDⁱᵗ = A_GRPOⁱ·[(1−λₙ) + λₙ·wᵢ,ₜ]
- **关键性质**：BCSD只改变优势大小，**不反转**由轨迹级奖励决定的优化方向。
- **衰减调度**：λₙ从初始值λ₀=0.1线性衰减至0，训练早期提供密集上下文指导，后期逐渐回归环境奖励主导，避免策略对特权信号形成依赖。

**（5）策略优化目标**

- 采用标准裁剪GRPO目标：
  - L_BCSD(θ) = −Eᵢ,ₜ[min(ρᵢ,ₜ(θ)A_BCSDⁱᵗ, clip(ρᵢ,ₜ(θ), 1−ε, 1+ε)·A_BCSDⁱᵗ)] + βL_KL
- 其中 ρᵢ,ₜ(θ) 为token级重要性比率，L_KL 为KL正则化项。

## 6. 主要结论与发现

- **主结果**：BCSD在三种模型规模下均取得最强综合性能。
  - Qwen2.5-7B：ALFWorld平均83.6%（超越最强基线3.1点），WebShop成功率78.1%（最高），任务得分仅低于最优0.2点。
  - Qwen2.5-3B：ALFWorld达到82.0%（超越最强基线5.4点），WebShop得分和成功率分别超越最强基线4.4和9.4点，优势最突出。
  - Qwen3-1.7B：ALFWorld平均46.9%（最高），WebShop得分76.8%（最高），成功率仅低于最优0.8点。
  - 相比Skill_GRPO*（同样训练和推理均保留技能），BCSD在ALFWorld、WebShop得分和成功率上均显著提升。
- **组件消融结论**：
  - 两个上下文视角均不可或缺：去掉Meta-Skill视角降幅最大（ALFWorld: 82.0→71.1；WebShop: 66.4→50.0），去掉Pruned-Skill视角也明显下降（→75.0/57.0），证明单一上下文教师的信号不可靠，双视角互补有效。
  - λₙ衰减至关重要：保持常数导致性能显著下降（→76.6/52.3），支持早期自蒸馏脚手架+后期奖励主导的设计。
  - Meta-Skill动态更新非常必要：固定Meta-Skill导致下降（→78.1/50.0），尤其在WebShop上降幅达16.4点，说明策略演化后旧指导会过时。
- **超参数敏感性**：λ₀=0.1最优，过大（0.3/0.5）或过小（0.05）均下降；α=(0.9, 0.1)最优，均衡权重(0.5, 0.5)训练波动大、不稳定。
- **训练动态**：BCSD在训练早期（约60步）即显著加速提升，且后期不出现基线方法的性能回退，保持稳定领先。
- **跨视图一致性分析**：两个上下文方向的token级符号一致率仅约47%–53%（接近随机），说明二者提供的是互补而非冗余的指导；对冲突token，缩减视角的较小权重起到调节作用，使信号更保守可靠。
- **技能依赖分析**：移除任务特定技能 S_c 后，BCSD的成功率降幅（ALFWorld −2.3，WebShop −7.8）大于Skill_GRPO*（−0.8/−6.2），证明BCSD策略更依赖外部技能作为决策依据，而非记住任务知识；其内化的是"如何用技能"而非"任务本身"。
- **总体判断**：BCSD为技能型LLM智能体的训练提供了新范式——在保留外部技能显式性和可编辑性的同时，通过双向上下文自蒸馏改进智能体的技能利用能力。

Meta-Skill的提取与刷新依赖外部LLM，在训练过程中需多次调用，且需维护证据缓冲区，增加了训练流程的复杂度和计算开销；对训练基础设施和工程实现的要求高于标准GRPO。
- **额外前向计算开销**：BCSD在每步训练中需用同一策略分别对C₀、C₁、C₂三个上下文做前向计算以获得token级对数概率差，比单上下文教师的自蒸馏方法（如RLSD）多出至少一次完整前向，训练时间成本相应增加。
- **外部LLM质量依赖**：Meta-Skill的初始生成和动态刷新质量取决于外部LLM的总结与对比能力；文中未明确外部LLM的具体型号、温度等配置，也未讨论其在长尾任务或罕见失败模式下的鲁棒性。
- **通用技能修剪粒度较粗**：缩减视角对通用技能G仅做一次性整体修剪，未按任务类型或查询内容差异化裁剪；对于不同子任务（如ALFWorld的6类家务），同一份精简G_p可能并非最优，存在信息丢失风险。
- **理论分析相对薄弱**：对双向上下文信号有效性的解释主要依赖经验证据（跨视图一致率接近随机、消融实验），缺乏关于为何增强与缩减两个方向的信号能够互补、以及优势重缩放收敛性质的更严格理论分析。
- **基线超参数搜索细节缺失**：文中称各基线在同一实验设置下复现，但未汇报各基线（尤其是RLSD、Skill-SD、SDAR）的超参数搜索范围和最佳配置，读者难以判断基线的调优充分程度。

## 9. 未来研究方向（基于论文脉络的合理展望）

- **扩展到更多长程任务与模型规模**：建议在更多样化的智能体环境（如具身操作、网页导航、代码生成与工具调用、多轮对话）中验证BCSD的普适性，并在更大模型（10B以上）和不同体系结构上检验其可扩展性。
- **自适应超参调节机制**：α（增强/缩减视角权重）和λ₀（初始衰减系数）目前依靠人工设定，可探索基于训练动态（如token级置信度、优势方差）自适应调节的机制，减少人工依赖。
- **降低特权上下文成本**：探索更经济的Meta-Skill更新策略（如间隔更长、仅基于失败轨迹更新、或使用小模型蒸馏替代外部LLM），以及复用同一批轨迹减少额外前向次数，从而降低训练开销。
- **理论深化**：从策略梯度方差缩减、上下文蒸馏偏差等角度分析双向自蒸馏信号对优势估计的影响，给出收敛性或偏置-方差权衡的理论保证。
- **与参数内化方法的有机结合**：论文强调保留外部技能显式性的价值，未来可探索将BCSD训练出的“技能利用能力”进一步凝聚为轻量技能选择/调用策略，或在与参数内化方法（如Skill-SD）的混合框架中提升效率。
- **在线持续学习场景**：Meta-Skill动态刷新机制天然适合非平稳任务分布，可探索在持续学习、新技能不断加入场景下BCSD的适应性与灾难性遗忘表现。

## 10. 总结

BCSD是针对技能增强型LLM智能体训练的一项有价值的方法创新。它将自蒸馏从单一特权上下文拓展为增强与缩减两个互补视角，并借助Token级优势重缩放将上下文层面的指导融入GRPO优化目标，在不内化技能、不改变优化方向的前提下显著提升了智能体对外部技能的利用能力。在ALFWorld和WebShop两个长程基准、三种模型规模下均取得一致且稳定的性能提升，消融与进一步分析支持了其核心设计动机。虽然存在算力成本高、外部LLM依赖、理论分析不足等局限，但该工作为“如何让智能体更会使用技能”这一关键问题提供了首个系统性的训练框架，并对后续研究具有明确的启发意义。
