## 摘要
智能体工具结合了检索、路由、状态、溯源和验证，但局部成功的组件可能在共享状态上产生分歧。我们用有限的能力层（capability sheaf）对此类失败建模：茎（stalks）编码类型化行为签名，限制映射保留共享字段，而可接受的运行是有用的全局截面。一个精确的有限约束满足问题（CSP）定义可接受性，而线性化的相对上同调类提供诊断和搜索特征。在20个任务簇的受控实验中，引入了隐藏的内部中介体，其原始状态为扰动变量。对它们的上边界（coboundaries）取商，将每个簇的候选预算从2000减少到1000；对齐隐藏状态则消除了该差距。精确CSP与商空间结果一致，因此该结果证明了其对陈旧代表的不变性，而非对精确推理的优越性。随后，我们在来自PatchFuseBench的SWE-bench多语言池的发现分割上测试该方法：来自20个仓库的160个问题、875个真实候选补丁、2579个源代码感知的编辑原子，以及153个新执行的补丁。首次池级构造是常值的，因为$[b-Dx]=[b]$在$\operatorname{coker}D$中，因此无法对配置进行排序。一个以候选索引的修复在848/875个候选上非平凡，并在120/160个问题内变化。它解决了118个问题，而匹配的非上同调选择器解决了116个，但该差异在仓库间并不显著（精确符号翻转$p=0.75$）。留一仓库出的弃权门达到127/160，与强锚点持平，并比其匹配门多一个问题（$p=1.0$）。因此，发现门失败，确认分割保持密封。该研究支持受控不变性机制和可辨识性校正，但不支持现实世界中的上同调优势。

## Abstract
Agent harnesses combine retrieval, routing, state, provenance, and verification, but locally successful components may disagree on shared state. We model this failure with a finite \emph{capability sheaf}: stalks encode typed behavior signatures, restriction maps retain shared fields, and accepted runs are useful global sections. An exact finite constraint-satisfaction problem (CSP) defines acceptance, while a linearized relative cohomology class provides a diagnostic and search feature.   A controlled experiment over 20 task clusters introduces hidden interior mediators whose raw states are nuisance variables. Quotienting their coboundaries reduces the candidate budget from 2,000 to 1,000 per cluster; aligning the hidden state removes the gap. Exact CSP matches the quotient, so the result demonstrates invariance to stale representatives, not superiority over exact reasoning.   We then test the method on a discovery split from the SWE-bench Multilingual pool of PatchFuseBench: 160 issues from 20 repositories, 875 real candidate patches, 2,579 source-aware edit atoms, and 153 newly executed patches. A first pool-level construction is constant because $[b-Dx]=[b]$ in $\operatorname{coker}D$ and therefore cannot rank configurations. A candidate-indexed repair is nontrivial on 848/875 candidates and varies within 120/160 issues. It resolves 118 issues versus 116 for a matched noncohomological selector, but the difference is not supported across repositories (exact sign-flip $p=0.75$). A leave-one-repository-out abstention gate reaches 127/160, tying the strong anchor and exceeding its matched gate by one issue ($p=1.0$). The discovery gate therefore fails and the confirmatory split remains sealed. The study supports the controlled invariance mechanism and an identifiability correction, but not a real-world cohomological advantage.

## 1. 核心问题与整体含义

- **背景**：语言模型智能体的行为高度依赖其“harness”（工具/支架），包括指令、检索、路由、状态、溯源、验证与恢复等组件。现有系统通常通过外层循环搜索（如提示优化、程序/工作流/智能体设计搜索）来优化整体候选，并用标量分数衡量整体表现。
- **核心问题**：一种常见且难以解释的失败模式——每个能力子组件局部看起来都可用且正确，但没有任何一次执行能把所有能力连贯地组合起来。典型例子：仓库补丁智能体中，不同子系统分别能定位文件、恢复 API 修订、保留提交、选择测试，但这些答案可能指向不同的文件/修订/提交/测试，共享状态无法“胶合”。
- **整体含义**：本文用**有限能力层（capability sheaf）**为这种“局部正确、全局不一致”的失败提供形式化建模：茎（stalk）编码类型化行为签名，限制映射保留共享字段，可接受的运行是“有用的全局截面”。精确 CSP 决定语义可行性，线性化相对上同调类提供诊断与搜索分数。论文的核心主张很克制：真实世界中的上同调优势**不成立**，但受控不变性机制得到验证。

## 2. 方法论

- **能力层构造**：以五顶点关联图 $X$ 表示五项需求——本地化（L）、契约（C）、排序（O）、保持（P）、验证（V）。每个顶点的茎是有限类型化行为签名（如 file path、API revision、source commit 等），边上的重叠茎由字面字段投影（restriction map）定义。共有六个重叠（L–V、L–P、C–P、O–V、P–V、C–O）。
- **精确 CSP（式 1）**：候选 harness $c$ 的可行性为所有局部有用谓词（$s_v(c)\in G_v$）与所有边上限制相等（$\rho_{v\to e}s_v(c)=\rho_{w\to e}s_w(c)$）的合取。这是普通有限约束满足问题；层论不消除组合困难，而是分离“局部存在”与“胶合”，并提供跨候选的类型化线性诊断。
- **相对上同调类（式 2–3）**：将有限字段值编码为 GF(2) 上的一热基向量；cellular coboundary 为 $(\delta^0 x)_e=\rho_{v\to e}x_v+\rho_{w\to e}x_w$。边界截面类 $\partial[s_A]=[\delta^0 s_A]\in H^1(X,A;\mathbb{F})$ 精确地检测相邻类型化限制是否一致。独立重建的复形维度：$\dim C^0=246$、$\dim C^1=233$、$\operatorname{rank}\delta^0=173$，故 $\dim H^1(X)=60$、$\dim H^1(X,A)=233$。
- **隐藏内部商空间（式 4–5）**：在每条公共重叠坐标 $j$ 中插入隐藏中介顶点；改变隐状态 $h_j$ 相当于加上内部上边界 $D_j u=(u,u)$。商映射 $P_j=[I\ I]$ 满足 $P_jD_j=0$ 且 $\ker P_j=\operatorname{im}D_j$，于是 $[q_j(h_j)]\mapsto \ell_j+r_j$，**商类与隐状态无关**。这支撑了对中介状态（陈旧/左对齐/右对齐/随机）的直接干预实验。
- **不承诺超出线性化能证明的结论**：命题 2 给出单侧投资组合证书——$[t]\ne0$ 可判定无候选具有签名 $t$，但反过来不成立（如签名 $(1,0)$、$(0,1)$ 和目标 $(1,1)$：目标在张成中但无人实现）。商消失后必须跟随精确 CSP 或实际执行。

## 3. 实验设计

- **实验一：基线生成仓库任务（受控）**  
  - 数据：每个任务含 2 个迁移票据、每个票据 4 个同命名空间适配器文件、恰好 1 个部署拥有的文件；有效响应须编辑该文件、安装依赖声明的 API 修订、排序、保持提交、选对公共契约测试。模型只输出有界 JSON 编辑操作，外部 Python 进程应用并运行公共测试。  
  - 模型端点：`deepseek-ai/DeepSeek-V4-Flash` 与 `zai-org/GLM-5-FP8`（服务于 GLM-5.2）；4 个任务复本，全部 200 个候选×块行，272 次模型调用。  
  - 对比策略：full relative class、exact CSP、pairwise proxy、local marginal、shuffled class、adaptive NSGA-II、random。主对比是块内 NSGA-II 减全类候选评估数，用精确单侧符号检验。

- **实验二：隐藏内部商实验（预注册因果干预）**  
  - 20 个独立任务簇，每个簇有新鲜屏幕任务、新鲜留出任务和独立模型种子；两个端点×25 候选×20 簇 = 1,000 个候选结果，1,360 次模型调用。  
  - 对中介状态做 4 种结果盲干预：陈旧（stale）、左对齐、右对齐、随机化；共 4,000 次检查中商签名不变。  
  - 主对比：stale-raw 减 quotient 的候选评估数；以任务簇为独立统计单元、端点平均后用精确配对符号检验；aligned-left 为负对照；exact CSP 为正向语义对照。

- **实验三：真实仓库压力测试（PatchFuseBench / SWE-bench Multilingual 开发分割）**  
  - 从 41 个合格仓库中按仓库（而非问题）分割：20 仓库 160 问题作为发现分割，21 仓库 140 问题作为密封确认分割；本文只用发现分割。  
  - 数据规模：160 问题、875 个唯一源兼容候选补丁、2,579 个无损编辑原子（保留文件、基准区间、新旧字节、模式变化、源支持）、2,022 个区间重叠冲突对 + 109 个源本地语义替代对。  
  - GLM-5 评估每个原子（不接触测试/答案/gold）；强仓库留出锚点解决 127/160。  
  - 该实验先暴露并修复一个**可辨识性缺陷**：全池级矩阵 $D$ 的类 $[b-Dx_1]-[b-Dx_2]=[D(x_2-x_1)]=0\in\operatorname{coker}D$，即所有选择类别相同、无法排序；修复为候选索引复形（$D_S$ 仅含该候选内部列），得到分数 $q(S)=\|(I-D_SD_S^+)b\|_2/\|b\|_2$；848/875 个候选复形非平凡，120/160 个问题上分数有变化。  
  - 对比方法：matched router（同原子证据但无投影，用最大支持/最大风险）、exact semantic control（确定性二值优化）、LOO 仓库弃权门。153 个新补丁全部用官方固定 SWE-bench harness 执行完成，无基础设施失败。

## 5. 实验数量与充分性

- **受控基线**：4 个任务簇 × 2 端点 = 8 个块测量；200 行中 71 行通过留出测试且全是精确联合成功（DeepSeek 35、GLM 36）。主对比 7 个差值为 1.25、1 个为 2.375，全部支持全类；逐块符号检验 $p=0.00390625$；按任务平均后为 $p=0.0625$——方向在每个任务和端点一致，但任务级复制数很小。
- **隐藏实验**：20 个独立簇，主结果 20/20 全部支持商空间，精确符号检验 $p=9.5367\times10^{-7}$；平均配对差为 1.000，bootstrap 95% CI 为 [1.000, 1.000]；aligned 负对照差距为 0；exact CSP 与商一致。该实验预注册、结果盲、负对照完备，机制验证充分。
- **真实压力测试**：160 问题/20 仓库/875 候选/2,579 原子/153 新执行，规模真实；但直接比较仅在 3 个仓库出现差异（精确 $p=0.75$），弃权门仅 1 个非零仓库差异（$p=1.0$），因此统计支持很弱；发现门（≥4 问题增益、宏效应为正、≥6 仓库非零、$p\le0.2$）失败，确认分割保持密封。
- **客观公平性**：受控实验采用预注册协议、结果盲设计、以簇/仓库为聚类单元而非伪重复，并明确标注探索性 p 值。但基线只有 4 个簇，真实实验的 p 值本质是探索性的，作者对此非常诚实。

## 6. 主要结论与发现

- **受控机制成立**：商掉陈旧内部代表将候选预算从 2.000 降到 1.000（平均差异 +1.000，20/20 簇一致）；对齐隐状态后差距消失；exact CSP 与商完全一致。这说明增益来自**对隐藏状态扰乱的不变性**，而非对精确推理的优越性。Token 总量在端点内分别减少 71.2%（DeepSeek）和 71.7%（GLM）。
- **真实上同调优势不成立**：① 全池级相对类在数学上对任何选择都恒定，无法排序配置（式 7 的反例），但这一缺陷被候选索引修复所修正；② 修复后的商选择器比匹配的非上同调选择器多解决 2 个问题（118 vs 116），但仅分布在 3 个仓库（$p=0.75$）；③ LOO 弃权门 127/160，与强锚点持平，比匹配门多 1 个问题，但仅 1 个仓库差异（$p=1.0$）。任何方法都没有把锚点失败变成成功。发现门失败，确认分割不开放。
- **总体判断**：论文支持“商空间不变性机制”和“候选索引可辨识性校正”，但**反对在真实补丁融合中宣称上同调优势**。当前义务-风险复形太弱，真正的进展需要编码语义接口，而非把一个全局类附加到问题上。

## 7. 优点

- **清晰的形式化分离

清楚地区分“局部存在”与“全局胶合”：层论/CSP 的二分法给出可解释的诊断语言，而不是把问题混为单一评分。**
- **诚实的不承诺纪律**：命题 2 明确给出线性化方法的正反两面，对照实验用负对照和语义对照锁定机制，探索性 p 值被反复标注。
- **真实工作负载上的可复现压力测试**：候选索引复形修复、LOO 弃权门、固定 harness 上的完整执行，没有隐藏基础设施失败。
- **优秀的可辨识性自我修正**：全池级矩阵缺陷被作者自己发现并修复为候选索引复形，这提高了结论的可信度。
- **写作结构清晰**：预注册、结果盲、统计单元与伪重复的区分都以显式方式呈现。

## 8. 缺点与局限

- **统计功效严重不足**：受控基线只有 4 个任务簇（按任务平均后 $p=0.0625$）；真实实验只在 3 个仓库上出现差异，直接比较与弃权门都无统计显著性。这决定了论文只能做机制验证，不能做效果声明。
- **真实设置中的上同调优势在测量上不可分辨**：2 个问题的差异既可能反映真实但微弱的效应，也可能是噪声；探索性失败后确认分割保持密封，因此真实结论悬而未决。
- **形式化依赖于“字面字段投影”的限制映射**：与语义接口的距离很大。一个语义上正确的 API 修订可能因文件名不同而被判为不一致，反之亦然；线性化类对这类“语义等价但字面不同”的组合问题无能为力。
- **理论界与实验规模不匹配**：定理 6 的 Azuma 界和定理 4 的 Wedin 界都是渐近/参数依赖型保证，而实验只有几十个簇的样本量；这些界无法在本文数据上导出可操作置信度。
- **模型端点封闭性**：只测试 DeepSeek 与 GLM 两个端点，未覆盖开源小模型、更弱模型或更强模型；外部效度未知。
- **商空间不变性只说明“鲁棒”，未说明“有用”**：20/20 的簇一致增益可能来自陈旧表示的普遍有害，而非商空间的真实信息增益；负对照只能排除“任意扰动都有效”，无法排除“随机化本身有正则化作用”。

## 9. 我个人的评估

- **机制层面**：商空间论点是有说服力的。隐藏状态干预（陈旧/左/右/随机）都被同一商类吸收，且 20 个独立簇一致给出相同方向的增益，这是很干净的结果。作者没有夸大其为“表现提升”，而是恰当地称为“不变性机制”。
- **算法层面**：新颖贡献主要在“候选索引复形”上。全池级不可辨识性的发现及其修复是真正有价值的工程/理论洞见；在此之上，相对上同调类只是许多可行诊断信号之一，而非必要组件。
- **应用层面**：我不认为这篇论文证明了上同调类在真实补丁融合中的实用价值。它的主要贡献是作为一个精心设计的负结果与机制验证：指出“把全局类附加到问题上”在当前语义接口缺失的情况下不会产生可测量的真实收益。
- **可复现性判断**：预注册、结果盲、固定 harness、公开工件、明确的统计单元划分使得该论文在同类工作中处于较高的可复现水准。探索性分析也没有被伪装成确定性结论。

## 11. “如果我是作者”的改进建议

1. **增加基线簇数**：至少 16–20 个受控任务簇，使任务级符号检验具备可接受的功效；若成本受限，可减少每簇候选行数、保留簇数。
2. **把语义接口引入线性化**：在限制映射中并入“语义等价”的规范化（如规范路径、包/修订别名、提交哈希前缀解析），使字面字段投影退化为语义投影；否则商类永远受制于式 7 的不可辨识性问题。
3. **给出商类差异的下界驱动采样**：与其枚举 25 个候选束，可用相对不动点或障碍权重上界先剔除确定不可行候选，然后只对“类内不可分辨”的候选做精确 CSP——这样能把线性化与精确搜索的接口讲清楚。
4. **增加正对照**：除 aligned-left 负对照外，增加一个“已知有害的中介偏移”（如故意注入陈旧字段值），证明商类吸收的是无关扰动，而不会吸收真正影响语义的扰动。
5. **如实呈现真实实验为机制转移研究**：把统计显著性标签改为“差异不可分辨”，并给出最小可检测效应量，而不是依赖探索性倾向。

## 12. 对领域的影响与展望

- **对智能体 harness 设计**：该论文强烈提示，与其在外层循环里搜索“更聪明的评分函数”，不如先构建可共享、可拼接的语义状态。一个统一的能力层如果只连接字面字段，其全局截面诊断价值有限；只有接口映射携带语义（例如“编辑目标文件 foo、安装 API 修订 7c3、运行契约测试 t17”之间的依赖），线性化类才能真正排序真实配置。
- **对上同调方法在 NLP/Agent 中的应用**：本文可视为一个“最小可行示范”，证明代数拓扑工具能以有限、可计算的方式用于候选配置的诊断；但真实收益需要更丰富的障碍复形（语义原子依赖图）而不是单全局类。
- **对负结果的元科学价值**：论文展示了如何用预注册、结果盲、替代统计单元、探索/确认分割来避免自我欺骗。这个模板值得在 Agent 评估中推广，哪怕其正面结论微弱。
- **展望**：下一步最可行的路线是将候选索引复形推广为“语义接口复形”——顶点为语义操作，边为前置/后置条件，限制映射由类型化逻辑蕴含而非字段相等定义。在此之上，相对上同调类可能真正具备排序能力，而不再只是不变性诊断。
