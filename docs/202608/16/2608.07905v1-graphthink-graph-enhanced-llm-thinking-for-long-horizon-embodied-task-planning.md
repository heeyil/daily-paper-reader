## 摘要
基于大语言模型规划器的具身智能体常面临物理幻觉、对长时程任务泛化能力差以及缺乏环境感知等问题。我们提出GraphThink，一种新颖的框架，它整合了任务图以提供结构化知识实现稳健规划，并利用场景图维护环境记忆以支持事件驱动的重规划。具体而言，任务图通过上下文提示和迭代精炼引导大语言模型思考，有效缓解了规划幻觉。此外，在GRPO框架内，任务图为训练大语言模型规划器提供了精细的奖励设计，增强了长时程规划能力并提升了泛化性能。最后，由场景图驱动的事件驱动重规划模块实现了闭环的环境感知与错误修正。GraphThink在ALFRED基准上取得了最先进的性能。特别地，我们的高层规划器在验证集和保留的长时程任务上均超越了领先的基于API的大语言模型，凸显了其强大的零样本与少样本能力。额外的评估进一步证明了其对新颖任务和环境的强分布外泛化能力。

## Abstract
Embodied agents using LLM-based planners often struggle with physical hallucinations, poor generalization to long-horizon tasks, and lack of environmental awareness. We propose GraphThink, a novel framework that integrates a task graph to provide structured knowledge for robust planning and a scene graph to maintain environmental memory for event-driven replanning. Specifically, the task graph guides LLM thinking through contextual prompting and iterative refinement, effectively mitigating planning hallucinations. Furthermore, within the GRPO framework, the task graph offers delicate reward design to train the LLM planner, enhancing long-horizon planning capabilities and improving generalization. Finally, an event-driven replanning module, powered by the scene graph, enables closed-loop environment awareness and error correction. GraphThink achieves state-of-the-art performance on the ALFRED benchmark. In particular, our high-level planner surpasses leading API-based LLMs on both the validation set and held-out long-horizon tasks, underscoring its robust zero-shot and few-shot capabilities. Additional evaluations further demonstrate strong out-of-distribution generalization to novel tasks and environments.

## 1. 核心问题与整体含义（研究动机与背景）

- 论文聚焦于**具身智能体长时程任务规划**问题，尤其是利用大语言模型（LLM）作为高层规划器的场景。
- 现有 LLM 规划器存在三大关键缺陷：
  - **物理幻觉**：通用 LLM 缺乏物理接地，容易错误理解指令或生成不可执行的子任务序列，任务越复杂失败率越高。
  - **泛化能力差**：在有限域内数据上做监督微调（SFT）难以推广到未见过的长时程任务，且标注成本高。
  - **缺乏环境意识**：传统重规划多针对低层执行错误，难以检测“可执行但与指令目标不一致”的高层规划问题，容易做出短视决策。
- 整体含义：论文提出一种**双图增强的闭环规划系统 GraphThink**，通过任务图提供结构化的物理与逻辑知识，通过场景图提供动态环境记忆，将 LLM 的“思维”约束在可行的子任务转移空间内，从而提升长时程规划的可靠性、泛化性和环境适应性。

## 2. 方法论

GraphThink 包含三大核心模块：

- **（a）高层规划模块：任务图（Task Graph）**
  - **任务图构造**：
    - 节点代表子任务，例如 `PickupObject(obj)`、`PutObject(obj, rec)` 等，共 12 种 ALFRED 高层子任务。
    - 引入元类 `{obj, rec, mov, spec}` 对对象进行抽象，提升跨环境泛化。
    - 边表示可行的子任务转移关系，通过 **LLM 辅助的转移兼容性分析**构建：将子任务转为“前置条件–效果”接口，若前序效果满足后续前置条件且语义合理，则连边；该方法不依赖轨迹演示，可支持新任务扩展。
  - **任务图的三种用途**：
    1. **提示引导**：将图拓扑（节点标签 + 边关系）注入 prompt，要求每个后续子任务为前一子任务的邻居节点，从而减少规划幻觉。
    2. **GRPO 奖励设计**：在 GRPO 框架下设计多项奖励：
       - 格式奖励 `Rfmt`：约束输出为 XML/JSON 结构；
       - 节点级奖励 `Rnode`：按元类动态加权的对象有效性；
       - 边级奖励 `Redge`：检查相邻子任务转移是否满足图边约束；
       - 指令跟随奖励 `Rinst`：两阶段设计——覆盖关键子任务得 0.5，与 GT 计划精确匹配得 1.0，兼顾多解与精确性。
       - 总奖励：`Rtotal = Rfmt + Rnode + Redge + Rinst`。
    3. **外部验证器**：推理时对生成计划做节点合法性验证和边合法性验证，错误反馈给 LLM 进行迭代修正（最多 3 轮）。
- **（b）低层策略：记忆增强的低层动作策略**
  - 将高层子任务翻译为可执行原语动作。
  - 特点：**主动缓存**未来可能用到的任务相关对象位置和分割掩码；支持**实例级区分**，避免多个同类对象混淆。
  - 例如执行 `Pickup(Glassbottle1)` 时顺带记录 `Glassbottle2` 的位置，后续 `Put(Glassbottle2, Shelf)` 可直接利用缓存，提升导航效率和放置准确性。
- **（c）动态重规划：场景图（Scene Graph）驱动的闭环机制**
  - 构建**任务感知的场景图**：只维护任务相关对象的语义三元组（如 `on`、`next to`），规模小（ALFRED 中通常 <20 节点），在线增量更新，并包含过滤（物理合理性、任务相关性）和冲突消解（重新观察后由 VLM 重估）。
  - **事件驱动的重规划触发**：
    - 低层执行错误（如找不到物体、交互失败）；
    - 高层子任务完成（主动检查计划是否仍与指令目标对齐，如“微波炉在边桌上但计划放到台面上”）。
  - 重规划时结合原始计划、已执行轨迹、反馈和场景图记忆，由 LLM 决定保留或修订，且修订必须经过任务图约束以保证可行性。

## 6. 主要结论与发现

- GraphThink 在 **ALFRED 测试集**上达到 SOTA：Tests Seen SR 67.71%、GC 73.96%；Tests Unseen SR 68.52%、GC 75.76%，显著优于此前方法。
- **仅使用目标指令**（不使用 step-by-step 指令）就超越了多数使用细粒度指令的基线，说明高层规划模块本身很强。
- 高层规划器在验证集和长时程任务上均优于 Deepseek-R1、Gemini-2.5-Pro、GPT-5.2 等 API LLM 的多种提示策略，且在长时程任务上优势更明显。
- 任务图是核心：移除任务图提示或 GRPO 训练会造成显著性能下降；**边级约束**比节点级约束更关键。
- **指令跟随奖励**能防止“满足图约束但偏离指令”的奖励黑客行为。
- 数据效率高：仅用 1%–20% 训练数据即可在短任务验证集上取得不错效果；长时程任务上随数据量增加显著提升。
- 具备零样本潜力：仅靠图奖励和未标注数据也能达到较高规划准确率。
- 能泛化到新动作（AI2-Thor）和新环境（VirtualHome），且跨域迁移有效。
- 在任务复杂度增加时，GraphThink 保持较高规划成功率和低错误率，推理时间稳定（约 7–10 秒，12 子任务时约 23.7 秒），效率优于 GPT-5.2+RAG。

## 7. 优点

- **双图结构化设计**：任务图提供“可执行性”约束，场景图提供“环境状态”记忆，两者互补，形成闭环。
- **任务图的多阶段集成**：prompt 引导、GRPO 奖励、推理验证三管齐下，显著缓解 LLM 物理幻觉。
- **奖励设计考虑多解性**：相比单一 GT 轨迹，图奖励鼓励探索所有可行路径，同时用指令奖励保持语义对齐，避免过拟合和奖励黑客。
- **事件驱动的双触发器重规划**：既处理低层执行失败，又能在子任务完成点主动检查高层指令对齐，具备前瞻性。
- **场景图轻量化**：任务感知、动态修正，避免冗余对象噪声，维护成本低。
- **低层策略的记忆增强**：主动缓存未来对象位置和实例区分，减少重复探索和错误交互。
- **泛化实验全面**：覆盖新任务组合、跨环境、跨动作空间的迁移，验证了方法通用性。

## 8. 不足与局限
