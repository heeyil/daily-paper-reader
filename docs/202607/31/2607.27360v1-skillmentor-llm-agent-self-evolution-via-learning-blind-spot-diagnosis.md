## 摘要
智能体自我进化主要关注学习如何行动，却忽视了一个同等重要的能力：学习发现智能体自身不知道什么。现有方法通常假设故障发现是给定的，专注于在故障被识别后如何修复。我们探究盲点诊断本身能否被学习。因此，我们将诊断作为独立于执行的一种智能体能力来研究，并排除了两个可能的进展来源：执行器适应和人类监督。在这些约束下，性能无法通过执行器更新或带注释的示例得到提升，迫使所有改进都源于所习得的诊断能力。我们提出了SkillMentor，它通过强化学习训练一个导师策略，用以生成诊断任务、识别反复出现的故障模式，并将其整理为可复用的纠正技能。在AppWorld和BFCLv3上，SkillMentor平均提升了执行器性能44.2%。这些结果表明，盲点诊断是一种可学习的能力，它使得在不更新执行器权重或依赖人工整理数据的情况下也能够实现自我进化。

## Abstract
Agent self-evolution has primarily focused on learning how to act, while overlooking an equally important capability: learning to discover what an agent does not know. Existing approaches typically assume that failure discovery is given, focusing on how to repair failures once they are identified. We ask whether blind-spot diagnosis itself can be learned. We thus study diagnosis as an agent capability separate from execution, and exclude two alternative sources of progress: executor adaptation and human supervision. Under these constraints, performance cannot improve through executor updates or annotated examples, forcing all improvements to originate from the learned diagnostic capability. We propose SkillMentor, which trains a Mentor policy via reinforcement learning to generate diagnostic tasks, identify recurrent failure modes, and curate them into reusable corrective skills. Across AppWorld and BFCLv3, SkillMentor improves executor performance by an average of 44.2%. These results suggest that blind-spot diagnosis is a learnable capability, enabling self-evolution without updating executor weights or relying on human-curated data.

## 2. 方法论：SkillMentor

- **核心思想**：训练一个轻量**Mentor策略** πθ，通过强化学习主动发现冻结执行器的盲点，将其整理为外部可复用纠正技能，形成发现→策展→暴露新盲点的自我进化反馈回路。
- **关键技术细节**：
  - **三步流程**：
    1. **盲点发现**：Mentor 在无预定义任务的环境沙箱中自由探索 API/工具，生成候选诊断任务（候选数 G=8），并维护多样性缓冲区以防策略坍缩。
    2. **差距评估**：对每个候选任务，由强参考模型 M 与冻结执行器 πE 分别执行并打分，两者得分差 δi 即为“诊断差距”。差距最大的任务进入技能策展。差距阈值随时间线性衰减（0.5→0.2），以追踪能力边界迁移。
    3. **技能策展**：Mentor 基于失败轨迹生成候选技能，支持 ADD、UPDATE、MERGE 三种库操作；技能须通过语法有效性（格式合规 f(c)）和执行器落地验证（执行器再次尝试，改进量 Δ > 0.5）才可入库；低成功率的技能会被 DELETE 机制自动淘汰。
  - **联合优化与奖励设计**：Mentor 通过 GRPO 联合优化两个奖励信号——**发现奖励** rdisc = δi（衡量任务的诊断价值）与**策展奖励** rcurate = 0.3·f(c) + 0.7·Δ（衡量技能效用）。整体目标是最大化累积期望奖励：max_θ Eπθ[Σt (rdisc(qt) + rcurate(ct))]，其 GRPO 目标为 JGRPO(θ) = Jdisc + Jcurate − βDKL(πθ∥πref)。联合优化的关键在于两个信号通过技能库耦合：发现决定暴露哪些盲点，策展改变哪些盲点仍存在，形成相互促进的正反馈回路。

## 6. 主要结论与发现

1. **诊断是可学习的能力**：RL 训练的 4B Mentor 在所有执行器和两个指标上一致超过更大的提示型模型（如 DeepSeek-V4-Flash），说明诊断并非模型规模的副产品，而是可优化的目标。
2. **“学习”创造了平均 44.2% 的相对提升**：不同执行器的提升幅度为 36.7%~46.6%；较弱执行器从诊断中获益更大，与其暴露更大能力缺口一致。
3. **发现与策展必须联合优化**：单独去除任一奖励都会使准确率显著下降（从 0.351 降至 0.292 或 0.303）；共享参数优于分离策略。
4. **盲点是非静态的**：修复旧盲点会迁移能力边界、暴露新盲点；递减阈值调度跟踪了这一自然变化过程（最终准确率：递减 0.351 > 静态 0.348 > 递增 0.334）。
5. **技能具有跨执行器可移植性**：弱执行器训练出的技能迁移到强执行器时效果尤为突出（接近甚至超过后者的自训练结果）；全部迁移矩阵均高于无技能基线。
6. **对强模型的依赖既轻且稳**：最强与最弱 judge 的准确率差仅为 0.023，而 API 成本相差超 10 倍；Flash 级低端 API 即足以实现近最优诊断质量。

## 7. 优点

- **概念新颖性**：将“诊断”从执行中分离，并形式化为可学习的策略优化问题，视角独特且具备理论基础。
- **严格的隔离设置**：冻结执行器、排除人工标注，使性能改进来源可唯一归因于诊断能力，消除了混杂变量，保证了内部效度。
- **反馈回路建模**：发现-策展联合优化较好建模了盲点动态演化的真实场景，超越了单次“修补式”方法。
- **可解释性与可转移性**：技能以人类可读 Markdown 存储，可直接检查、编辑和复用；跨执行器迁移实验证明了其泛化潜力。
