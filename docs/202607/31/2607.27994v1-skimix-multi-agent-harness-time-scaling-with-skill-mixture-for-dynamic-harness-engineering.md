## 摘要
人工智能智能体日益依赖大型技能库，但选择、组合和维护技能仍然困难。我们提出SKIMIX，一种多智能体框架，其中拥有不同技能组合的智能体通过迭代细化进行协作。SKIMIX结合了基于嵌入的技能检索、子模抗稀释路由和自适应技能演化。在六个推理基准测试中，多智能体协作显著提升了开放式数学推理能力，但在多项选择任务上提升有限或产生负面效果。智能体数量扩展是非单调的，且大多数改进出现在第一轮细化中。这些结果表明，任务特征决定了技能级集成是否有帮助，并为可扩展智能体设计提供了实用指导。

## Abstract
AI agents increasingly rely on large skill libraries, but selecting, combining, and maintaining skills remains difficult. We propose SKIMIX, a multi-agent framework in which agents with different skill portfolios collaborate through iterative refinement. SKIMIX combines embedding-based skill retrieval, submodular anti-dilution routing, and adaptive skill evolution. Across six reasoning benchmarks, multi-agent collaboration substantially improves open-ended mathematical reasoning but offers limited or negative gains on multiple-choice tasks. Agent-count scaling is non-monotonic, and most improvements arise during the first refinement round. These results show that task characteristics determine whether skill-level ensembles help and provide practical guidance for scalable agent design.

## 1. 核心问题与研究动机

- **背景**：随着大语言模型（LLM）智能体的普及，现代智能体平台（如 Claude Code、AutoGen 等）配备了包含数十到数百个预置技能的大型技能库。技能可以是专用提示词、工具集成、推理策略或领域工作流。
- **核心痛点**：
  - **技能组合难题**：给定一个查询，没有人知道最佳技能组合是什么。查询极少显式"告知"需要哪些技能，而可能的技能组合空间太大，无法穷举搜索。当前系统要么使用单一固定流水线，要么依赖用户手动选择，导致大部分技能库未被利用。
  - **技能稀释问题**：随着技能库增长，冗余技能增加噪声、加大路由难度、拉低集成性能。现有系统没有同时处理"可扩展组合"与"抗稀释"的方案。
- **整体含义**：本文是首次系统性地研究"技能层面"的集成缩放（skill-level ensemble scaling）——区别于现有工作中关注模型多样性（如 MoA）或工具多样性（如 TUMIX）的做法——为可扩展智能体设计提供任务感知的实践指导。

## 2. 方法论：SKIMIX 框架

### 2.1 核心思想

- SKIMIX 并行运行多个智能体，每个智能体被分配**不同的技能组合**（skill portfolio，即技能库的一个精选子集及调用策略），并让它们跨轮次共享与细化答案。
- 与只关注模型/工具多样性的方法不同，SKIMIX 的切入点在于**技能组合的多样性**，因为技能更廉价、更易混合、与任务性能的关联更直接。

### 2.2 三大关键机制

1. **动态技能注册表（Dynamic Skill Registry, DSR）**
   - 构建一个可学习的嵌入空间，每个技能对应一个稠密向量，编码其能力画像、调用模式和成功统计。
   - 通过相似性路由（而非硬编码规则）完成技能检索；支持新技能注册（k-NN 索引）、查询检索（top-k 余弦相似度）和技能演化（对过期技能标记弃用或再生）。
   - 嵌入随时间通过使用反馈更新：`e_i^(t+1) = e_i^(t) + η · ∇_ei L_align(q, e_i, y)`。

2. **抗稀释路由（Anti-Dilution Routing, ADR）**
   - 将技能路由形式化为**子模最大化**问题：在给定查询 q 下选择大小不超过 k 的技能子集 P，最大化
     `F(P; q) = Σ_{s∈P} rel(s, q) + γ · log det(I + K_P)`
   - 其中第一项衡量技能与查询的相关性（嵌入相似度），第二项（log-determinant 项）鼓励技能间低相似度、高多样性，直接对抗稀释。
   - 贪心求解可达到 (1−1/e) 近似；边际增益低于阈值 τ_min 的技能被排除或归档。

3. **自适应技能演化（Adaptive Skill Evolution, ASE）**
   - 根据近期性能持续评分，过时技能被弃用；当使用模式暴露能力缺口时，从观测到的推理轨迹中综合生成新技能。

### 2.3 多轮细化流程（Refinement as Message Passing）

- 每一轮中，每个智能体同时参考原始查询和上一轮所有智能体的输出，独立生成新答案（即"共享与细化"）。
- 设定两个核心指标：**平均准确率**（average accuracy）和**覆盖率**（coverage，即至少一个智能体给出正确答案的概率）。
- 实验发现真实动态：覆盖率和准确率在 Round 1→Round 2 急剧上升，随后趋于平稳或略微下降——说明过度细化可能丢弃正确答案。

### 2.4 终止与答案聚合

- 停止规则：当预期边际收益 ∆r = E[A_{r+1} − A_r | signals] 不超过边际成本 λ 时停止；实际通过 **LLM-as-Judge** 决定终止，最少运行 2 轮。
- 答案聚合：终止后通过**多数投票（majority voting）**选出最终答案。

## 6. 主要结论与发现

- **任务形式决定多智能体的价值**：
  - 开放式数学推理（AIME、MATH-500）上，SKIMIX 大幅超越自细化：AIME 从 Self-Refine 的 40.0% 提升至 SKIMIX-3 的 73.3%（+33.3 个百分点，相对提升约 83%），SKIMIX-15 达 76.7%；MATH-500 上 SKIMIX-5 达到 72.0%（vs. 自细化 61.0%）。
  - 多项选择任务（GPQA）上，**单智能体自细化表现最佳**（88.0%），每增加一个智能体都会导致性能单调下降（SKIMIX-3=78.0%、SKIMIX-5=74.0%、SKIMIX-15=72.0%）。
  - 混合/一般基准（HLE、MMLU-Pro、BBH）介于两者之间，增益有限。
- **智能体数量缩放非单调**：AIME 上 3 个智能体（73.3%）超过 5 个（70.0%），15 个才恢复到 76.7%；"更多智能体 = 更好性能"的默认假设不成立。
- **第 2 轮是增益关键点**：几乎所有方法/基准上最大提升都发生在 Round 1→Round 2；Round 3 收益递减，甚至在多智能体配置下出现准确率下降（正确解在过度细化中被丢弃）。
- **覆盖率持续高于最终准确率**：例如 HLE 上 SKIMIX-15 第 2 轮覆盖率达 72.0%，但最终多数投票准确率仅 51.0%（21 个百分点缺口）——说明**答案聚合是当前瓶颈**，而非候选生成。
- **AIME 增益分解**：总 +73.3 个百分点中，多轮细化贡献 40.0（55%），多智能体多样性贡献 33.3（45%），两者均不可或缺；但在 GPQA 上多样性贡献为负（−10~−16 个百分点）。

## 8. 不足与局限

- **外部效度有限**：仅用单一模型（DeepSeek-V3.2）和单一推理提供商（SiliconFlow），结论在跨模型族、跨部署环境下的稳健性未知。
