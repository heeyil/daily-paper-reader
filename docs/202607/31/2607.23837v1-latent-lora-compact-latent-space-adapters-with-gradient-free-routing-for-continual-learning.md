## 摘要
大型语言模型在单个任务上泛化良好，但缺乏按顺序学习任务的固有机制，导致灾难性遗忘。为了缓解这一问题，基于LoRA的持续学习方法为每个任务分配单独的低秩适配器，但现有方法要么在推理时需要任务身份，要么不加区分地求和所有适配器，让无关分支扭曲输出。最近的基于门控的解决方案将输入路由到正确的适配器，但引入了本身需要防止遗忘的可训练参数。在这项工作中，我们观察到，来自冻结LLM嵌入层的池化令牌嵌入已经在整个学习序列中区分了任务分布。在这些嵌入上拟合的高斯混合模型，无需任何基于梯度的训练，就足以在测试时进行与任务无关的适配器选择。这消除了对学习门控模块的需求。在适配器方面，通过SVD将每个任务的参数约束到预训练权重的主子空间，产生紧凑的潜空间参数化。在此子空间内，正交正则化直接控制任务间干扰。由此产生的系统Latent-LoRA无需重放，不需要可训练的路由组件，并且每个任务使用的参数大大减少。在五个模型规模和两个已建立的持续学习基准上的实验表明，其性能达到最先进水平，且几乎零遗忘。

## Abstract
Large language models generalize well to individual tasks but lack an inherent mechanism for learning them sequentially, leading to catastrophic forgetting. To mitigate this, LoRA-based continual learning methods allocate a separate low-rank adapter per task, yet existing approaches either require task identity at inference or sum all adapters indiscriminately, letting irrelevant branches distort the output. Recent gating-based solutions route inputs to the correct adapter but introduce trainable parameters that themselves need protection against forgetting. In this work, we observe that pooled token embeddings from a frozen LLM embedding layer already separate task distributions throughout the learning sequence. A Gaussian mixture model fitted on these embeddings, without any gradient-based training, is sufficient for task-agnostic adapter selection at test time. This eliminates the need for a learned gating module. On the adapter side, constraining each task's parameters to the principal subspace of the pretrained weights via SVD yields a compact latent-space parameterization. Within this subspace, orthogonal regularization directly controls inter-task interference. The resulting system, Latent-LoRA, is replay-free, requires no trainable routing component, and uses substantially fewer parameters per task. Experiments across five model scales and two established continual learning benchmarks show state-of-the-art performance with near-zero forgetting.

  - 要么需要任务身份（任务无关场景下不可用）；
  - 要么将所有适配器**直接相加**，导致不相关任务的分支干扰输出，重新引入遗忘。
- 近期门控方法（如 GainLoRA）引入可训练的门控模块来路由输入到正确适配器，但：
  - 门控参数随任务数量线性增长；
  - 门控本身会受遗忘影响，需要额外机制（如梯度投影记忆 GPM）来保护，形成“第二重持续学习问题”。
- 本文的核心视角：**冻结 LLM 嵌入层产生的池化 token 嵌入已经能够较好地区分不同任务分布**，因此可以用一个无梯度训练的简单概率模型（高斯混合模型）完成任务路由，从而消除可训练门控模块；同时采用基于 SVD 的紧凑适配器，显著降低每任务参数，并引入直接针对干扰的正交正则化。

## 2. 方法论
### 2.1 紧凑潜空间适配器
- 对预训练权重 \( W \in \mathbb{R}^{m \times n} \) 做秩为 \( r \) 的截断 SVD：\( W \approx U_r \Sigma_r V_r^\top \)，其中 \( U_r, V_r \) 固定且正交，\( \Sigma_r \) 为奇异值对角矩阵。
- 每个任务只训练一个小矩阵 \( R_t \in \mathbb{R}^{r \times r} \)，权重更新为：
  \[
  \Delta W_t = U_r \Sigma_r R_t V_r^\top
  \]
- 每任务可训练参数从标准 LoRA 的 \( r(m+n) \) 降至 \( r^2 \)，参数效率随模型维度增大而显著提升。
- 适配器训练后冻结为**独立快照**，后续任务无法修改。

### 2.2 干扰分析与正交正则化
- 两个任务适配器在层输出上的干扰可分解为：
  \[
  \delta_i(h)^\top \delta_j(h) = \psi(h)^\top (\Sigma_r R_i)^\top (\Sigma_r R_j) \psi(h)
  \]
  其中 \( \psi(h) = V_r^\top h \)，\( \tilde{R}_t = \Sigma_r R_t \)。
- 干扰完全由 \( \tilde{R}_i^\top \tilde{R}_j \) 决定，因此直接对该项施加正交惩罚：
  \[
  \mathcal{L}_{\text{ortho}} = \sum_{i<j} \| \tilde{R}_i^\top \tilde{R}_j \|_F^2
  \]
- 完整损失为任务语言建模损失 + \( \lambda \cdot \mathcal{L}_{\text{ortho}} \)。文中给出了干扰上界证明（Proposition 1），说明该正则化可对所有输入统一抑制干扰，而标准 LoRA 的类似正则化不完备（无法约束 up-projection 的乘积项）。

### 2.3 无梯度任务路由器
- 对输入 \( x \)，用冻结嵌入层提取固定表示：
  \[
  \phi(x) = \text{MeanPool}(\text{Emb}(x))
  \]
- 每个任务训练完成后，对其训练数据的 \( \phi(x) \) 拟合一个 \( K \) 个分量的高斯混合模型（GMM）：
  \[
  p(\phi(x) | t) = \sum_{k=1}^K \pi_{t,k} \mathcal{N}(\phi(x); \mu_{t,k}, C)
  \]
- 协方差 \( C \) 为所有任务共享的池化散度矩阵（正则化后），无需存储旧数据即可增量更新。
- 推理时计算任务后验 \( p(t|x) \)，以软路由方式混合所有适配器：
  \[
  R(x) = \sum_{t=1}^T p(t|x) R_t
  \]
- 路由器**无可训练参数**，不会受后续训练的影响，也不需要额外的保护机制；每次新增任务只需拟合新任务的 GMM 均值和权重并更新共享协方差。

## 7. 优点
- **消除可训练门控**：路由完全不依赖梯度，从根本上避免“门控自身遗忘”的问题，无需 GPM 等额外保护。
- **参数极高效率**：每任务仅需 r² 参数，与模型维度无关，在 13B 模型上比标准 LoRA 减少 80 倍。
- **清晰的干扰理论**：干扰分解公式与正交正则的目标完全一致，有上界保证，优于标准 LoRA 中仅约束一侧的不完整正则。
- **实现简单、增量友好**：GMM 拟合仅需 K-means 和共享协方差更新，CPU 即可完成，不占用 GPU 训练资源。
- **实验较全面**：跨编码器-解码器与解码器架构、五种规模、两种基准、多种顺序，且重复随机种子，结果较可靠。

## 8. 不足与局限
- **共享协方差矩阵求逆成本较高**：\( C \in \mathbb{R}^{d \times d} \)，每次新增任务需 \( O(d^3) \) 求逆；对于大嵌入维度（如 Llama-2-13B 的 d=5120）虽然用 Cholesky 可行，但未来更大模型可能成为瓶颈。
- **路由依赖嵌入可分性假设**：若两个任务输入分布高度重叠（如同领域两个情感任务），GMM 路由可能无法可靠区分；软路由提供一定容忍度，但路由精度的上限受冻结嵌入的可分性限制。
- **未在超过 13B 的模型上验证**：更强更大模型的嵌入可分性与紧凑适配器容量是否保持仍是开放问题。
- **参数比较的轻微不对等**：基线 rank=8 而本文 rank=32，尽管参数总数减少，但 rank 的选择可能影响不同任务上的表达能力，论文未详细分析 rank 敏感性。
- **缺少与真实学习门控的推理开销定量对比**：论文仅定性说明 GMM 路由比 MLP 门控更便宜，未提供端到端延迟数据。
