## 摘要
AI智能体在每次运行中都会遇到学习机会，但几乎全部丢弃：底层模型在部署时被冻结，因此今天解决困难请求的智能体明天重复出现时又从零开始。然而，常规操作已经以结果判定和事后修正的形式产生反馈。我们证明，当冻结模型与外部记忆配对，将每次运行提炼为可检索的自然语言规则时，这种反馈是持续学习的充分信号。在τ-bench的银行领域上，相比检索完整政策语料库的静态RAG控制，从单比特结果判定中学习将单次成功率提升至基线的1.6倍，从修正中学习提升至2.6倍，将基线从未解决的84个任务中的22个转化成功。该结果适用于部署全谱，在Mistral Large（一种具有数据主权要求的组织可自托管的开放权重模型）上测量，并在前沿模型Claude Sonnet 5上复现。累积的记忆也可迁移：每个模型读取由另一个模型构建的存储，性能超过其自身无记忆基线。我们发布了相关的框架、协议和数据。

## Abstract
AI agents encounter learning opportunities in every episode they run, and discard nearly all of them: the underlying models are frozen at deployment, so an agent that resolves a difficult request today starts from zero when it recurs tomorrow. Yet ordinary operation already produces feedback, in the form of outcome verdicts and after-the-fact corrections. We show that this feedback is a sufficient signal for continual learning when the frozen model is paired with an external memory that distils each episode into retrievable natural-language rules. On the banking domain of $τ$-bench, against a static-RAG control retrieving over the complete policy corpus, learning from the one-bit outcome verdict lifts single-trial success to 1.6$\times$ the baseline, and learning from corrections to 2.6$\times$, converting 22 of the 84 tasks the baseline never solves. The result spans the deployment spectrum, measured on Mistral Large, an open-weights model that organisations with data sovereignty requirements can self-host, and replicated on a frontier model, Claude Sonnet 5. The accumulated memory also transfers: each model, reading the store built by the other, rises above its own no-memory baseline. The harness, protocol, and data are released.

## 1. 论文的核心问题与整体含义（研究动机和背景）

当前AI智能体在部署后模型权重被冻结，无法从每次运行中学习。即便解决了困难任务，当相同请求再次出现时仍需从零开始。然而，日常运行中本已存在丰富的反馈信号（如结果是否成功、人工修正等），但现有系统几乎完全丢弃了这些学习机会。论文的核心动机是：能否仅利用这些自然产生的反馈信号，在不更新模型权重的前提下，让冻结智能体实现持续学习？这能降低模型更新带来的训练成本、灾难性遗忘风险和安全评估负担，对具有数据主权要求、需要自托管模型的组织尤为重要。

## 2. 论文提出的方法论

### 核心思想
- 为冻结权重模型附加一个**外部记忆系统（Spark）**，将每个episode（交互回合）的反馈提炼为可检索的自然语言规则（insight），存储后可在后续相关episode中被检索和重用。
- 学习过程**不涉及任何权重更新**，属于梯度自由的持续学习范式。
- 利用两种反馈信号：
  - **经验（Experience）**：仅使用单比特结果（成功/失败）让智能体自行生成教训。
  - **指令（Instruction）**：失败episode额外提供事后修正（正确的动作序列）。

### 关键技术细节
- **记忆单元（Insight）**：每个记忆存储标题、内容、检索查询（以未来智能体可能提出的问题形式），以及可选的标签。
- **智能体接口**：提供四个工具调用：`memory_search`、`memory_create`、`memory_enrich`、`memory_feedback`，形成“读取-贡献-反馈”循环。
- **知识生命周期**：异步后台管道进行安全过滤、质量门控、去重、冲突协调、推导新见解等，无需人工干预。
- **写入路径**：所有写入发生在episode结束后（专门的反思回合），避免中途被错误猜测污染。反思步骤会根据反馈信号生成特定形式的规则（成功时记录“已验证规则”，失败时在经验模式下仅记录“避免...”，指令模式下记录正确的“WHEN-THEN”规则）。
- **读取路径**：完全由智能体主动调用`memory_search`，系统不会自动注入。提供一次性提示指导何时搜索。
- **去重与合并**：支持将相似但不同正确动作的场景合并为分支规则。

## 3. 实验设计

### 数据集/场景
- **τ-bench 银行领域**：一个多轮对话基准，包含97个任务，每个任务为智能体与模拟客户（由单独LLM扮演）之间的交互。智能体拥有领域工具（读写数据库），最终数据库状态与预计算真值比较作为判定标准（确定性评估，除一个任务外完全确定）。
- 智能体**没有预先获得业务规则**，必须通过检索约700个互连政策文档的语料库（使用稀疏BM25检索）来发现规则和可用工具。这模拟了组织拥有专属知识的实际场景。

### 基准方法
- **静态RAG基线**：标准τ-bench智能体，使用BM25检索完整政策语料库，但不保留跨试验的记忆。

### 对比条件
1. **无记忆基线**：静态RAG。
2. **经验（Experience）**：学习单比特结果判断。
3. **指令（Instruction）**：学习结果判断+事后修正。

每个条件运行每项任务4次试验（共97×4=388次模拟对话）。记忆条件中，存储从空开始并跨试验保留。

### 第二项实验：跨模型迁移
- 将指令条件下Mistral Large和Claude Sonnet 5分别构建的记忆存储冻结，然后让对方模型只读地读取（无写入），测量其性能相对于各自无记忆基线的提升。

### 使用的模型
- **智能体模型**：Mistral Large（开放权重，可自托管）和Claude Sonnet 5（前沿模型，中等推理努力）。模拟客户使用GPT-5.2。

## 6. 论文的主要结论与发现

1. **事后反馈是足够的持续学习信号**：
   - Mistral Large上，单比特经验反馈使pass^1（单次成功率）提升至基线的1.6倍（从0.064到0.103）；指令反馈提升至2.6倍（0.170）。配对对比均有统计学显著。
   - 经验模式下保留率为0.88，指令模式下为0.65（指令因合并冲突保留率较低但仍高于随机重绘）。
   - 解决了基线从未成功的84个任务中的22个（指令模式）。

2. **结果在更强模型上复现**：
   - Claude Sonnet 5的基线pass^1为0.248（典型前沿水平），指令提升至0.397，提升幅度（+0.149）甚至大于Mistral的绝对提升。

3. **累积记忆可跨模型迁移**：
   - Mistral读取Sonnet构建的存储，pass^1从0.064升至0.289（+0.224）；Sonnet读取Mistral存储，从0.248升至0.314（+0.066）。
   - 在“可迁移任务”子集（消费者本身无法解决但生产者解决过的）上，两个方向的转换率均约31%，表明记忆包含通用任务知识而非风格依赖。

4. **学习曲线**：记忆条件从第一次试验（与基线无差异）开始逐步上升，基线保持平坦，证明效果来自记忆累积而非重绘噪声。

5. **pass^4的局限性**：由于pass^4要求全部四轮都成功，而记忆条件下许多任务在首次失败后才成功（如0111模式），导致pass^4与基线无法区分。作者指出应使用保留率衡量一致性，并释放了包含逐次曲线和保留率的测量协议。

## 7. 优点

- **方案简洁实用**：无需模型权重更新，利用现有反馈，适合企业部署。
- **记忆可迁移**：不同模型间的知识共享验证了记忆的通用性，且迁移效果不弱。
- **实验设计严谨**：配对对比、集群自助法、逐任务网格报告、冷启动基线对齐。
- **开源释出**：发布了完整代码、数据和测量协议，便于复现。

- **覆盖两类模型**：开放权重和前沿闭源，增强结论通用性。
