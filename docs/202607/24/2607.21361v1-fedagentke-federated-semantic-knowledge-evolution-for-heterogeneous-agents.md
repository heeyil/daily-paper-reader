## 摘要
基于大语言模型的智能体越来越依赖推理、工具使用和迭代执行，然而现有的智能体框架在很大程度上仍孤立运行。虽然近期基于记忆的智能体系统通过本地检索和工作流重用来改进单个智能体，但本地经验在孤立的智能体框架间仍是碎片化的，限制了跨框架知识迁移和协作推理演化。我们提出了FedAgentKE，一个用于异构智能体间联邦语义知识演化的轻量级框架。FedAgentKE使分布式智能体框架能够通过迭代的语义知识蒸馏、聚合和适配，协同演化可迁移的推理抽象，而无需共享原始推理轨迹。实验表明，在跨框架和跨任务场景下均取得了一致改进，凸显了联邦语义知识演化对未来协作智能体生态系统的潜力。

## Abstract
Large language model (LLM)-based agents increasingly rely on reasoning, tool use, and iterative execution, yet existing agent frameworks still operate largely in isolation. While recent memory-based agent systems improve individual agents through local retrieval and workflow reuse, local experiences remain fragmented across isolated agent frameworks, limiting cross-framework knowledge transfer and collaborative reasoning evolution. We propose FedAgentKE, a lightweight framework for Federated Semantic Knowledge Evolution across heterogeneous agents. FedAgentKE enables distributed agent frameworks to collaboratively evolve transferable reasoning abstractions through iterative semantic knowledge distillation, aggregation, and adaptation without sharing raw reasoning trajectories. Experiments demonstrate consistent improvements under both cross-framework and cross-task settings, highlighting the potential of federated semantic knowledge evolution for future collaborative agent ecosystems.

## 2. 方法论：核心思想、关键技术细节与算法流程

### 核心思想
- FedAgentKE 在语义层面（而非参数层面）同步知识，允许异构智能体框架（推理协议、工具环境、执行流程不同）通过蒸馏本地经验为可迁移的语义知识单元，经由联邦知识池聚合后分发适应。

### 关键技术细节
1. **本地知识蒸馏**  
   - 每个智能体客户端 \(C_i\) 收集执行轨迹 \(\tau_{i,j} = (x_{i,j}, a_{1:T_{i,j}}, o_{1:T_{i,j}}, y_{i,j})\)，包含任务输入、动作-观察序列、最终结果。
   - 通过 LLM 驱动的语义蒸馏算子 \(D_i(\cdot)\)，将轨迹转换为语义知识单元 \(z_{i,j} = (\pi_{i,j}, \rho_{i,j}, e_{i,j}, c_{i,j}, u_{i,j})\)，分别表示抽象任务描述、可复用推理工作流、执行修正或失败模式、框架元数据、效用评分。
2. **联邦语义聚合**  
   - 服务器收集所有客户端上传的知识单元 \(U^{(t)} = \bigcup_{i=1}^N K_i^{(t)}\)。
   - 对每个知识单元进行语义嵌入 \(h_z = \phi(z)\)，通过跨任务语义聚类分组 \(\{G_1, \dots, G_M\}\)。
   - 在每个聚类中选择代表性知识单元：\(\bar{z}_m = \arg\max_{z \in G_m} [\lambda_1 u(z) + \lambda_2 q(z)]\)，其中 \(u(z)\) 是效用，\(q(z)\) 是跨智能体/任务的可迁移性。
   - 通过语义去重和效用更新机制整合进入全局知识池 \(K_g^{(t+1)}\)。
3. **知识适应**  
   - 客户端根据本地任务 \(x_i\) 检索 top-k 相关联邦知识 \(\hat{K}_i = \text{TopK}_{z \in K_g} \text{sim}(\psi(x_i), \phi(z))\)。
   - 进行知识适应 \(\tilde{K}_i = \mathcal{T}_i(\hat{K}_i, c_i)\)，将外部知识映射为本地可执行的推理指导。
   - 最终优化本地推理工作流 \(\rho'_i = \mathcal{R}_i(\rho_i, \tilde{K}_i)\)。

### 算法流程（文字说明）
1. 服务器初始化全局知识池 \(K_g^{(0)}\)。
2. 每一通信轮次 \(t\)：
   - 服务器分发当前知识池。
   - 每个客户端并行：检索适应知识 → 执行本地任务并收集轨迹 → 蒸馏为知识单元 → 上传。
   - 服务器聚集知识 → 语义聚类 → 选择代表 → 更新知识池。
3. 返回最终联邦知识池。

## 6. 主要结论与发现

1. **Intra-framework 改进**：在同一框架内，FedAgentKE 在 SWE-bench Lite 上使 SWE-agent 从 27.00 提升至 42.67（+15.67），OpenHands 从 29.33 提升至 44.67（+15.34）；在 GAIA 上 OWL 平均提升 19.39 分，SmolAgents 提升 13.34 分。
2. **Cross-framework 可扩展性**：异构客户端数量从 2 增加到 8 时，GAIA 平均成功率从 49.0% 提升至 54.4%，表明更大联邦规模提供更丰富的协作知识。
3. **迭代演化效果**：在 SmolAgents 上，成功率和从 R=1 的 44.24% 持续提升至 R=5 的 74.55%，验证了多轮同步逐步增强推理能力。
4. **语义级同步有效性**：无需共享原始执行轨迹即可实现知识迁移，支持隐私保护和异构适应性。
