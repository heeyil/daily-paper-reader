## 摘要
大语言模型（LLM）在多个领域表现出色，但为每个查询使用最强大的模型在规模上是不可行的。LLM路由利用模型能力和成本的多样性，为每个查询分配一个合适的模型，以平衡效用和预算。当前方法有两个局限性：(i) 要么使用启发式方法，不能始终强制预算约束，要么施加固定的每查询预算，无法适应工作负载并导致次优性能；(ii) 需要在密集数据集上进行监督学习，其中包含每个查询-模型对的统计信息，收集成本高昂。为解决这些挑战，我们将LLM路由形式化为一个带约束的上下文多臂老虎机问题，并提出WISERouter（简称WR），这是一个支持从历史交互中进行离线学习以及通过探索进行在线学习的框架。我们进一步证明，WR-Online在时间范围T上实现了O(√T)的次线性遗憾界。在RouterBench和SWE-Bench上的实验结果表明：(i) WR-Offline在固定预算下性能优于现有基线，并且更严格地遵守预算约束；(ii) WR-Online在与基线相当的性能下，使用的探索数据显著减少。

## Abstract
Large language models (LLMs) achieve impressive performance across multiple domains, but using the most capable model for every query is prohibitive at scale. LLM routing exploits diversity in model capability and cost by assigning each query to a suitable model to balance utility and budget. Current methods have two limitations: (i) they either use heuristics that do not always enforce the budget constraint or impose a fixed per-query budget that cannot adapt across the workload and leads to suboptimal performance; (ii) they require supervised learning on a dense dataset with statistics for every query-model pair, which is expensive to collect. To address these challenges, we formulate LLM routing as a constrained contextual multi-armed bandit problem and introduce WISERouter (WR for short), a framework that supports offline learning from historical interactions as well as online learning with exploration. We further prove that WR-Online achieves a sublinear regret bound of $O(\sqrt{T})$ over a time horizon $T$. Empirical results on RouterBench and SWE-Bench demonstrate that (i) WR-Offline surpasses existing baselines in performance under a fixed budget and adheres more closely to budget constraints, and (ii) WR-Online achieves comparable performance to the baselines, while using substantially less exploration data.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题背景**：大语言模型（LLM）推理成本高昂，尤其在高吞吐量工作负载下。不同LLM在能力与成本上存在显著差异，因此通过路由策略为每个查询选择合适的模型，可在保持性能的同时降低成本。
- **现有方法局限**：
  - 无法有效施加工作负载级别的预算约束（多数方法仅约束每查询预算或采用启发式）。
  - 需要收集每个查询-模型对的输出与评分（密集监督），成本极高，难以扩展。
- **本文目标**：设计一种能直接优化全局预算约束、且能从稀疏交互中学习的高效路由框架。

## 2. 方法论：核心思想、关键技术细节

- **核心思想**：将LLM路由形式化为“约束上下文多臂老虎机”（Constrained Contextual Bandit, CCB）。
  - 上下文：查询嵌入（经聚类离散化为有限个上下文类）。
  - 动作：选择某个LLM。
  - 奖励：响应质量（如准确率、人类偏好）。
  - 成本：模型调用费用（归一化）。
  - 目标：在期望总成本不超过给定预算B的前提下，最大化期望累计奖励。
- **关键组件**：
  1. **上下文离散化**：使用预训练编码器（如OpenAI text-embedding-3-small）生成查询嵌入，经K-means聚类为J个簇，每个簇视为一个离散上下文，并估计上下文分布πj。
  2. **自适应线性规划（ALP）**：每一轮t，按剩余预算b和剩余轮次τ求解一个小型线性规划（LP），得到当前上下文的动作选择概率，从而自适应地将全局预算动态分配至各轮。
  3. **WR-Offline**（数据丰富场景）：
     - 利用历史数据集Dhist估计每个上下文-动作对的平均奖励ûj,k和成本ĉj,k。
     - 部署时每轮求解ALP并采样动作。
     - 无需重训练即可适应不同预算设置（仅需调整LP中的b/τ）。
  4. **WR-Online**（数据稀缺场景）：
     - 在统一工作负载预算下，先进行ε步探索（ϵ-first策略），每个上下文-动作对至少被访问⌊ε/K⌋次，在线更新平均奖励和成本估计。
     - 剩余步数转入利用阶段，使用估计的统计量运行ALP。
- **理论保证**：
  - 证明WR-Online的端到端遗憾界：非边界预算情况为O(log T)，边界情况为O(√T)。
  - 推导了充分探索条件（依赖最小成本差Δ_c_min、最小比率分离Δ_ξ_min等）。
  - 给出了置信度检验（CLT）作为理论上可停止探索的判据，但实际因保守性而采用固定探索长度。

## 7. 优点

- **问题建模新颖**：首次将工作负载级预算约束引入LLM路由，形式化为CCB，具有理论支撑。
- **双模式覆盖**：支持离线数据丰富场景（WR-Offline）和在线数据稀缺场景（WR-Online），实用性强。
- **无需重训练适应新预算**：WR-Offline只需在推理时调整LP参数，训练成本极低。
- **理论保证全面**：证明了WR-Online的端到端遗憾界（覆盖探索和利用阶段），这是该领域首次。

- **实用高效**：上下文离散化与轻量LP求解使推理延迟极低，适合生产部署。
