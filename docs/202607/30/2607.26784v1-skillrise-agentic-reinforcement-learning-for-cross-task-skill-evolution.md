## 摘要
大型语言模型智能体常常遇到相关但不同的任务，这些任务共享可重用的解决方案模式。然而，标准的自主强化学习将任务视为独立的情节，而现有的技能学习方法要么专注于重复尝试同一任务，要么使用多阶段流水线，将提取、检索和执行纠缠在一起。我们提出了SkillRise，一个统一的强化学习框架，用于跨任务学习技能。SkillRise将相关实例组织成逐步具有挑战性的序列，并使用单一策略在任务解决和整理不断演化的技能文档（直接传递给下一个任务）之间交替。跨任务的解耦信用分配使用当前任务结果监督解决，并使用折扣后的下游结果监督整理。在ALFWorld、WebShop和ScienceWorld上的实验表明，SkillRise在比较的方法中取得了最强的Pass@1性能，相比最强基线提升了2.3到8.5个百分点。尽管在不同任务上训练，其学到的整理策略在重复尝试同一任务时仍然有效。进一步分析揭示了跨任务的测试时缩放：即使每个任务只尝试一次，随着相关任务序列变长，性能也会提升。这一趋势表明SkillRise重复使用跨任务的可迁移技能，而不是从同一任务的重复采样中受益。SkillRife在显著降低多阶段技能学习流水线运行时开销的同时，仍保持了强劲的性能。这些结果共同为LLM智能体提供了一种简单高效的训练范式，用于跨任务提取、精炼和重用可迁移技能。

## Abstract
Large language model agents often encounter related yet distinct tasks that share reusable solution patterns. Yet standard agentic reinforcement learning treats tasks as independent episodes, while existing approaches to skill learning either focus on repeated attempts of one task or use pipelines with multiple stages that entangle extraction, retrieval, and execution. We introduce SkillRise, a unified reinforcement learning framework for learning skills across tasks. SkillRise organizes related instances into progressively challenging sequences and uses a single policy to alternate between task solving and curating an evolving skill document passed directly to the next task. Decoupled credit assignment across tasks supervises solving with the current task outcome and curation with discounted downstream outcomes. Experiments on ALFWorld, WebShop, and ScienceWorld show that SkillRise achieves the strongest Pass@1 performance among the compared methods, with gains over the strongest baseline ranging from 2.3 to 8.5 percentage points. Although trained across distinct tasks, its learned curation policy remains effective for repeated attempts on the same task. Further analysis reveals scaling at test time across tasks: performance improves with longer sequences of related tasks even when each task is attempted only once. This trend suggests that SkillRise reuses transferable skills across tasks rather than benefiting from repeated sampling of the same task. SkillRise further retains strong performance while substantially reducing the runtime overhead of skill learning pipelines with multiple stages. Together, these results provide a simple and efficient training paradigm for LLM agents to extract, refine, and reuse transferable skills across tasks.

## 1. 核心问题与整体含义（研究动机和背景）

大型语言模型（LLM）智能体在实际部署中常遇到一系列相关但不同的任务（如 ALFWorld 中不同物体的拾取、清洁等），这些任务共享可重用的解决模式。然而，现有的自主强化学习（Agentic RL）方法通常将每个任务视为独立的情节，丢弃交互过程中积累的经验，导致智能体从零开始重复探索。另一方面，已有的技能学习方法存在两个主要局限：一是集中于同一任务的重复尝试（如 Reflexion），所学知识局限于单一实例；二是采用多阶段流水线（如技能提取、存储、检索、执行），各环节耦合导致难以归因失败原因，且引入额外运行时开销。因此，需要一个简单、端到端的跨任务技能学习框架。

## 2. 方法论

### 核心思想
SkillRise 将相关任务实例组织成渐进难度的序列，使用单一策略交替进行任务求解和技能文档整理。技能文档作为跨任务的唯一信息通道，随任务进行不断演化。策略通过强化学习联合优化求解和整理行为，采用解耦信用分配：当前任务求解由当前任务奖励监督，技能整理由后续任务的折扣奖励监督。

### 关键技术细节
- **跨任务序列构建**：从同一任务族（task family）中选择不同实例，按难度（如属性数量、选项数）排序，形成长度为 K 的序列。
- **跨任务展开**：每次试验从空文档 S₀ = ∅ 开始。对于第 i 个任务，策略基于当前文档 S_{i-1} 生成求解轨迹 τ_i，获得奖励 r_i。接着（除最后一个任务外），策略基于 S_{i-1}、τ_i 和 r_i 整理出新文档 S_i，用于下一个任务。
- **解耦信用分配**：对于求解阶段，回报 G = r_i（当前任务奖励）；对于整理阶段，回报 G = Σ_{j=i+1}^{K} γ^{j-i} r_j，γ ∈ [0,1] 是跨任务折扣因子。
- **角色感知组相对优化**：在同一序列、同一任务位置、同一阶段内，对 N 个独立试验计算组相对优势 A = G - 平均值。采用 PPO 的裁剪目标函数优化，将阶段级优势应用于对应阶段的所有生成 token。
- **共享策略**：求解和整理使用同一策略模型（仅角色指令不同），实现端到端训练。

### 公式/算法流程（文字说明）
- 序列 x = (x₁,...,x_K) 来自分布 G。
- 初始化 S₀ = ∅。
- 对于 i = 1..K：
  - τ_i ~ πθ(·|x_i, S_{i-1})；r_i = R(τ_i)
  - 若 i < K：S_i ~ πθ(·|S_{i-1}, τ_i, r_i)
- 对于每个阶段（solve 或 curate），计算：
  - G_{i,z}(n) (n=1..N)
  - 组内平均 Ĝ_{i,z}，优势 A_{i,z}(n) = G_{i,z}(n) - Ĝ_{i,z}
- 优化目标：对每个 token 使用裁剪的 PPO 目标。

## 3. 实验设计

### 数据集/场景

- **ScienceWorld**：128 个保留实例。

### Benchmark

### 对比方法

- 额外对比：RetroAgent、SkillRL（多阶段技能学习流水线）

## 6. 主要结论与发现

- **主结果**：SkillRise 在三个基准上均取得最佳 Pass@1 性能，ALFWorld 85.9%、WebShop 84.4%、ScienceWorld 54.6%，比最强基线 GiGPO 分别提升 2.3、7.1、8.5 个百分点。
- **跨任务测试时缩放**：随测试时相关任务序列长度 K 增加，SkillRise 性能单调提升（83.6% → 87.5%），而其他方法无此趋势，表明技能文档逐步精炼带来累积收益。
- **模型大小泛化**：1.7B 和 4B 下均表现最佳，且 4B 相比 1.7B 提升幅度更大（+7.8pp），说明更大容量有利于跨任务抽象。
- **效率优势**：在多阶段流水线对比中，SkillRise 性能与 RetroAgent 相当（85.9%），优于 SkillRL（+12.5pp），而运行时间仅为 RetroAgent 的 1/6、SkillRL 的 1/4.3。
- **解耦信用分配鲁棒**：γ 在 0.3–0.7 范围内性能变化小于 1pp。
- **技能整理关键性**：移除整理后性能下降约 3pp，显示显式演化文档的必要性。

## 7. 优点

- **端到端简洁性**：无需外部教师、检索模块或单独的记忆维护，单策略统一求解与整理。
- **解耦信用分配**：根据行为的时间角色（当前 vs 未来）赋予不同监督信号，避免信号混淆。
- **跨任务转移能力强**：从不同任务中学习如何提取可迁移技能，而非记忆实例特定知识。
- **测试时缩放**：首次证明随相关任务序列长度增加性能提升，暗示可在线持续改进。
- **鲁棒性**：对折扣因子不敏感，易于部署。
- **通用性**：在文本交互环境下（家务、购物、科学推理）均有效。

## 8. 不足与局限

- **任务族元数据依赖**：当前假设可获取任务族信息来构建序列；在开放任务流中自动发现任务关系是未来方向。
- **模型规模受限**：实验仅限 4B 参数模型，更大模型（如 70B）上的效果未验证。
- **任务类型有限**：仅三个文本基准；多模态、真实世界及不易验证奖励的任务未覆盖。
- **并非绝对最优**：ScienceWorld 上成功率仅 54.6%，仍有较大提升空间。
- **纵向比较不足**：与其他技能学习方法（如 Retrogent、SkillRL）的对比仅在 ALFWorld 上进行，缺少跨基准的全面比较。
