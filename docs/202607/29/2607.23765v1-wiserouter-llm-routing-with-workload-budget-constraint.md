## 摘要
大型语言模型（LLM）在多个领域取得了令人印象深刻的性能，但为每个查询都使用最强大的模型在规模上是不可行的。LLM路由通过将每个查询分配给合适的模型来平衡效用和预算，从而利用模型能力和成本的多样性。当前方法存在两个局限性：（i）它们要么使用启发式方法，不总能强制预算约束，要么施加固定的每次查询预算，无法适应工作负载并导致次优性能；（ii）它们需要在包含每个查询-模型对统计数据的密集数据集上进行监督学习，而收集这些数据成本高昂。为解决这些挑战，我们将LLM路由形式化为一个受约束的上下文多臂老虎机问题，并引入WISERouter（简称WR），一个支持从历史交互中进行离线学习以及通过探索进行在线学习的框架。我们进一步证明，WR-Online在时间范围T上实现了次线性遗憾界O(√T)。在RouterBench和SWE-Bench上的实验结果表明：（i）WR-Offline在固定预算下的性能超越了现有基线，并且更严格地遵守预算约束；（ii）WR-Online在使用的探索数据显著减少的情况下，达到了与基线相当的性能。

## Abstract
Large language models (LLMs) achieve impressive performance across multiple domains, but using the most capable model for every query is prohibitive at scale. LLM routing exploits diversity in model capability and cost by assigning each query to a suitable model to balance utility and budget. Current methods have two limitations: (i) they either use heuristics that do not always enforce the budget constraint or impose a fixed per-query budget that cannot adapt across the workload and leads to suboptimal performance; (ii) they require supervised learning on a dense dataset with statistics for every query-model pair, which is expensive to collect. To address these challenges, we formulate LLM routing as a constrained contextual multi-armed bandit problem and introduce WISERouter (WR for short), a framework that supports offline learning from historical interactions as well as online learning with exploration. We further prove that WR-Online achieves a sublinear regret bound of $O(\sqrt{T})$ over a time horizon $T$. Empirical results on RouterBench and SWE-Bench demonstrate that (i) WR-Offline surpasses existing baselines in performance under a fixed budget and adheres more closely to budget constraints, and (ii) WR-Online achieves comparable performance to the baselines, while using substantially less exploration data.

## 1. 核心问题与整体含义（研究动机和背景）
- **背景**：使用最强大的LLM处理每一个查询在大规模场景下成本过高，因此需要推理时模型选择技术（如路由和级联）来在性能与成本之间取得平衡。
- **现有方法的根本局限**：
  1. **预算约束不合理**：大多数方法要么没有硬性预算约束，要么只施加**每查询固定预算**，无法全局优化。工作负载级预算（如月度API配额）更符合实际，但现有算法不能动态分配预算。
  2. **训练数据昂贵**：传统路由方法需要为每个查询收集所有候选模型的输出和质量分数（密集监督），收集成本随模型数量和查询量线性增长，且难以在新场景中复用。
- **论文核心意义**：首次将LLM路由问题形式化为**约束上下文多臂老虎机（CCB）**，并提出WISERouter框架，**同时解决全局预算约束和稀疏反馈学习两大挑战**，且提供了理论遗憾保证。

## 2. 提出的方法论
### 核心思想
- 将每个查询的嵌入向量作为上下文，候选LLM作为动作，路由后观测到的质量分数作为奖励、成本作为约束。目标是最大化累积期望奖励，同时满足全局期望成本预算。
- 通过**上下文离散化**：使用预训练嵌入器（如OpenAI text-embedding-3-small）将查询映射到向量，再通过K-means聚类得到有限个离散上下文（J=16），并估计每个上下文的分布π_j。
- 提出两种模式：
  - **WR-Offline**（数据丰富场景）：从历史数据中离线估计每个上下文-动作对的平均奖励Û_j,k和平均成本Ĉ_j,k，然后在线路由时**每个时间步求解自适应线性规划（ALP）**，将剩余预算b和剩余时间τ转化为每轮平均约束b/τ，从而动态调整资源分配，无需重新训练。
  - **WR-Online**（数据稀缺场景）：采用**ε-first探索策略**，先在预算内均匀探索每个上下文-动作对，更新在线均值ȗ_j,k和ċ_j,k，之后进入利用阶段（与WR-Offline相同的ALP过程）。**探索和利用共享同一个工作负载级预算**。

### 关键技术细节
- **ALP (Adaptive Linear Programming)**：在每个路由步骤，根据当前剩余预算b和剩余时间τ求解线性规划，输出一个概率策略p_{j,k}(b/τ)，按概率采样动作。该规划无需重新训练，可适应任意预算水平。
- **保障正确排序的探索长度**：定理5.2给出充分条件，保证探索后估计的奖励-成本比（ξ）排序与真实排序一致，从而利用阶段的ALP性能与已知统计量时的ALP接近。
- **遗憾界**：WR-Online在非边界情况下遗憾为O(log T)，在边界情况下为O(√T)（定理5.3），这是首个覆盖探索和利用全过程的LLM路由遗憾界。

### 算法流程
- **WR-Offline**（算法1）：初始化剩余预算b=B，剩余时间τ=T；每步分配上下文j→解LP→采样动作→更新b和τ。
- **WR-Online**（算法2）：前ε(T)步进行最小访问次数探索；后(1-ε)T步使用估计统计量重复ALP路由。

## 6. 主要结论与发现
1. **WR-Offline性能领先**：在SWE-Bench最紧预算下平均质量比最佳基线提升14%；在所有预算水平上性能匹配或超越基线。

4. **WR-Online数据高效**：在RouterBench上仅单次遍历训练数据（1×探索）即可达到离线方法性能，减少90%数据收集成本；探索到4×时性能进一步提高，但边际收益递减。
5. **理论验证**：模拟实验显示WR-Online的累计遗憾衰减速度优于O(1/√T)，接近已知成本的上界算法，验证了O(√T)遗憾界。
6. **自适应LP的必要性**：静态LP（固定每轮约束）在成本方差大的SWE-Bench上超支>5%，而WR-Offline通过动态调整b/τ避免了超支。
